# 第一章金属切削加工中的基本定义

1.属切削加——属切削刀具和件按定规律作相对运动，通过刀具上的切削刃切除件上多余的(或预留的)金属，从而使工件的形状、尺寸精度及表面质量都合乎预定要求，这样的加工称为金属切削加工。切削加工的目的：是被加工零件的尺寸精度、形状和位置精度、表面质量达到设计与使用要求。

2.金属切削加工过程中的两在要素：成形运动（切削运动）、刀具。

3.工件表面形状与成形方法：

(1）表都可以看成是根母线沿着导线运动形成的，般情况下母线和导线可以互换，特殊表如圆锥表不可互换。母线和导线统称为发线。  
(2) 发线的形成法：轨迹法(切削刃与被加表为点接触，发线为接触点的轨迹线)、成形法(曲线形的母线由切削刃直接形成，直线形的导线由轨迹法形成)、相切法(刀具边旋转边作轨迹运动，需两个独的成形运动)、展成法(需个独的成形运动)。

(3）成形运动是形成发生线所需成形运动的总和。

4.切削运动：

(1)主运动：刀具和工件之间产生的最主要的相对运动，它是刀具切削刃及其毗邻的刀面切入工件材料使切削层属转变成切屑从形成新鲜表的运动。特点：速度、消耗机床功率最、唯、可以由刀具或件完成。向：切削刃上选定点相对于件的瞬时主运动向。速度： $\mathrm { v } = \pi d _ { w } n / 1 0 0 0$   
(2)进给运动：由机床或提供完成件成形的运动。特点：速度低、消耗机床功率少、般不唯、可由刀具或件完成。向：切削刃上选定点相对于件的瞬时进给运动向。

5.切削深度：指已加工表面和待加工表面之间的垂直距离。

6.切削用量三要素：主运动速度ν、进给量f、切削深度 $\scriptstyle { \pmb { a } } _ { p ^ { 0 } }$ （参照图1-1）切削量三要素直接影响切削的、切削温度的低、刀具磨损、刀具耐度，同时还对产率、加成本、加质量都有很的影响。

7.刀具几何角度：

(1)刀具切削部分组成：“尖两刃三”。（前刀上有切屑流出，主后刀与加表相对，副后刀与已加工表面相对）  
(2)度标注参考系的建基于两点假设：i.假定进给运动速度为零；i.假定刀具安装底或轴线与基或切削平平或垂直。

# 第二章切屑形成过程及加工表面质量

1.研究切屑形成过程的意义：切削过程中的各种物理现象，如切削力、切削热、刀具磨损和加工质量都以切屑形成过程为基础，产中的许多问题如积屑瘤、鳞刺、振动、卷屑与断屑也与切屑形成有关。对于保证加平面、降低产成本、提生产效率有着分重要的意义。

2.研究金属切削变形过程的实验方法：(1)侧面方格变形观察法；(2)高频摄影法；(3)快速落刀法（手锤敲击式和爆炸式)；(4）扫描电镜和透视电镜显微观察法；(5）光弹性和光塑性试验法。

注：文中标有\*的地为PPT中未加说明的知识点。

3.金属切削过程—就是件的被切属层在刀具前刀的推挤下，沿着剪切(滑移)产剪切变形并转变为切屑的过程。  
4.属切削变形的基本特征：属材料受压其内部产应应变，约与受向成 $4 5 ^ { \circ }$ 的斜平面内，剪应随载荷增逐渐增，并且有剪应变产。开始是弹性变形，此时若去掉载荷，则材料将恢复原状；若载荷增到定程度，剪切变形进塑性流动阶段，属材料内部沿着剪切发相对滑移，于是属材料被压扁(对于塑性材料)或剪断(对于脆性材料)。

5.第一变形区的变形及其特征：

(1)始滑移OA和终滑移OM之间的变形区称为第变形区，位于前刀附近。第变形区的厚度随切削速度的增大面变薄，故可近似用一个平面OM表不第一变形区，OM与切削速度方向的夹角称为剪切角。

(2)第一变形区的特征：

a) 切削层金属产生沿滑移面的剪切变形，且变形会深入到切削层以下；  
b) 切削层金属经剪切滑移变成切屑后产了加工硬化现象，即切屑的硬度大于工件材料基体的硬度；  
c) 切削层金属经剪切滑移后晶格扭曲，晶粒拉长，即金属组织纤维化。  
d) 切屑厚度变厚且大于切削层厚度，剪切变形越大，切屑厚度越大；  
e) 切削塑性金属时，切屑背面呈锯齿形。

(3)切屑变形程度的表示法：切屑厚度变形系数、切屑长度变形系数、剪切、相对滑移。

6.第变形区的变形及其特征

(1)切削塑性属时，切屑从前刀上流出时受前刀的挤压和摩擦，在靠近前刀处形成第变形区。

(2)第二变形区的特征：

a) 切屑底层靠近前刀面处流速减慢，甚至滞留在前刀面上，形成滞留层，使切屑产生内摩擦；  
b) 切屑底层流经前刀时产的摩擦热使切屑与前刀的接触处温度进点升，达到百度甚上千度；  
c) 切屑底层因摩擦变形而纤维化，底层长度增加，切屑发向上弯曲，与前刀面的接触面积减；  
d) 切屑底层进步产加硬化，硬度大于切屑的上层硬度，底面因摩擦呈光滑面。

(3)剪切与前上摩擦的关系： $\begin{array} { r } { \Phi + \beta - \gamma _ { o } = \frac { \pi } { 4 } . } \end{array}$ 。前增，则剪切增，切屑变形减；摩擦增， 则剪切减，切屑变形增。

(4)前刀面上的摩擦：

a） 在有粘结情况下，切屑与前刀之间就不是般的外摩擦，是切屑底层属和刀具上的粘结层与其上层金属之间的内摩擦。b） 影响前刀摩擦系数的因素有四个：件材料↓、切削厚度↓、切削速度↑↓、刀具前↑。（P15）

(5)积屑瘤：

a）产生原因：切屑对前刀面接触处的摩擦使前刀面十分洁净，当两者接触达到一定温度同时压力又较高时，就会产生粘结现象，即“冷焊”。这时切屑从粘结在前刀面的底层上流过，形成内摩擦。如果温度、压适当，底面上的金属因内摩擦变形也会发加硬化而被阻滞在底层，粘结成一体，这样粘结层逐渐增大，直到该处的温度与压不以造成粘附为。积屑瘤的产以及它的积聚度与金属材料的硬化性质有关，也与刃前区的压力和温度分布有关。  
b)产生条件： $\textcircled{1}$ 塑性材料的加硬化（加硬化倾赂愈强愈易产积屑瘤）； $\textcircled{2}$ 切削温度的影响（实质反映切削速度对积屑瘤度的影响)。  
c)对切削过程的影响： $\textcircled{1}$ 实际前角增大； $\textcircled{2}$ 增大了切削厚度； $\textcircled{3}$ 使加工表面粗糙度增大； $\textcircled{4}$ 对刀具耐度的影响（稳定时提刀具耐度，不稳定时可使刀具产粘结磨损）  
d）防止积屑瘤的措施： $\textcircled{1}$ 降低切削速度： $\textcircled{2}$ 高速切削； $\textcircled{3}$ 采用润滑性能良好的切削液； $\textcircled{4}$ 增大刀具前以减小刀一屑接触区的压力； $\textcircled{5}$ 提件材料的硬度，减加硬化，这可以通过对件材料正或调质来实现。

7.第三变形区的变形注：文中标有\*的地方为PPT中未加说明的知识点。

(1）刀刃圆弧OB、后刀磨损带宽度VB和CD三部分对件加表属的挤压和摩擦便构成了第三变形区。  
(2)加变质层：已加表的属受多次挤压和摩擦，其组织与基体材料的性质不同，属的晶粒被拉得更细更长，其纤维向平于已加表面。

8.已加工表面质量

(1)已加工表面质量包括表面何学方面和表层材质的变化两个方面的内容。对零件使用性能有较大影响的是表面粗糙度、加工硬化及残余应力。

(2）表粗糙度：已加表的微观不平度。对零件使性能的影响： $\textcircled{1}$ 减了连接表的接触积，接触表面有相对运动时，降低了连接表面的接触刚度； $\textcircled{2}$ 影响液压元件的密封性； $\textcircled{3}$ 受交变载荷的零件易产应力集中，降低了抗疲劳强度的能力； $\textcircled{4}$ 在表面粗糙度的凹处容易储存有害介质，使零件易被腐蚀。

(3）表面粗糙度产生的原因：

a） 残留积：减进给量可减残留积的最度，所以精加时宜很的进给量。增刀尖圆弧半径或减主偏同样能减残留积的最度，但会使径向分增，艺系统刚性不时易引起振动使已加表面产振纹。产中多减副偏的法来减残留面积的最度，甚副偏为零的修光刃，此时修光刃度必须于进给量。  
b） 积屑瘤的影响：对表面粗糙度的影响公次于残余面积高度所形成的已加工表面粗糙度。  
c） 鳞刺的影响：鳞刺是在较低及中等切削速度下切削塑性材料时在已加表出现的鳞状刺。其形成过程分为四个阶段：抹拭阶段、导裂阶段、层积阶段、切成阶段。抑制鳞刺的措施： $\textcircled{1}$ 减小切削厚度以减小切屑作用在前刀面上的压力； $\textcircled{2}$ 采用润滑性能良好的切削液；$\textcircled{3}$ 采用硬质合金刀具高速切削； $\textcircled{4}$ 当切削速度的提受到限制时，可采加热切削，以降低件材料的硬度。  
d） 切削过程中的变形的影响：单元切屑周期性的断裂深到切削表面以下，在表留下波浪形纹路；由于刀刃两端没有来自侧面的约束力，工件材料被挤压而隆起。  
e) 刀具边界磨损的影响：副后刀面上的边界磨损。  
f) 切削过程中的振动的影响：\*减小或消除振动的措施： $\textcircled{1}$ 提工艺系统的刚度； $\textcircled{2}$ 对高速回转的零件进动、静平衡，降低往复运动部件的速度； $\textcircled{3}$ 提机床传动件的制造精度和装配精度； $\textcircled{4}$ 合理选择切削量，在允许的情况下适当增进给量和切削速度； $\textcircled{5}$ 采减振措施。

(4)加工硬化：

a）对零件使用性能的影响： $\textcircled{1}$ 有助于提零件的耐磨性，但容易出现微裂纹，影响零件的疲劳强度：②给后继工序加工带来困难，加剧刀具的磨损，降低刀具的耐用度。  
b）产的原因： $\textcircled{1}$ 第变形区的变形深到切削层以下； $\textcircled{2}$ 刀刃圆弧的挤压和摩擦产附加塑性变形；$\textcircled{3}$ 里层金属的弹性恢复使已加工表面与后刀面继续产生挤压和摩擦，已加工表面经上述多次挤压和摩擦后产强烈的塑性变形，晶格扭曲，晶粒拉长，晶粒破碎而强化，硬度显著提。

(5)残余应力：

a）对零件使用性能的影响： $\textcircled{1}$ 使加后的零件变形，影响其形状精度；②容易产微裂纹，影响受交变载荷的零件的抗疲劳强度能力。b）产原因：机械应引起的塑性变形、热应引起的塑性变形、相变引起的体积变化。

9.切屑类型：带状切屑、挤裂切屑、单元切屑、崩碎切屑。（注意各切屑类型的形成条件！）

10.切屑形状及控制：

(1)切屑形状的形成过程： $\textcircled{1}$ 基本变形阶段： $\textcircled{2}$ 卷曲变形阶段； $\textcircled{3}$ 附加变形和折断阶段。(2)控制切屑的方法： $\textcircled{1}$ 改变前、切削速度及进给量以控制基本变形；②断屑槽控制切屑运动轨迹卷曲半径及螺距。

# 第三章切削过程中的物理现象及影响因素

金属切削过程：复杂的能量转换过程，它伴随着一系列的物理现象，工件材料的变形、摩擦、切削力、切削热

和温度以及道具的磨损破损等影响工件表面质量和切削效率。  
影响切削过程的主要因素：工件材料、刀具切削性能、切削用量（v、f、ap）、切削液。

1.切削力：

(1)在切削过程中，切削直接影响着切削热的产，并进步影响着刀具磨损、刀具寿命、加精度和已加工表面质量。(2)来源：两个正压，两个摩擦。弹性变形抗、塑性变形抗、前和后刀的摩擦。

(3）切削力经验公式可分为指数公式和单位切削两类。

(4)影响切削力的因素：

a） 被加件材料的影响：注意：铜、铝等有金属的强度低，虽然塑性较大，但加硬化倾向，故切削；加工铸铁等脆性材料时，因件材料的塑性，加硬化，形成的是崩碎切屑，切屑与前刀面的接触长度短，接触面积，摩擦，所以加铸铁的切削比刚。  
b) 切削用量的影响：1.切削深度ap和进给量f对切削力的影响，是通过切削面积AD的影响而达到的。2.切削速度v对切削力的影响：实验法。影响规律不是呈单调的曲线，而是随速度不同而变化的。  
c) 刀具几何角度的影响： $\textcircled{1}$ 前角：加工钢时， $F _ { x } \setminus F _ { y } \setminus F _ { z }$ 都会随刀具前角的增大而减小且影响程度随切削速度的增大而减小，加工脆性金属时，前角对切削力的影响不明显； $\textcircled{2}$ 主偏角： $\kappa _ { \textit { r } }$ 增大时， $F _ { x }$ 增大， $\boldsymbol { F } _ { v }$ 减小； $\kappa \_ < 6 0 ^ { \circ }$ ${ \sim } 7 5 ^ { \circ }$ 时， $\pmb { F } _ { z }$ 减小， $\pmb { \kappa } _ { r } { > } 6 \mathbf { 0 } ^ { \circ }$ \~75°时， $\pmb { F } _ { z }$ 增大； $\textcircled{3}$ 刃倾角：入，增大时，$\underline { { F } } _ { \mathrm { x } }$ 增大， $\underline { { F } } _ { \underline { { v } } }$ 减小， $\pmb { F } _ { z }$ 没影响； $\textcircled{4}$ 负倒棱：在正前相同时，有负倒棱的刀具切削； $\textcircled{5}$ 刀尖圆弧半径：半径增大，切削力增大，相当于主偏角减小的影响。  
d) 刀具材料的影响：通过刀具材料与工件材料之间的摩擦系数影响摩擦力，从而直接影响切削力的。同等条件下，各刀具切削：陶瓷<硬质合金<高速钢  
e) 切削液的影响：减小摩擦，降低切削力。  
f) 刀具磨损的影响：前刀面牙洼增大了前，减了切削；后刀面磨损棱面宽度越大，切削越大。

2.切削热和切削温度：

(1)切削热和由它产生的切削温度能改变刀具前刀面上的摩擦系数，直接影响刀具的磨损和刀具耐用度；切削温度能改变件材料的切削性能，影响积屑瘤的产和消失，直接影响件的加工精度和表面质量。  
(2)\*切削热的产与传出：a）三个发热区：剪切发热区、切屑与前刀接触区、后刀与加表接触区。b）切屑热的传出：切屑、件、刀具、周围介质（空、切削液）。

(3）\*影响切削温度的因素：切削量、刀具何参数、刀具磨损、件材料、切削液等。

3.刀具磨损和刀具耐用度：

# 第六章机械加工精度

1.零件的机械加工质量包括加工精度和加工表面质量两大方面。

2.机械加工精度的概念

(1）机械加精度零件经过加后的尺、何形状以及各表相互位置等参数的实际值与理想值相符合的程度，而它们之间的偏离程度则称为加工误差。  
(2)加精度包括：尺寸精度、何形状精度、相互位置精度  
(3)误差分类：系统误差(常值系统误差和变值系统误差)与随机误差、静态误差与切削状态误差

.获得尺寸精度的法：试切法(产率低，技术平要求，多于单件批量产)、调整法(动调整法由于考虑了加工过程中的影响因素，其精度比静调整法高)、定尺寸刀具法(大多用于孔加工刀具，成形刀具加工也属于这类，由于成本较，多于批、量产中)、动控制法(精度，质量稳定，产率，多于批量产，同时对前序的加精度要有定要求)。

4.影响加工精度的因素：

(1)零件的加精度主要取决于艺系统的结构要素和运式。艺系统的误差称为原始误差。  
(2)加原理误差的影响：由于采了近似的运动或者近似的刀具轮廓产的误差，如阿基德滚刀加渐开线齿轮。  
(3)工艺系统的制造误差和磨损的影响：a） 机床的制造精度和磨损： $\textcircled{1}$ 导轨误差：平内的弯曲变形引起的误差垂直内的误差得多； $\textcircled{2}$ 主轴误差：主轴的回转误差可分为四类，即纯径向跳动、纯度摆动、纯轴向窜动、轴心漂移。主轴的纯轴向窜动对于孔加工和外圆加并没有影响，但在加端面时造成端面与内外圆不垂直。b）刀具的制造误差和尺寸磨损：减刀具尺寸磨损对加精度影响的措施： $\textcircled{1}$ 进行尺寸补偿； $\textcircled{2}$ 降低切削速度，增长刀具寿命； $\textcircled{3}$ 选耐磨性较的刀具材料。c）夹具的制造误差和磨损：夹具中定位元件、对刀装置和导向元件的磨损会直接影响加精度。

(4)工艺系统受力变形对加工精度的影响

a） 刚度：工艺系统的切削力综合作下的y向(加工表面的法线方向)的切削分与y向的变形的值。动刚度主要造成艺系统的振动。  
b） 切削作点的位置变化产的误差  
c) 切削力大小的变化而引起的误差：“误差复映”：由于毛坯加工余量不均匀，或由于其他原因引起切削和艺系统受发变化，件产尺寸误差和形状误差。如车削个横截为椭圆的坯，致使件产相应的椭圆形误差的现象称为误差复映。随着刀次数增多，加误差也就愈，但当到定程度时，即使再增加次数，也不再起作了。此时其他原始误差的影响将其主要作。

d) \*减艺系统变形的措施： $\textcircled{1}$ 提机床部件或夹具部件的刚度； $\textcircled{2}$ 提高零件间接触表面的接触精度；$\textcircled{3}$ 当工件刚度成为产生加工误差的薄弱环节时，应采用合理的加工方法或装夹，以提高工件加工时的刚度； $\textcircled{4}$ 当机床部件、夹具部件刚度或件刚度的提受到条件限制时，则应尽量设法减径向。

a）艺系统的热源：内部热源(切削热、摩擦热、电机)和外部热源(环境温度、辐射热源)  
b） 机床热变形的影响：对加精度影响最的仍然是主轴部件、床导轨以及两者的相对位移。\*减机床热变形的措施： $\textcircled{1}$ 在机床结构设计上尽量将热源从艺系统中分离出去，使之独； $\textcircled{2}$ 尽量消除或减少关键部件在误差敏感向的热位移，均衡关键部件的温度场； $\textcircled{3}$ 采必要的冷却、通风散热装置等。  
c） 刀具热变形的影响：\*措施：合理选择切削量和刀具切削何参数，并给以充分的冷却和润滑，以减少切削热，降低切削温度。  
d） 件热变形的影响：受热均匀的热变形影响尺寸精度，受热不均的热变形影响形状精度。减件热变形应从减切削热、缩短对件的热作时间以及改善散热条件等面考虑。如及时进行刀具的刃磨和砂轮的修整，不让过分磨钝的刀刃和磨粒参加切削以减切削热；提切削速度，使大部分热量被切屑带走以减小传件的热量；供以充分的冷却液迅速散热；合理安排艺，粗精加工分开且件在精加前有充分时间进冷却；使件夹紧状态下有伸缩的由。

(6)艺系统残余应的影响：零件在没有外在载荷的情况下，其内部仍存在的应称为残余应。

a） 残余应特点：始终要求处于相互平衡的状态，在然候影响下会逐渐消失。

6.定位基准的选择：基准是用来确定生产对象上几何要素间的儿何关系所依据的那些点、线、面。从设计和工艺两个面看，分为两类：设计基准和艺基准。

(1) 设计基准设计图样上所采的基准。  
(2)艺基准——艺过程中所采的基准。根据用途不同可分为序基准(在序图上以确定该序所加表加后的尺、形状、位置的基准)、定位基准、测量基准和装配基准(装配时以确定零件或部件在产品中的相对位置所采用的基准)。

(3)精基准的选择原则：

a) “基准重合”原则：尽量选择被加工表面的设计基准作为精基准。这样可以避免因基准不重合引起的误差Δhi  
b) “基准统一”原则：应选择多个表面加工时都能使用的定位基准作为精基准。这样便于保证各加工表面间的相互位置精度，避免基准变换所产的误差并简化夹具的设计制造作；

c) “互为基准”原则：当两个表面的相互位置精度及其自身的尺寸与形状精度都要求很时，可采用这两个表面互为基准，反复多次进行精加工；  
d) “自为基准”原则：在某些要求加工余量尽量小而均匀的精加工工序中，应尽量选择加工表面本身作为定位基准。

(4) 粗基准的选择原则：

a) 若工件必须首先保证某重要表面的加工余量均匀，则应选择该表面为粗基准。  
b) 在没有要求保证重要表面加工余量均匀的情况下，若零件上每个表面都要加工，则应以加工余量最小的表作为粗基准。这样可使这个表在加中不致因加余量不造成加后仍有，件报废。  
c) 在没有要求保证重要表面加工余量均匀的情况下，若零件有的表面不需要加工时，则应以不加工表面中与加工表面的位置精度要求较的表面为粗基准。若既需保证某重要表面加余量均匀，又要求保证不加工表面与加工表面的位置精度，则仍按本原则处理。  
d) 选作粗基准的表面，应尽可能平整和光洁，不能有飞边、浇口、冒口及其他缺陷，以便定位准确，装夹可靠。  
e) 粗基准在同一尺寸向上通常只允许使用一次，否则定位误差太。

7.工艺路线的制订（1）加工经济精度与加工方法的选择：

a) 加工经济精度：指在正常加工条件下所能保证的加工精度和表面粗糙度。  
b) 加工方法的选择原则：i. 所选加工方法的经济精度及表面粗糙度与加工表面的要求相适应。ii. 所选加工方法应能保证加工表面的几何形状精度与表面相互位置精度要求。ii. 所选加工方法应与零件材料的可加工性相适应。iv. 所选加工方法应与生产类型相适应。V. 所选加工法应与本厂现有产条件相适应。

(2)加工顺序的安排：

a) 工序顺序的安排原则：i. 先加工基准面，再加工其他表面。（“基准优先”)ii. 一般情况下，先加工平面，后加工孔。（“先面后孔”)iii. 先加工主要表面，后加工次要表面。（“先主后次”)iv. 先安排粗加工工序，后安排精加工工序。（“先粗后精”）

ii. 对于消除内应力而进行的热处理工序，一般安排在粗加工之后，精加工之前。  
ii. 对于提零件表硬度的热处理序(如淬、渗碳淬等)，般安排在半精加之后，精加之前；对渗氮，一般安排在粗磨后，精磨前。

a）装配尺寸链的建就是在装配图上，根据装配精度的要求，找出与该项精度有关的零件及其有关的尺寸，最后画出相应的尺寸链图。  
b)步骤：i. 判别封闭环ii. 判别组成环（判别法：从封闭环出发，按逆时针型号顺时针向依次寻找相邻零件，直返回到封闭环，形成封闭环链)ii. 画出尺寸链图（遵循原则： $\textcircled{1}$ 封闭的原则； $\textcircled{2}$ 最短的原则）

(3）利用装配尺寸链达到装配精度的方法：

a) 互换法：

i. 完全互换法：多于精度要求不太的短环装配尺寸链。特点是：装配容易，技术平要求不，装配产率，装配时间定额稳定，易于组织装配流线产，企业之间的协作与备品问题易于解决。  
ii. 不完全互换法：多于产节奏不是很严格的批量产中。  
b）分组法：实质是按组互换，既能扩各组成环的公差，又能保证装配精度的要求。多于封闭环精度要求较的短环尺寸链且般只于组成环公差都相等的装配尺寸链。缺点：测量、分组、保管、运输等各种比较复杂，所需的零件储备量要增。  
c）修配法：实质是扩组成环的公差，是不能互换的。在选增环为修配环时，当按各组成环所订经济公差极值法算出新封闭环 ${ { \bf A } _ { 0 } } ^ { \prime }$ ,若 $ { \mathrm { E I } _ { 0 } } ^ { \prime } \mathrm { > E I } _ { 0 }$ ，则修配环的基本尺不必改变(或减个数值 ${ | E I _ { 0 } } ^ { ' } - E I _ { 0 } | )$ ,否则要增加个数值 ${ | E I _ { 0 } } ^ { ' } - E I _ { 0 } { | }$ o  
d）调整法：采更换不同尺寸的某个组成环或调整某个组成环的位置来达到封闭环的精度要求，这就是调整法。可分为：可动调整法、固定调整法、误差抵消调整法等.i. 可动调整法：用改变所选定的调节件的位置来达到装配精度的方法。ii. 固定调整法：按定尺寸等级制造套专零件（垫圈、垫或轴套）。ii. 误差抵消调节法：根据尺寸链中某些组成环误差的向作定向装配。
