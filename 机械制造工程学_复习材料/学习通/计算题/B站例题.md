# 尺寸链计算
易错点
1. 保证的尺寸不一定是间接得到的
2. 封闭环: 间接得到的
3. 每一个尺寸链只有一个封闭环, 如果画的尺寸链草图中出现了两个封闭环, 说明要拆开
4. 组成环: 由加工中得到的, 也就是工序中加工得到的尺寸
5. 组成环不能重复, 也就是直径如果要作为组成环, 为了避免重复, 要用半径


入体原则: 
判断尺寸随着加工进行
- 尺寸越来越大, 下偏差为0, 比如孔的直径, 键槽的
- 尺寸越来越小, 上偏差为0, 比如轴的直径

设计图和工序图相互计算尺寸的思路
- 判断两个图中的相同尺寸的设计基准, 定位基准, 工序基准是否重合
	- 重合, 则设计尺寸和工序尺寸相同
	- 不重合, 需要用工艺尺寸链进行计算
