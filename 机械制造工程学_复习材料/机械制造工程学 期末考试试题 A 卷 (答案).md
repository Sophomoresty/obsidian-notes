## 一、填空题 (每空1分, 共38分)

1. 在加工中, 切削运动按其功用, 可分为 **主**运动和 **进给**运动 ，其中, **主**运动消耗功率最大 。**切削深度**是指已加工表面与待加工表面之间的垂直距离 。

2. 过主切削刃上选定点的主剖面内, 前刀面与基面之间的夹角称为 **前**角、主后刀面与切削平面之间之间的夹角称为 **主后**角 ，这两个角度都在主剖面内测量。

3. 金属切削过程中常见的物理现象, 如切削力、**切削热**、**刀具磨损**和加工质量都以 **切屑**形成过程为基础 。

4. 切削力的来源主要有: 切削层金属、切屑和工件已加工表面都要发生 **弹性变形**和**塑性变形**的抗力、刀具与切屑、工件表面产生的 **摩擦力**所产生 。

5. 主偏角 kr 减小, 进给力 Ff **增大**、切深抗力 Fy(径向力 Fp) **增大**。

6. 切削加工性的常用衡量指标主要有: 以加工质量衡量、以 **刀具耐用度**衡量、以 **切削力和切削温度**衡量、以断屑性能衡量 。

7. 从刀具耐用度角度, 切削用量三要素选择顺序是, 首先选择 **切削深度 ap**，再选 **进给量 f**，然后根据确定的刀具耐用度计算 **切削速度 v** 。

8. 切削液的使用方法主要有 **浇注法**、**高压冷却法**、喷雾冷却法 。

9. 用于孔的精加工的镗刀又称为浮动镗刀。浮动镗刀镗孔时, 镗刀块可在镗杆的方孔中稍许浮动, 使径向切削力自动平衡, 刀块自动 **对中**，从而补偿了由于刀具安装误差或镗杆径向跳动引起的 **偏心**。但由于镗刀块可在镗杆方孔中移动, 所以不能纠正 **原有孔的轴线**的偏斜 。

10. 铣床夹具对刀时, 对刀块和刀具间要放入 **塞尺**，防止刀具和对刀块 **直接接触(或碰撞)**而损坏刀具和对刀块。而铣床夹具在机床上的定位, 一般是夹具体底面及其上的两个 **定位键**来实现的 。

11. 深孔钻必须合理解决 **断屑**和排屑、冷却和 **润滑**、**导向**等问题才能正常工作 。

12. 在滚齿时, 要求滚刀的 **刀齿螺旋线**方向与工件齿槽方向必须一致, 这是沿齿向进给切出全齿长的条件。所以, 加工前要调整滚刀的 **安装**角 。

13. 为了减少或消除残余应力, 可采取的措施主要有 **合理设计零件的结构**和 **采取时效处理** 。

14. 许多功能完全相同而结构 **工艺**性不同的零件, 它们的加工方法与制造成本常常有着很大的差别。

15. 机器的装配精度可分为 **几何精度**和 **运动精度**两大部分 。

## 二、简述题 (32分)

1. **积屑瘤的产生原因、对切削过程的影响? (6分)**
    * **产生原因**: 在切削塑性金属时，在合适的切削速度和温度下，切屑底层金属与刀具前刀面之间因高温高压产生强烈的摩擦和粘结（“冷焊”）现象 。被粘住的金属层在其后切屑的推挤下发生加工硬化，形成一个硬度很高的楔形体，即积屑瘤 。
    * **对切削过程的影响**:
        * **有利影响**: ① 增大了刀具的实际工作前角，减小了切削变形和切削力 。 ② 积屑瘤代替刀尖进行切削，保护了切削刃，在稳定时能提高刀具耐用度 。
        * **不利影响**: ① 积屑瘤的产生、长大和脱落过程不稳定，会引起切削力波动和振动。 ② 脱落的积屑瘤碎块会粘附在已加工表面或划伤表面，使表面粗糙度急剧增大 。 ③ 增大了实际切削深度 。 ④ 不稳定时，积屑瘤脱落可能带走刀具材料，加剧刀具的粘结磨损 。

2. **刀具材料应具备的切削性能? (3分)**
    刀具材料应具备以下基本性能 ：
    * **高的硬度和耐磨性**: 这是刀具材料最基本的性能，硬度越高，耐磨性越好。
    * **足够的强度和韧性**: 保证刀具在承受切削力、冲击和振动时，不发生崩刃和折断。
    * **高的耐热性(热稳定性)**: 保证刀具在高温下仍能保持足够的硬度、耐磨性和强度。
    * **良好的工艺性**: 包括锻造、热处理和刃磨等加工性能，便于将材料制成刀具。
    * **经济性**: 在满足切削要求的前提下，成本应尽可能低。

3. **刀具磨损的形式及磨损原因 (7分)**
    * **磨损形式** ：
        * **前刀面磨损**: 在前刀面上靠近切削刃处产生的月牙洼状磨损。
        * **后刀面磨损**: 在后刀面上形成的平行于主切削刃的磨损带。
        * **边界磨损**: 在前后刀面交界处，即切削刃附近的磨损。
    * **磨损原因** ：
        * **机械磨损(磨粒磨损)**: 工件材料中的硬质点（如碳化物、氧化物夹杂）在刀具表面刻划出沟纹造成的磨损，是低速切削时的主要原因 。
        * **热磨损**: 包括粘结磨损和扩散磨损。
            * **粘结磨损**: 刀具与工件材料在高温高压下发生粘结，粘结点在相对运动中被撕裂而造成的磨损 。
            * **扩散磨损**: 在高温下，刀具与工件材料的化学元素相互扩散，改变了刀具表层成分和性能而导致的磨损，是硬质合金刀具高速切削时的主要原因之一 。
        * **化学磨损**: 刀具材料与周围介质（如空气中的氧）在高温下发生化学反应，生成硬度较低的化合物被切屑带走而形成的磨损 。

4. **拉削加工的特点? 可否拉削三角形孔? (4分)**
    * **拉削加工的特点** ：
        * **生产效率高**: 一次拉削行程可完成粗、精加工，辅助时间短。
        * **加工精度高、表面粗糙度低**: 拉刀有校准齿和精加工齿，可获得很高的尺寸精度和表面质量。
        * **加工范围广**: 可加工各种内外表面，如圆孔、花键孔、键槽、平面和各种复杂成形面。
        * **拉刀寿命长，但制造成本高**: 因此拉削主要适用于大批量生产 。
    * **可否拉削三角形孔**: **可以**。只要能制造出相应截面形状的拉刀，拉削就可以加工各种形状的通孔，包括三角形、四边形等异形孔。

5. **获得加工精度的方法? (2分)**
    获得零件尺寸精度的方法主要有四种 ：
    1. **试切法**: 通过“试切-测量-调整-再切削”循环来达到尺寸要求，多用于单件小批生产 。
    2. **调整法**: 在加工前，通过调整刀具、夹具或机床挡块的相对位置来保证尺寸精度，生产率较高 。
    3. **定尺寸刀具法**: 依靠刀具的相应尺寸来保证工件的尺寸精度（如用钻头、铰刀加工孔），生产率高，多用于大批量生产 。
    4. **自动控制法**: 在加工过程中自动测量加工尺寸，并与要求尺寸比较，通过伺服系统自动补偿误差，精度高，生产率高 。

6. **机械加工工序的安排原则? (2分)**
    主要安排原则如下 ：
    1. **先基准后其它**: 先加工用作定位基准的表面，再加工其它表面。
    2. **先面后孔**: 先加工平面，后加工孔，保证孔与平面的位置精度，且加工平面时不易损伤孔。
    3. **先主后次**: 先加工主要表面（如装配基面、工作表面），后加工次要表面。
    4. **先粗后精**: 先安排粗加工工序，然后是半精加工，最后是精加工和光整加工，保证最终精度。

7. **试说明辅助支承与可调支承的区别, 各起什么作用? (4分)**
    * **区别**:
        * **作用不同**: **可调支承**属于主要支承，其作用是**限制工件的自由度**，参与工件的定位 。而**辅助支承**的作用是**不限制工件自由度**，仅用于提高工件在夹紧和切削力作用下的刚性，防止变形 。
        * **结构与使用不同**: 可调支承在工件装夹前调整好并固定，以确定工件位置。辅助支承则是在工件被主要支承定位好之后，再使其与工件轻轻接触并锁紧，起一个“扶持”作用。
    * **各自作用**:
        * **可调支承**: 用于因毛坯尺寸变化较大或加工系列零件时，需要调整定位元件位置的场合，起到**定位**作用 。
        * **辅助支承**: 用于加工刚性较差的工件时，增加支承点，**提高工件刚度**，防止其在夹紧力或切削力作用下产生变形或振动，从而保证加工精度 。

8. **生产中多采用阿基米德滚刀而不是渐开线滚刀加工齿轮的原因是什么? (4分)**
    这是因为**阿基米德滚刀的制造和检验要比渐开线滚刀简单得多**。
    * **制造简便**: 阿基米德滚刀在垂直于其螺旋线方向的法剖面内，其齿廓是直线。通过铲磨或磨削的方法，很容易加工出精确的直线齿廓。
    * **测量方便**: 直线齿廓的测量非常方便和准确。
    * **渐开线滚刀的困难**: 理论上，要精确加工出渐开线齿轮，需要使用齿廓为渐开线的滚刀。但渐开线是曲线，制造和检验这种精确的曲线刀刃非常困难且成本高昂。
    * **误差影响**: 使用阿基米德滚刀加工会产生微小的**加工原理误差** ，但在大多数精度要求不高的场合，这种误差可以忽略不计。因此，从经济性和工艺性考虑，生产中普遍采用阿基米德滚刀。

## 三、图形分析题 (10分)

1. **图中夹紧方案示例, 分析夹紧方案是否合理? 如有不合理之处、则应如何改进? (本题共5分)**
    * **分析**: **不合理**。
    * **原因**:
        1. **夹紧力方向不当**: 图中夹紧力方向垂直向下，主要作用是使工件底面与定位面 A 贴紧。而镗孔 K 时，主要的切削力是水平方向的，会推动工件使其离开垂直定位面 B，该夹紧力对此方向的切削力抵抗效果很差，不能保证孔轴线与 B 面的垂直度要求。
        2. **夹紧力作用点不当**: 夹紧力作用在工件的悬臂部分，容易使工件产生弯曲变形，影响加工精度。
    * **改进措施**:
        1. 应改变夹紧力的**方向**，使其指向主要定位基面。可将夹紧装置移到工件左侧，施加一个水平向右的夹紧力，直接将工件紧靠在定位面 B 上。
        2. 应改变夹紧力的**作用点**，使其作用在工件刚性好的部位。例如，在施加水平夹紧力的同时，夹紧点应尽量靠近下方的支撑面。

2. **根据六点定位原理, 试分析下面图中所示定位方案。(本题共5分)**
    * **长心轴**: 限制工件沿 Y、Z 轴的移动（2个自由度），以及绕 Y、Z 轴的转动（2个自由度）。共限制 **4个** 自由度。
    * **台阶端面**: 限制工件沿 X 轴的移动（1个自由度）。共限制 **1个** 自由度。
    * **总结**: 该定位方案共限制了工件的 **5个** 自由度。唯一未被限制的自由度是 **绕 X 轴的转动**。对于轴对称的套类零件，这个自由度通常不影响加工，因此这是一种合理的不完全定位。

## 四、计算题 (16分)

1. **尺寸链计算 (8分)**
    1. **画尺寸链**:
        * 根据题意，要求保证尺寸 $A_2$ ，$A_0$ 和 $A_1$ 已加工好。工序是保证 $A_2$。从图中关系可知，这三个尺寸与左边台阶尺寸 $A_3$ (即题中要求的工序尺寸) 共同构成了封闭的尺寸关系。
        * 尺寸链为：$A_3 + A_2 + A_1 = A_0$。
        * **封闭环**是最后间接保证的尺寸，但本题是反算工序尺寸，已知封闭环的要求，求组成环。此题中，我们把 $A_0$ 看作封闭环，因为它连接了所有尺寸。
        * 组成环：$A_1$ (增环), $A_2$ (增环), $A_3$ (增环)。
    2. **用极值法计算**:
        * **基本尺寸**:
            $A_{0基本} = A_{1基本} + A_{2基本} + A_{3基本}$
            $38 = 8 + 10 + A_{3基本}$
            $A_{3基本} = 38 - 8 - 10 = 20mm$
        * **上偏差**:
            $ESA_0 = ESA_1 + ESA_2 + ESA_3$
            $0 = 0 + 0.1 + ESA_3$
            $ESA_3 = -0.1 mm$
        * **下偏差**:
            $EIA_0 = EIA_1 + EIA_2 + EIA_3$
            $-0.1 = -0.05 + (-0.1) + EIA_3$
            $-0.1 = -0.15 + EIA_3$
            $EIA_3 = -0.1 + 0.15 = 0.05 mm$
        * **校核**: $T_3 = ESA_3 - EIA_3 = -0.1 - 0.05 = -0.15$。公差不能为负，说明计算或尺寸链分析有误。

    * **重新分析尺寸链**:
        当一个尺寸由其他几个尺寸保证时，该尺寸为封闭环。本题是**要求保证尺寸 $A_2$**，所以 $A_2$ 是**封闭环**。
        * 从图a)可得尺寸链关系：$A_0 = A_1 + A_2 + A_3$。
        * 变换后以 $A_2$ 为封闭环：$A_2 = A_0 - A_1 - A_3$。
        * **增环**: $A_0$
        * **减环**: $A_1, A_3$
    * **重新计算**:
        * **基本尺寸**: $A_{2基本} = A_{0基本} - A_{1基本} - A_{3基本}$
            $10 = 38 - 8 - A_{3基本}$
            $A_{3基本} = 20mm$
        * **上偏差 (ESA)**: $ESA_2 = ESA_0 - EIA_1 - EIA_3$
            $0.1 = 0 - (-0.05) - EIA_3$
            $0.1 = 0.05 - EIA_3$
            $EIA_3 = 0.05 - 0.1 = -0.05 mm$
        * **下偏差 (EIA)**: $EIA_2 = EIA_0 - ESA_1 - ESA_3$
            $-0.1 = -0.1 - 0 - ESA_3$
            $ESA_3 = -0.1 - (-0.1) = 0 mm$
        * **结果**: 工序尺寸 $A_3$ 应为 $20_{-0.05}^{0} mm$。
        * **校核**: $T_3 = 0 - (-0.05) = 0.05 mm$。$T_0 = 0.1, T_1 = 0.05, T_2 = 0.2$。$T_2 = T_0 + T_1 + T_3 \Rightarrow 0.2 = 0.1 + 0.05 + 0.05$。校核正确。

2. **定位误差分析 (8分)**
    1. **分析定位误差来源**:
        * 工序是在三爪卡盘上夹持小轴颈d1($\phi25$)，加工大轴颈d2($\phi50$)上的平面，保证尺寸 h。
        * **定位基准**: 小轴颈 d1的轴线。
        * **测量基准**: 大轴颈 d2的轴线（因为尺寸 h 是对称于 d2轴线标注的）。
        * 由于定位基准（d1轴线）与测量基准（d2轴线）不重合，存在**基准不重合误差**。
    2. **计算定位误差**:
        * 基准不重合误差的大小等于两基准间的最大允许变动量。题中已给出d1与d2的同轴度误差为0.06mm，这意味着d1轴线相对于d2轴线（反之亦然）的最大偏移量（偏心距e）为 $e = 0.06 / 2 = 0.03mm$。
        * 这个偏心距e会直接引起工序尺寸h产生误差。当偏心方向与h的测量方向一致时，误差最大。定位误差 $\Delta_{定}$ 主要由该基准不重合误差引起。
        * $\Delta_{定} = e = 0.03 mm$。
        * *（注：严格来说三爪卡盘本身有定心误差，但题中未给，故只考虑基准不重合误差。）*
    3. **分析能否满足加工要求**:
        * 工序尺寸h的公差 $T_h = 45_ {-0.2}^{0}$，公差值为 $T_h = 0 - (-0.2) = 0.2 mm$。
        * 允许的定位误差要求为：$T_h / 3 = 0.2 / 3 \approx 0.067 mm$。
        * **比较**: 实际定位误差 $\Delta_{定} = 0.03 mm$。因为 $0.03 mm < 0.067 mm$，所以定位误差小于允许值。
    4. **结论**: **能够满足加工要求**。

## 五、自由回答题 (4分)

**谈谈你对计算机辅助工工艺设计(CAPP)的了解?以及其在装备制造业中可能起到的作用的认识。**

* **对 CAPP 的了解**:
    计算机辅助工艺设计(CAPP)是利用计算机技术来辅助完成产品零件从毛坯到成品整个制造过程的工艺规程设计。它位于 CAD（计算机辅助设计）和 CAM（计算机辅助制造）之间，是连接设计与制造的关键桥梁。CAPP 系统通常能根据零件的几何、材料、精度等信息，自动或半自动地生成加工工序、选择机床和刀具、确定切削用量、计算工时和成本等，最终输出完整的工艺卡片。

* **在装备制造业中可能起到的作用**:
    1. **提高工艺设计效率和质量**: CAPP 能将经验丰富的工艺师的知识和逻辑固化在系统中，快速生成标准、规范的工艺文件，大大缩短了工艺准备周期，并减少了因人为经验差异导致的工艺质量波动。
    2. **实现设计与制造的集成**: 作为 CAD/CAM 的纽带，CAPP 可以无缝读取 CAD 的设计信息，并将其转化为 CAM 所需的制造指令，是实现计算机集成制造系统(CIMS)和智能制造的核心环节。
    3. **优化制造成本与资源配置**: CAPP 系统可以快速评估多种工艺方案，通过成本核算和工时计算，帮助企业选择最优的、最具经济性的加工路线，从而降低制造成本，合理配置设备和人力资源。
    4. **促进工艺知识的传承与创新**: 它将企业的工艺知识以数据库和知识库的形式进行管理和积累，避免了因人员流动造成的技术流失，并为工艺的持续改进和创新提供了数据支持。
