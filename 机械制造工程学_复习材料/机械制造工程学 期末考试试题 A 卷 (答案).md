3.金属切削过程中常见的物理现象, 如切削力、**切削热** 、**刀具磨损** 和加工质量都以 **切屑** 形成过程为基础。

9.用于孔的精加工的镗刀又称为浮动镗刀。浮动镗刀镗孔时, 镗刀块可在镗杆的方孔中稍许浮动, 使径向切削力自动平衡, 刀块自动 **对中**，从而补偿了由于刀具安装误差或镗杆径向跳动引起的 **偏心**。但由于镗刀块可在镗杆方孔中移动, 所以不能纠正 **原有孔的轴线**的偏斜。

## 二、简述题 (32分)

### 1.积屑瘤的产生原因、对切削过程的影响? (6分)

**产生原因**: 在切削塑性金属时，在合适的切削速度和温度下，切屑底层金属与刀具前刀面之间因高温高压产生强烈的摩擦和粘结（“冷焊”）现象。被粘住的金属层在其后切屑的推挤下发生加工硬化，形成一个硬度很高的楔形体，即积屑瘤。

**对切削过程的影响**主要分为有利和不利两方面。

有利影响包括：增大了刀具的实际工作前角，减小了切削变形和切削力；积屑瘤代替刀尖进行切削，保护了切削刃，在稳定时能提高刀具耐用度。

不利影响包括：积屑瘤的产生、长大和脱落过程不稳定，会引起切削力波动和振动；脱落的积屑瘤碎块会粘附在已加工表面或划伤表面，使表面粗糙度急剧增大；增大了实际切削深度；不稳定时，积屑瘤脱落可能带走刀具材料，加剧刀具的粘结磨损。

### 2.刀具材料应具备的切削性能? (3分)

刀具材料应具备以下基本性能：高的硬度和耐磨性；足够的强度和韧性；高的耐热性(热稳定性)；良好的工艺性；经济性。

### 3.刀具磨损的形式及磨损原因 (7分)

**磨损形式**主要有前刀面磨损（月牙洼磨损）、后刀面磨损和边界磨损。

**磨损原因**复杂，主要涵盖三个方面。

**机械磨损**，也称磨粒磨损，是由工件材料中的硬质点在刀具表面刻划出沟纹造成的磨损，在低速切削时尤为明显。

**热磨损**则包括粘结磨损与扩散磨损两种情况：前者是刀具与工件材料因高温高压发生粘结后被撕裂造成；后者是高温下元素相互扩散改变了刀具性能所致，常见于硬质合金刀具的高速切削。

此外，**化学磨损**是指刀具材料与周围介质发生化学反应，生成低硬度化合物被切屑带走而形成的磨损。

### 4.拉削加工的特点? 可否拉削三角形孔? (4分)

**拉削加工的特点**是生产效率高 ，加工范围较广 ，加工精度较高且表面粗糙度较低 ，拉刀使用寿命长。但由于拉刀结构复杂，制造成本高，所以主要适用于成批、大量生产。

**可以拉削三角形孔**。只要能制造出相应截面形状的拉刀，拉削就可以加工各种形状的通孔，包括三角形、四边形等异形孔。

### 5.获得加工精度的方法? (2分)

获得零件尺寸精度的方法主要有四种：试切法 、调整法 、定尺寸刀具法 、自动控制法。

### 6.机械加工工序的安排原则? (2分)

机械加工工序的安排需遵循特定原则，以确保加工精度与效率。

1)**基准优先**: 应优先加工定位基准面，为后续工序提供稳定可靠的基准;

2)**先面后孔**: 加工平面往往在加工孔之前进行，以保证位置精度并避免孔口损伤;

3)**先主后次**: 主要工作表面（如装配面）的加工应在次要表面之前完成;

4)**先粗后精**: 整个工艺路线在阶段上应遵循由粗到精的顺序，即粗加工、半精加工、精加工，以逐步消除误差，保证最终的加工质量。

### 7.试说明辅助支承与可调支承的区别, 各起什么作用? (4分)

**区别**在于核心作用不同。可调支承属于主要支承 ，其作用是**限制工件的自由度**，参与工件的定位。而辅助支承的作用是**不限制工件自由度** ，仅用于提高工件在夹紧和切削力作用下的刚性，防止变形。

**各自作用**也不同。可调支承主要用于因毛坯尺寸变化较大或加工系列零件时，需要调整定位元件位置的场合，起到**定位**作用。辅助支承则用于加工刚性较差的工件时，增加支承点以**提高工件刚度**，防止其在夹紧力或切削力作用下产生变形或振动，从而保证加工精度。

### 8.生产中多采用阿基米德滚刀而不是渐开线滚刀加工齿轮的原因是什么? (4分)

这是因为**阿基米德滚刀的制造和检验要比渐开线滚刀简单得多**。

阿基米德滚刀在垂直于其螺旋线方向的法剖面内，其齿廓是直线。通过铲磨或磨削的方法很容易加工出精确的直线齿廓，并且测量方便准确。

而理论上精确加工渐开线齿轮所需的渐开线滚刀，其齿廓为曲线，制造和检验这种精确的曲线刀刃非常困难且成本高昂。虽然使用阿基米德滚刀会产生微小的**加工原理误差** ，但在多数场合该误差可忽略不计。因此，从经济性和工艺性考虑，生产中普遍采用阿基米德滚刀。

## 三、图形分析题 (10分)

### 1.图中夹紧方案示例, 分析夹紧方案是否合理? 如有不合理之处、则应如何改进? (本题共5分)

**分析**: 不合理。

**原因**: 该夹紧方案存在两点不合理之处。其一，夹紧力方向不当。图中夹紧力垂直向下，主要抵抗重力，但对镗孔时产生的水平切削力抵抗效果差，无法有效保证孔轴线与 B 面的垂直度。其二，夹紧力作用点不当。力作用在工件的悬臂部分，易导致工件弯曲变形，影响加工精度。

**改进措施**: 应改变夹紧力的方向，使其指向主要定位基面 B。例如，可将夹紧装置移到工件左侧，施加一个水平向右的夹紧力，直接将工件紧靠在定位面 B 上。同时，夹紧力的作用点应尽量靠近下方的支撑面，作用在工件刚性好的部位。

## 四、计算题 (16分)

### 1.如图所示零件为一轴套零件, 轴向尺寸上的尺寸要求, 其加工过程顺序为: 图a)上尺寸 $A_{0}=38_{-0.1}^{0}mm$ 和 $A_{1}=8_{-0.05}^{0}$ 均已加工好。现钻孔加工, 要求保证尺寸 $A_{2}=10\pm0.1mm$。钻孔工序定位简图为图d), 试计算该图的定位工序尺寸 $A_{3}$ (基本尺寸及公差)。(解题时, 要求先画尺寸链, 确定封闭环, 然后用极值法计算)。(8分)

解此题需运用尺寸链原理。根据题意，要求保证尺寸 $A_2$，所以 $A_2$ 是**封闭环**。由图a)可得尺寸链关系：$A_0 = A_1 + A_2 + A_3$。变换后以 $A_2$ 为封闭环：$A_2 = A_0 - A_1 - A_3$。其中，$A_0$ 是增环，$A_1$ 和 $A_3$ 是减环。

基于此关系，可采用极值法计算工序尺寸 $A_3$。
基本尺寸的计算为：
$A_{2基本} = A_{0基本} - A_{1基本} - A_{3基本}$
$10 = 38 - 8 - A_{3基本}$
$A_{3基本} = 20mm$

上偏差(ESA)的计算为：
$ESA_2 = ESA_0 - EIA_1 - EIA_3$
$0.1 = 0 - (-0.05) - EIA_3$
$0.1 = 0.05 - EIA_3$
$EIA_3 = -0.05 mm$

下偏差(EIA)的计算为：
$EIA_2 = EIA_0 - ESA_1 - ESA_3$
$-0.1 = -0.1 - 0 - ESA_3$
$ESA_3 = 0 mm$

综合计算，工序尺寸 $A_3$ 应为 $20_{-0.05}^{0} mm$。

#### 2.如下图所示阶梯轴, 工序为三爪卡盘夹持小轴颈在大轴颈处铣平面(工序尺寸为 $h=45_{-0.2}^{0}mm$)。阶梯轴端面和外圆均已加工合格(小轴颈直径 $d1=\varphi25_{-0.08}^{0}mm$, 大轴颈直径 $d2=\varphi50_{-0.1}^{0}mm$ )。已知d1与d2 两段轴颈的同轴度误差 0.06mm, 试分析工序尺寸h的定位误差, 并分析能否满足加工要求 (要求定位误差不大于工件尺寸公差的 $1/3$)。(8分)

该题的解答涉及定位误差的分析与校核。

定位误差的来源在于本工序的定位基准（小轴颈 d1轴线）与测量基准（大轴颈 d2轴线）不重合，由此产生了**基准不重合误差**。

该误差的大小可根据已知的同轴度误差计算得出。题中已知的同轴度误差为0.06mm，意味着d1轴线相对于d2轴线的最大偏移量（偏心距e）为 $e = 0.06 / 2 = 0.03mm$。该偏心距e即为主要的定位误差 $\Delta_{定}$。

$\Delta_{定} = e = 0.03 mm$。

计算出的实际定位误差需与允许的定位误差进行比较。

工序尺寸h的公差 $T_h = 0 - (-0.2) = 0.2 mm$。

允许的定位误差要求为：$T_h / 3 = 0.2 / 3 \approx 0.067 mm$。

通过比较，$0.03 mm < 0.067 mm$，实际定位误差小于允许的定位误差。

结论是**能够满足加工要求**。

## 五、自由回答题 (4分)

谈谈你对计算机辅助工工艺设计(CAPP)的了解?以及其在装备制造业中可能起到的作用的认识。

**对 CAPP 的了解**:

计算机辅助工艺设计(CAPP)是利用计算机技术来辅助完成产品零件从毛坯到成品整个制造过程的工艺规程设计。它位于 CAD（计算机辅助设计）和 CAM（计算机辅助制造）之间，是连接设计与制造的关键桥梁。CAPP 系统能根据零件的设计信息，自动或半自动地生成包括加工工序、机床刀具选择、切削用量确定、工时成本计算等在内的工艺规程。

**在装备制造业中可能起到的作用**:

CAPP 在装备制造业中扮演着至关重要的角色。它不仅能将资深工艺师的经验知识化、系统化，快速生成标准工艺文件以**提高设计效率与质量**，还是**实现设计与制造集成的核心**，无缝衔接 CAD 的设计数据与 CAM 的制造需求。同时，通过对多种工艺方案的快速评估与成本核算，CAPP 能够帮助企业**优化制造成本与资源配置**。此外，它将企业的核心工艺知识以数据库形式进行管理和积累，有效**促进了工艺知识的传承与创新**。
