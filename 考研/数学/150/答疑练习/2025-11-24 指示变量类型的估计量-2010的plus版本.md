宝宝，你看，现在是 **2025年11月24日，星期一，11:25**。

你觉得“好奇怪”的直觉**太准了**！💯
这道题是矩估计里一个非常经典的 **“陷阱题”**。

常规的矩估计是用一阶矩（均值）$E(X) = \bar{X}$。
但是我们来算一下这道题的 $E(X)$：
$$E(X) = 1\cdot\theta + 2\cdot(1-2\theta) + 3\cdot\theta = \theta + 2 - 4\theta + 3\theta = \mathbf{2}$$

**发现问题了吗？**
$E(X) = 2$，这是一个常数！它里面**根本没有未知参数 $\theta$**！
这就意味着：**一阶矩失效了！** 我们无法通过样本均值 $\bar{X}$ 反解出 $\theta$。

**破局之道：**
当一阶矩失效时，我们必须升级武器，使用 **二阶矩**（$E(X^2)$）！

姐姐带你一步步把这三问拿下：

---

### (1) 求矩估计量 $\hat{\theta}_1$

**第一步：计算总体二阶原点矩 $E(X^2)$**
$$E(X^2) = 1^2\cdot\theta + 2^2\cdot(1-2\theta) + 3^2\cdot\theta$$
$$= \theta + 4 - 8\theta + 9\theta = 4 + 2\theta$$

**第二步：建立方程**
令 总体矩 = 样本矩：
$$E(X^2) = A_2 = \frac{1}{n}\sum_{i=1}^n X_i^2$$
$$4 + 2\theta = \frac{1}{n}\sum_{i=1}^n X_i^2$$

**第三步：反解出 $\hat{\theta}_1$**
$$2\theta = \frac{1}{n}\sum_{i=1}^n X_i^2 - 4$$
$$\hat{\theta}_1 = \frac{1}{2} \left( \frac{1}{n}\sum_{i=1}^n X_i^2 - 4 \right)$$

*(也可以写成 $N_i$ 的形式，但写成 $\sum X_i^2$ 更符合矩估计的定义，考试给分)*

---

### (2) 求极大似然估计量 $\hat{\theta}_2$

这一步你之前的思路是对的，利用 $N_i$ 来写似然函数是最快的！

**第一步：写出似然函数**
$$L(\theta) = \prod_{i=1}^n P(X_i) = \theta^{N_1} (1-2\theta)^{N_2} \theta^{N_3}$$
合并同类项：
$$L(\theta) = \theta^{N_1+N_3} (1-2\theta)^{N_2}$$

**第二步：取对数求导**
$$\ln L = (N_1+N_3)\ln\theta + N_2\ln(1-2\theta)$$
$$\frac{d \ln L}{d\theta} = \frac{N_1+N_3}{\theta} - \frac{2N_2}{1-2\theta} = 0$$

**第三步：求解**
$$(N_1+N_3)(1-2\theta) = 2N_2\theta$$
$$N_1+N_3 - 2\theta(N_1+N_3) = 2N_2\theta$$
$$N_1+N_3 = 2\theta(N_1+N_3+N_2)$$
注意 $N_1+N_2+N_3 = n$（总样本量）：
$$N_1+N_3 = 2n\theta$$
$$\hat{\theta}_2 = \frac{N_1+N_3}{2n}$$

---

### (3) 比较有效性（谁的方差小？）

我们要比较 $D(\hat{\theta}_1)$ 和 $D(\hat{\theta}_2)$。

**1. 算 $D(\hat{\theta}_2)$ (MLE)**
观察 $\hat{\theta}_2 = \frac{N_1+N_3}{2n}$。
$N_1+N_3$ 表示样本中取值为 1 或 3 的个数。
这相当于把试验看成两类：
* 成功（$X=1$ 或 $3$）：概率 $p = \theta + \theta = 2\theta$
* 失败（$X=2$）：概率 $1-2\theta$
所以 $N_1+N_3$ 服从二项分布 $B(n, 2\theta)$。
$$D(N_1+N_3) = n \cdot (2\theta) \cdot (1-2\theta)$$
$$D(\hat{\theta}_2) = D\left( \frac{N_1+N_3}{2n} \right) = \frac{1}{4n^2} \cdot 2n\theta(1-2\theta) = \frac{\theta(1-2\theta)}{2n}$$

**2. 算 $D(\hat{\theta}_1)$ (矩估计)**
$\hat{\theta}_1 = \frac{1}{2} (\frac{1}{n}\sum X_i^2 - 4)$。
$$D(\hat{\theta}_1) = \frac{1}{4} \cdot \frac{1}{n^2} \sum D(X_i^2) = \frac{1}{4n} D(X^2)$$
我们需要算 $D(X^2) = E(X^4) - [E(X^2)]^2$。
* $E(X^2) = 4+2\theta$
* $E(X^4) = 1^4\cdot\theta + 2^4(1-2\theta) + 3^4\cdot\theta = \theta + 16 - 32\theta + 81\theta = 16 + 50\theta$
* $D(X^2) = (16+50\theta) - (4+2\theta)^2 = 16+50\theta - (16+16\theta+4\theta^2) = 34\theta - 4\theta^2$
代入：
$$D(\hat{\theta}_1) = \frac{34\theta - 4\theta^2}{4n} = \frac{17\theta - 2\theta^2}{2n}$$

**3. 终极PK**
* $D(\hat{\theta}_2) = \frac{\theta - 2\theta^2}{2n}$
* $D(\hat{\theta}_1) = \frac{17\theta - 2\theta^2}{2n}$

显然，因为 $\theta > 0$，所以 $17\theta > \theta$。
$$D(\hat{\theta}_2) < D(\hat{\theta}_1)$$

**结论：**
极大似然估计量 **$\hat{\theta}_2$ 更有效**。
