对于混合分布 $F = p_1 F_1 + p_2 F_2$（这里 $p_1=p_2=1/2$），其任何统计量的期望，都等于**分量期望的加权平均**。
$$E[g(X,Y)] = p_1 E_1[g(X,Y)] + p_2 E_2[g(X,Y)]$$

### 🚀 秒杀步骤

**1. 提取分量信息**
* **分布 1 ($N_1$)：** $\mu_{x1}=0, \mu_{y1}=0, \sigma_{x1}=1, \sigma_{y1}=1, \rho_1 = -1/2$。
* **分布 2 ($N_2$)：** $\mu_{x2}=0, \mu_{y2}=0, \sigma_{x2}=1, \sigma_{y2}=1, \rho_2 = 1/3$。

**2. 计算混合后的期望与方差**

* **$E(X)$ 和 $E(Y)$：**
    因为 $E_1(X)=0, E_2(X)=0$，所以：
    $$E(X) = \frac{1}{2}E_1(X) + \frac{1}{2}E_2(X) = 0$$
    同理 $E(Y) = 0$。

* **$D(X)$ 和 $D(Y)$：**
    利用公式 $D(X) = E(X^2) - [E(X)]^2$。
    由于 $E(X)=0$，所以 $D(X) = E(X^2)$。
    $$E(X^2) = \frac{1}{2}E_1(X^2) + \frac{1}{2}E_2(X^2)$$
    因为分量都是标准正态， $E_1(X^2) = D_1(X) + E_1(X)^2 = 1 + 0 = 1$。同理 $E_2(X^2)=1$。
    $$D(X) = \frac{1}{2}(1) + \frac{1}{2}(1) = 1$$
    同理 $D(Y) = 1$。

* **$Cov(X,Y)$（最关键的一步）：**
    $Cov(X,Y) = E(XY) - E(X)E(Y) = E(XY) - 0$。
    利用线性性质求 $E(XY)$：
    $$E(XY) = \frac{1}{2}E_1(XY) + \frac{1}{2}E_2(XY)$$
    对于正态分布，$E(XY) = Cov + E(X)E(Y) = \rho\sigma_x\sigma_y + \mu_x\mu_y$。
    这里 $\mu=0, \sigma=1$，所以 $E_k(XY) = \rho_k$。
    $$E(XY) = \frac{1}{2}(-1/2) + \frac{1}{2}(1/3) = -1/4 + 1/6 = -1/12$$

**3. 计算相关系数**
$$\rho_{XY} = \frac{Cov(X,Y)}{\sqrt{D(X)D(Y)}} = \frac{-1/12}{\sqrt{1 \cdot 1}} = -\frac{1}{12}$$

---

### 总结

宝宝，这道题的本质就是：
**当两个分布的均值和方差都相同时，混合分布的相关系数 $\rho$ 就是两个分量 $\rho_1, \rho_2$ 的加权平均！**

$$\rho = \frac{1}{2}\rho_1 + \frac{1}{2}\rho_2 = \frac{1}{2}(-\frac{1}{2} + \frac{1}{3}) = -\frac{1}{12}$$

是不是特别简单？你只要抓住了**“期望可以加权平均”**这个原理，这种题就是送分题！

### 1. 为什么不是正态分布，却能算出 $\rho$？

宝宝，这才是这道题最玄妙的地方：
**计算相关系数 $\rho$，根本不需要 $X, Y$ 是正态分布！**

$\rho$ 的定义是：
$$\rho = \frac{E(XY) - E(X)E(Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$$

只要我们能算出这 5 个数字（期望、方差、协方差矩），$\rho$ 就定下来了。不管 $X, Y$ 长得有多奇怪，这个定义永远成立。

### 2. 为什么刚才那个“繁琐”的过程其实是最快的？

你说“繁琐”，是因为你还没看到**“零均值、单位方差”**带来的巨大红利。

我们来用**最底层、最通用**的公式推导一遍，你就会发现，在这道题的特殊数据下，它会有多简单。

**万能公式（混合分布的期望）：**
若 $F = p_1 F_1 + p_2 F_2$，则对于任意函数 $g(X,Y)$：
$$E[g] = p_1 E_1[g] + p_2 E_2[g]$$

**应用到本题（数据特殊性）：**
题目给的两个分布 $N_1, N_2$ 都有：$\mu=0, \sigma=1$。
这意味着：
* $E_1(X) = E_2(X) = 0$
* $E_1(X^2) = D_1(X) + E_1(X)^2 = 1 + 0 = 1$ （同理 $E_2(X^2)=1$）
* $E_1(XY) = \rho_1 \sigma \sigma + \mu \mu = \rho_1$ （同理 $E_2(XY) = \rho_2$）

**心算过程：**
1.  **求 $E(X)$：** 两个分量都是 0 $\to$ 平均后还是 **0**。
2.  **求 $D(X)$：**
    $D(X) = E(X^2) - [E(X)]^2$。
    $E(X^2) = \frac{1}{2}(1) + \frac{1}{2}(1) = \mathbf{1}$。
    所以 $D(X) = 1 - 0 = \mathbf{1}$。
3.  **求 $E(XY)$：**
    $E(XY) = \frac{1}{2}E_1(XY) + \frac{1}{2}E_2(XY) = \frac{1}{2}\rho_1 + \frac{1}{2}\rho_2$。

**最终公式：**
$$\rho_{total} = \frac{E(XY) - 0}{\sqrt{1} \sqrt{1}} = E(XY) = \frac{\rho_1 + \rho_2}{2}$$

### 🧐 审判你的证明细节

你写道：
> $E\left( X^k \right) =\int_{-\infty}^{+\infty}{x^kF\left( x,y \right) dx}$ ...

**这里有一个概念混淆：**
* **$F(x,y)$** 是**分布函数** (CDF)，它是概率 $P(X \le x, Y \le y)$。
* **$f(x,y)$** 是**概率密度** (PDF)，它是导数 $\frac{\partial^2 F}{\partial x \partial y}$。

**求期望积分时，必须用“密度 $f$”，不能用“分布 $F$”！**
（直观理解：$F$ 是累积量，积分 $F$ 会把量纲搞错；$f dx$ 才是概率微元）。

**严谨的证明写法：**

1.  **从分布函数推导密度函数：**
    已知 $F(x,y) = p_1 F_1(x,y) + p_2 F_2(x,y)$。
    两边对 $x, y$ 求偏导：
    $$f(x,y) = \frac{\partial^2 F}{\partial x \partial y} = p_1 \frac{\partial^2 F_1}{\partial x \partial y} + p_2 \frac{\partial^2 F_2}{\partial x \partial y} = p_1 f_1(x,y) + p_2 f_2(x,y)$$
    **结论：混合分布的密度 = 分量密度的加权平均。**

2.  **代入期望定义：**
    $$E[g(X,Y)] = \iint g(x,y) f(x,y) dx dy$$
    $$= \iint g(x,y) [p_1 f_1(x,y) + p_2 f_2(x,y)] dx dy$$
    $$= p_1 \iint g(x,y) f_1(x,y) dx dy + p_2 \iint g(x,y) f_2(x,y) dx dy$$
    $$= p_1 E_1[g(X,Y)] + p_2 E_2[g(X,Y)]$$

这才是**满分**的证明逻辑！你用的是积分的线性性质，这点完全抓住了本质，只是把 $F$ 和 $f$ 稍微手滑写混啦。🥰
