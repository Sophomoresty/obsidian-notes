### **方法一：幂级数除法 (Power Series Division)**

这是最直接的思路，就是利用 $\\tan x = \\frac{\\sin x}{\\cos x}$。
既然我们已经熟知 $\\sin x$ 和 $\\cos x$ 的展开式，我们就可以像做多项式除法一样，直接对它们的幂级数进行**长除法**！

1.  **写出已知的展开式**：
    $$\sin x = x - \frac{x^3}{6} + \frac{x^5}{120} - \dots$$   $$\cos x = 1 - \frac{x^2}{2} + \frac{x^4}{24} - \dots$$

2.  **进行长除法计算**：

    ```
          x   + (1/3)x³ + (2/15)x⁵ + ...
        _____________________________
    1-x²/2+x⁴/24 | x -  x³/6  +   x⁵/120 - ...
                -(x -  x³/2  +   x⁵/24 - ...)
                _____________________________
                      (1/3)x³ - (1/30)x⁵ + ...
                    -((1/3)x³ - (1/6)x⁵ + ...)
                    _____________________________
                              (2/15)x⁵ + ...
    ```

**结论**：通过长除法，我们轻松地得到了 $\\tan x = x + \\frac{1}{3}x^3 + \\frac{2}{15}x^5 + o(x^5)$，这比反复求四阶、五阶导数要简单多了！

-----

### **方法二：积分法 (Integration Method)**

另一个思路，是利用导数关系。我们知道 $(\\tan x)' = \\sec^2 x$，这个还是有点复杂。但我们可以反过来想：什么函数的导数和 $\\tan x$ 有关呢？
我们知道 $(\ln(\cos x))' = \frac{1}{\cos x} \cdot (-\sin x) = -\tan x$。

所以，我们只要能求出 $\\ln(\\cos x)$ 的幂级数，再对它**求导并取负号**，就能得到 $\\tan x$ 的幂级数！

1.  **从 $\\cos x$ 开始**：
    $$\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - o(x^5) = 1 - \frac{x^2}{2} + \frac{x^4}{24} - \dots$$

2.  **利用 $\\ln(1+u)$ 的展开式**：我们知道 $\ln(1+u) = u - \frac{u^2}{2} + \frac{u^3}{3} - \dots$
    我们把 $\\cos x$ 构造成 $1+u$ 的形式，令 $u = -\frac{x^2}{2} + \frac{x^4}{24} - \dots$

3.  **代入展开**：
    $$\ln(\cos x) = \ln(1 + u) = u - \frac{u^2}{2} + \dots$$   $$= \left(-\frac{x^2}{2} + \frac{x^4}{24} - \dots\right) - \frac{1}{2}\left(-\frac{x^2}{2} + \dots \right)^2 + \dots$$
    我们只需要保留到 $x^4$ 项：
    $$= -\frac{x^2}{2} + \frac{x^4}{24} - \frac{1}{2}\left(\frac{x^4}{4}\right) + \dots = -\frac{x^2}{2} - \frac{x^4}{12} + \dots$$

4.  **求导得到 $-\\tan x$**：
    $$(\ln(\cos x))' = \frac{d}{dx}\left(-\frac{x^2}{2} - \frac{x^4}{12} - \dots\right) = -x - \frac{4x^3}{12} - \dots = -x - \frac{x^3}{3} - \dots$$

5.  **取负号得到 $\\tan x$**：
    $$\tan x = -(\ln(\cos x))' = -(-x - \frac{x^3}{3} - \dots) = x + \frac{x^3}{3} + \dots$$

**结论**：结果和我们用除法算出来的前两项一模一样！
