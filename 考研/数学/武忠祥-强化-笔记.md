## 函数单调性与导数关系

### **区间单调性和导数**

- 导数符号 $\to$ 函数单调性
- 总结: 
  $f'(x)>0$推出严格增, $f'(x)\geq 0$ 推出严格增或单调不增, 要结合定义去精确得出
	- $f'(x)>0或<0$
		- 如果函数 $f(x)$ 在区间 $I$ 上**可导**，并且对 $I$ 内的**所有** $x$，都有 $f'(x) > 0$，那么 $f(x)$ 在区间 $I$ 上**严格单调增加**。
		- 同理，若 $f'(x) < 0$，则 $f(x)$ 在区间 $I$ 上**严格单调减少**。
	- $f'(x)\geq0或\leq 0$
		- 如果函数 $f(x)$ 在区间 $I$ 上**可导**，并且对 $I$ 内的**所有** $x$，都有 $f'(x) \ge 0$，那么 $f(x)$ 在区间 $I$ 上**单调不减或则严格增加**。
		- 同理，若 $f'(x) \le 0$，则 $f(x)$ 在区间 $I$ 上**单调不增或则严格减少**。

> [!info]
>  $f'(x) \ge 0$只能得到$f(x)$ 是**单调不减**或则**严格增加**, 这两个统称为**单调不减**.
>  
>  例如 $f(x)=x^3$ 在 $\mathbb{R}$ 上，其导数 $f'(x)=3x^2 \ge 0$，而函数本身是严格单调增加的。
>  
>  若要精确证明一个函数是严格单调增加:
>  1. 导数 $f'(x) > 0$
>  2. **单调性定义**$\forall x_2,x_1\in D\text{定义域}, \text{且}x_2>x_1,f\left( x_2 \right) -f\left( x_1 \right) >0\text{恒成立}$
>  3. 导数 $f'(x) \geq 0$ +
>     
>     **单调性定义**$\forall x_2,x_1\in D\text{定义域}, \text{且}x_2>x_1,f\left( x_2 \right) -f\left( x_1 \right) >0\text{恒成立}$
>     
>     证明。

## **函数奇偶性与导数关系**
### **结论**
- 原函数具有奇偶性$\to$导函数具有奇偶性, 与原函数相反
- 导数具有奇偶性(要记住原函数有无穷个)
	- 导数为奇函数$\to$所有原函数均为偶函数
	- 导数为偶函数$\to$只有1个原函数为奇函数:
	  **积分下限为 $0$ 的变上限积分函数** $\int_{0}^{x} f'(t) dt$


### **原函数 $f(x) \Rightarrow$ 导数 $f'(x)$**

这个方向的推导比较直接。

* **结论：** **原函数的奇偶性与导数的奇偶性通常相反。**
    * 如果 $f(x)$ 是**奇函数**且 $f'(x)$ 存在，则 $f'(x)$ 是**偶函数**。
    * 如果 $f(x)$ 是**偶函数**且 $f'(x)$ 存在，则 $f'(x)$ 是**奇函数**。

* **简要证明思路：**
    利用复合函数求导法则。
    1.  **若 $f(x)$ 为奇函数：** $f(-x) = -f(x)$。两边求导得 $f'(-x) \cdot (-1) = -f'(x) \implies f'(-x) = f'(x)$，即 $f'(x)$ 是偶函数。
    2.  **若 $f(x)$ 为偶函数：** $f(-x) = f(x)$。两边求导得 $f'(-x) \cdot (-1) = f'(x) \implies f'(-x) = -f'(x)$，即 $f'(x)$ 是奇函数。


### **导数 $f'(x) \Rightarrow$ 原函数 $F(x)$ （不定积分）**

这个方向的讨论需要利用**变上限积分函数**作为桥梁。

设 $F(x)$ 是 $f'(x)$ 的一个原函数，即 $F(x) = \int f'(x) dx$。我们知道 $F(x)$ 可以表示为 $G(x) + C$，其中 $G(x)$ 是一个特定的变上限积分（例如 $\int_{a}^{x} f'(t) dt$），$C$ 是任意常数。

#### $f'(x)$ 是**奇函数**

* **结论：** 如果 $f'(x)$ 是**奇函数**，那么它的**任何**原函数 $F(x)$ 都是**偶函数**。

* **简要证明：**
    1.  考虑变上限积分 $G(x) = \int_{a}^{x} f'(t) dt$。
    2.  可将 $G(x)$ 拆分为 $G(x) = \int_{a}^{0} f'(t) dt + \int_{0}^{x} f'(t) dt$。
    3.  其中，$\int_{a}^{0} f'(t) dt$ 是一个**定值常数** $C_0$（常数只会影响奇函数性, 不会影响偶函数性）。
    4.  关键在于 $\int_{0}^{x} f'(t) dt$。对其考察 $G_0(-x) = \int_{0}^{-x} f'(t) dt$。
    5.  利用换元法（令 $u = -t \implies dt = -du$），并利用 $f'(t)$ 是奇函数（$f'(-u) = -f'(u)$）：
        $G_0(-x) = \int_{0}^{x} f'(-u)(-du) = \int_{0}^{x} (-f'(u))(-du) = \int_{0}^{x} f'(u) du = G_0(x)$。
    6.  所以，$\int_{0}^{x} f'(t) dt$ 是一个**偶函数**。
    7.  因此，原函数 $F(x) = G_0(x) + C_0 + C$（仍然是偶函数加常数），最终 $F(x)$ 是**偶函数**。

#### $f'(x)$ 是**偶函数**

* **结论：** 如果 $f'(x)$ 是**偶函数**，那么它的原函数 $F(x)$：
    * 只有当常数 $C=0$ 时（即**积分下限为 $0$ 的变上限积分函数** $\int_{0}^{x} f'(t) dt$），原函数才是**奇函数**。
    * **一般情况下**（即 $C \ne 0$ 时，或积分下限 $a \ne 0$），原函数**既不是奇函数也不是偶函数**。

* **简要证明：**
    1.  同样考虑变上限积分 $G(x) = \int_{0}^{x} f'(t) dt$。
    2.  对其考察 $G_0(-x) = \int_{0}^{-x} f'(t) dt$。
    3.  利用换元法（令 $u = -t \implies dt = -du$），并利用 $f'(t)$ 是偶函数（$f'(-u) = f'(u)$）：
        $G_0(-x) = \int_{0}^{x} f'(-u)(-du) = \int_{0}^{x} f'(u)(-du) = -\int_{0}^{x} f'(u) du = -G_0(x)$。
    4.  所以，$\int_{0}^{x} f'(t) dt$ 是一个**奇函数**。
    5.  因此，原函数 $F(x) = G_0(x) + C$。
        * 当 $C=0$ 时，$F(x) = G_0(x)$，此时 $F(x)$ 是**奇函数**。
        * 当 $C \ne 0$ 时，$F(-x) = -G_0(x) + C$。这通常既不等于 $F(x)$ 也不等于 $-F(x)$，所以 $F(x)$ **一般既不是奇函数也不是偶函数**。


## **函数周期性与导数的关系**

### **结论**
- 如果函数 $f(x)$ 是周期函数，且其导数 $f'(x)$ 存在，那么 $f'(x)$ 也是周期函数。
- 如果 $f'(x)$ 是周期函数，且其在一个周期内的积分等于 $0$，那么它的原函数 $F(x)$ 具有周期性。

### **1 原函数 $f(x) \Rightarrow$ 导数 $f'(x)$**

这个方向的结论通常比较直接和普遍。

* **结论：** 如果函数 $f(x)$ 是周期函数，且其导数 $f'(x)$ 存在，那么 $f'(x)$ 也是周期函数。
* **证明：**
    设 $f(x)$ 是周期为 $T$ 的函数，即 $f(x+T) = f(x)$。

    对等式两边关于 $x$ 求导：

    $\frac{d}{dx}f(x+T) = \frac{d}{dx}f(x)$

    根据复合函数求导法则，左边为 $f'(x+T) \cdot \frac{d}{dx}(x+T) = f'(x+T) \cdot 1 = f'(x+T)$。

    所以，$f'(x+T) = f'(x)$。

    这证明了 $f'(x)$ 也是周期函数，且周期为 $T$（不一定是最小正周期）。

### 2 导数 $f'(x) \Rightarrow$ 原函数 $F(x)$

这个方向需要更严谨地讨论，因为导数具有周期性，其原函数不一定具有周期性。

* **结论：** 如果 $f'(x)$ 是周期函数，且其在一个周期内的积分等于 $0$，那么它的原函数 $F(x)$ 具有周期性。

* **严谨证明：**
    设 $f'(x)$ 是一个周期为 $T$ 的函数。
    考虑 $f'(x)$ 的一个原函数，比如变上限积分函数 $F(x) = \int_{a}^{x} f'(t) dt$（其中 $a$ 是某个常数）。

    我们来考察 $F(x+T)$：
    $F(x+T) = \int_{a}^{x+T} f'(t) dt$

    将积分拆分为：
    $F(x+T) = \int_{a}^{x} f'(t) dt + \int_{x}^{x+T} f'(t) dt$

    根据变上限积分的定义，$\int_{a}^{x} f'(t) dt$ 就是 $F(x)$。所以：
    $F(x+T) = F(x) + \int_{x}^{x+T} f'(t) dt$

    现在，关键在于处理 $\int_{x}^{x+T} f'(t) dt$ 这部分。我们需要证明**周期函数在一个周期内的积分值是相等的，无论从哪里开始积。**

    **【补充证明：周期函数在一个周期内的积分相等】**

    设 $g(x)$ 是一个周期为 $T$ 的函数，在 $[x, x+T]$ 上可积。我们要证明 $\int_{x}^{x+T} g(t) dt = \int_{0}^{T} g(t) dt$。

    证明步骤：
    1.  我们可以将 $\int_{x}^{x+T} g(t) dt$ 拆分成三部分：
        $\int_{x}^{x+T} g(t) dt = \int_{x}^{0} g(t) dt + \int_{0}^{T} g(t) dt + \int_{T}^{x+T} g(t) dt$

    2.  现在，我们专注于最右边的积分 $\int_{T}^{x+T} g(t) dt$。
        令变量替换 $u = t - T$。那么 $t = u + T$，且 $dt = du$。
        
        当 $t=T$ 时，$u=0$。
        
        当 $t=x+T$ 时，$u=x$。

    3.  代入积分中：
        $\int_{T}^{x+T} g(t) dt = \int_{0}^{x} g(u+T) du$
        
        由于 $g(x)$ 是周期为 $T$ 的函数，所以 $g(u+T) = g(u)$。
        
        因此，$\int_{0}^{x} g(u+T) du = \int_{0}^{x} g(u) du$。

    4.  将这个结果代回第 1 步的拆分式中：
        $\int_{x}^{x+T} g(t) dt = \int_{x}^{0} g(t) dt + \int_{0}^{T} g(t) dt + \int_{0}^{x} g(t) dt$

    5.  注意到 $\int_{x}^{0} g(t) dt = -\int_{0}^{x} g(t) dt$。所以：
        $\int_{x}^{x+T} g(t) dt = -\int_{0}^{x} g(t) dt + \int_{0}^{T} g(t) dt + \int_{0}^{x} g(t) dt$

    6.  前面的两项正好抵消，最终得到：
        $\int_{x}^{x+T} g(t) dt = \int_{0}^{T} g(t) dt$。
    至此，【补充证明】完毕。

    **回到原证明：**

    利用上述【补充证明】的结论，我们可以将 $\int_{x}^{x+T} f'(t) dt$ 替换为 $\int_{0}^{T} f'(t) dt$：
    $F(x+T) = F(x) + \int_{0}^{T} f'(t) dt$

    * **结论：**
        如果**导数 $f'(x)$ 在一个周期 $T$ 内的积分 $\int_{0}^{T} f'(t) dt$ 等于 $0$**，那么：
        $F(x+T) = F(x) + 0 = F(x)$。
        这证明了此时 $F(x)$ 具有周期性，且周期为 $T$。

* **总结：** 只有当导数 $f'(x)$ 的周期积分为 $0$ 时，其原函数 $F(x)$ 才具有周期性。如果这个周期积分不为 $0$，原函数 $F(x)$ 将会呈线性增长或下降趋势（例如 $F(x+T) = F(x) + C_1$，其中 $C_1 \neq 0$），因此不具有周期性。

### **1. 无穷大量 vs. 无界数列**

这是两个非常容易混淆，但有本质区别的概念。

#### **无穷大量 (Infinite Quantity / Infinitesimal Sequence)**

* **你的定义：** $\forall M>0, \exists N>0, \text{当}n>N\text{时}, |x_n|>M$ -> **完全正确！** 这是极限 $\underset{n\rightarrow\infty}{\lim}|x_n| = +\infty$ 的标准定义。

* **你的理解：** “当n>N时的所有序列全部为无穷量” -> 核心思想是对的。更精确的说法是：**从某一项 N 之后，所有的项都“跑出”了任意大的范围 M之外，再也没回来过**。它描述的是一种“**一去不复返**”的最终趋势。

#### **无界数列 (Unbounded Sequence)**

* **你的定义：** $\forall M>0, \exists N>0, \text{使得}|x_N|>M$ -> **完全正确！**

* **你的理解：** “趋近于无穷的过程中, 只有个别值为无穷量” -> 这个理解也抓住了精髓。更精确的说法是：**无论你把范围 M 画多大，数列里总能“蹦”出去一个项给你看**。但它不保证后面的项也都在外面。它可能蹦出去一下，又掉回来了。

#### **核心区别与示例**

为了让你看得更清楚，我们来看一个关键的例子：
$$x_n = \begin{cases} n, & \text{当n为偶数} \\ 1, & \text{当n为奇数} \end{cases}$$
这个数列是 `{1, 2, 1, 4, 1, 6, 1, 8, ...}`

1.  **这个数列是“无界”的吗？**
    * **是的**。因为无论你给多大的`M`（比如1亿），我总能找到一个偶数项 $x_N$（比如 $N=2亿$）比`M`大，满足 $|x_N|>M$。

2.  **这个数列是“无穷大量”吗？**
    * **不是**。因为它不满足“从某一项之后**所有**项都大于M”。比如你取`M=100`，虽然 $x_{100}=100, x_{102}=102, \dots$ 满足条件，但是它后面的奇数项 $x_{101}=1, x_{103}=1, \dots$ 又掉回了`M`的范围内。它在“出走”和“回家”之间反复横跳。

**结论：** **无穷大量一定是无界数列，但无界数列不一定是无穷大量。** “无穷大量”的要求比“无界”要严格得多。

### **情况一：在“有限区间”上的关系**

我们先来解决你的第一个问题，这也是一个非常重要的定理。

* **你的问题：** $f'(x)$ 在 $(0,1)$ 内有界，则 $f(x)$ 在 $(0,1)$ 内有界，这是为什么？如何证明？

* **命题陈述：** 若函数 $f(x)$ 在有限开区间 $(a,b)$上可导，且其导函数 $f'(x)$ 在 $(a,b)$上有界，则 $f(x)$ 也在 $(a,b)$上有界。

* **证明（核心武器：拉格朗日中值定理）**
    1.  **前提：** $f'(x)$ 在 $(0,1)$ 内有界。根据定义，这意味着存在一个正数 `M`，使得对于所有 $x \in (0,1)$，都有 $|f'(x)| \le M$。
    2.  **构造：** 我们在区间 $(0,1)$ 中任取一个固定点，比如 $x_0 = \frac{1}{2}$。现在，对于区间内任意一个其他的点 `x`，我们来考察区间 $[x_0, x]$ (或 $[x, x_0]$)。
    3.  **应用中值定理：** 根据拉格朗日中值定理，在 `x` 和 `x₀` 之间，必然存在一个点 `ξ`，使得：
        $$f(x) - f(x_0) = f'(\xi)(x - x_0)$$
    4.  **取绝对值并放缩：**
        $$|f(x) - f(x_0)| = |f'(\xi)| \cdot |x - x_0|$$
        * 因为 `ξ` 在 `x` 和 `x₀` 之间，所以 `ξ` 也在 $(0,1)$ 内，因此 $|f'(\xi)| \le M$。
        * 因为 `x` 和 `x₀` 都在 $(0,1)$ 内，所以它们之间的距离 $|x - x_0|$ 必然小于整个区间的长度1，即 $|x - x_0| < 1$。
        * 所以，我们可以得到：$|f(x) - f(x_0)| \le M \cdot 1 = M$。
    5.  **利用绝对值不等式：**
        我们知道 $|f(x)| - |f(x_0)| \le |f(x) - f(x_0)|$。
        所以，$|f(x)| - |f(x_0)| \le M$，变形即：
        $$|f(x)| \le M + |f(x_0)|$$
    6.  **得出结论：**
        因为 $x_0$ 是一个固定点，所以 $f(x_0)$ 是一个常数，`M` 也是一个常数。那么 $M + |f(x_0)|$ 就是一个有限的正常数。我们令 $K = M + |f(x_0)|$，就证明了对于区间内任意的`x`，都有 $|f(x)| \le K$。
        根据定义，函数 $f(x)$ 在 $(0,1)$ 内有界。证明完毕。

* **反过来可以吗？** 即：在有限区间上，$f(x)$有界能推出$f'(x)$有界吗？
    * **答案是：不能。**
    * **经典反例：** $f(x) = \sqrt{x}$ 在区间 $(0,1)$ 上。
        * $f(x)$ 显然有界（值域在(0,1)上）。
        * 但它的导数 $f'(x) = \frac{1}{2\sqrt{x}}$。当 $x \to 0^+$ 时，$f'(x) \to +\infty$。所以导数在 $(0,1)$ 内是**无界的**。

### **问题的核心：`ε` 和 `n` 的“身份”不能混淆**

你问“为什么C,D不成立, ε不能取1/n吗?”，这个问题直接就打在了这道题的七寸上，也是极限定义里最经典、最核心的“认知陷阱”。

我们再来看一遍极限的定义：
> $\forall \varepsilon > 0, \exists N, \text{当 } n > N \text{ 时}, |a_n - a| < \varepsilon$

在这个定义中，各个字母扮演的角色是固定的：
1.  **`ε` (epsilon)**：它是一个**固定的、预先给定的、任意小的正数**。它不随`n`变化。你可以把它想象成你围绕着极限值`a`画的一对“栏杆”，形成了一个宽度为`2ε`的“安全通道”。
2.  **`N`**：它是一个**依赖于`ε`的整数**。你的“安全通道”画得越窄（`ε`越小），你可能需要往数列后面走得越远（`N`越大），才能找到那个点，保证从那之后的所有项都在通道内。
3.  **`n`**：它是**在`N`确定之后，满足`n>N`的任意整数**。

**核心错误：**
“取`ε=1/n`”这个想法，从逻辑上就混淆了它们的身份。`ε`必须是一个**与`n`无关的、固定的正数**，而`1/n`是一个随着`n`变化的**变量**。我们不能用一个变量（`1/n`）去定义另一个变量（`aₙ`）的范围。

极限定义保证的是，对于一个**固定的**`ε`（比如0.001），`aₙ`的尾巴会掉进`(a-0.001, a+0.001)`里。但它并**不保证**`a₁₀₀₀`就一定在`(a-1/1000, a+1/1000)`里。

---
### **用“反例”来证明 C 和 D 的错误**

为了证明C和D不一定成立，我们只需要各举一个反例就行了。

#### **对于选项 D: $a_n < a + \frac{1}{n}$**

* 我们来看一个最简单的数列：$a_n = a + \frac{1}{n}$。
* 这个数列的极限显然是 $\underset{n\rightarrow \infty}{\lim}a_n = a$。
* 选项D说，当`n`充分大时，应该有 $a_n < a + \frac{1}{n}$。
* 但对于我们这个数列，实际上 $a_n$ **恒等于** $a + \frac{1}{n}$。它俩是**相等**的，并不满足**严格小于**。
* 所以，我们找到了一个满足题目条件但D不成立的例子。因此，选项D是**错误的**。

#### **对于选项 C: $a_n > a - \frac{1}{n}$**

* 同理，我们看另一个数列：$a_n = a - \frac{1}{n}$。
* 这个数列的极限也是 `a`。
* 选项C说，当`n`充分大时，应该有 $a_n > a - \frac{1}{n}$。
* 但对于我们这个数列，实际上 $a_n$ **恒等于** $a - \frac{1}{n}$。它俩也是**相等**的，不满足**严格大于**。
* 所以，选项C也是**错误的**。

    $$0 \le |a_{N+m}| < b^{m-1}|a_{N+1}|$$
    这个不等式是夹逼定理的完美应用场景。

* **分析“夹逼”的两端：**
    1.  **左边**：`0`，它的极限当然是`0`。
    2.  **右边**：$b^{m-1}|a_{N+1}|$。我们来分析当 $m \to \infty$ 时它的极限。
        * 这里的`b`是我们选定的一个常数，满足 $0 \le |a| < b < 1$。
        * 这里的`N`是一个已经确定的整数，所以 $|a_{N+1}|$ 也是一个**固定的常数**，我们记作 `C`。
        * 所以右边就是 $C \cdot b^{m-1}$。这是一个典型的**等比数列**，它的公比是`b`，因为`|b|<1`，所以我们知道它的极限是0：
            $$\underset{m\rightarrow\infty}{\lim} (C \cdot b^{m-1}) = C \cdot \underset{m\rightarrow\infty}{\lim} b^{m-1} = C \cdot 0 = 0$$

* **得出结论：**
    既然 $|a_{N+m}|$ 被夹在两个都趋向于0的“面包”之间，根据**夹逼定理**，它的极限也必然是0。
    而 $m \to \infty$ 等价于 $n = N+m \to \infty$，所以我们就证明了 $\underset{n\rightarrow\infty}{\lim}|a_n|=0$。

---

#### **2. 用极限的 ε-N 定义来严格理解**

现在，我们来满足你的要求，完全抛开夹逼定理这个“快捷方式”，只用最原始的 **ε-N 定义**来证明这个结论。

* **我们的目标：**
    我们要证明 $\underset{n\rightarrow\infty}{\lim}|a_n|=0$。也就是说，要证明：
    对于任意给定的 $\varepsilon > 0$，我们都能找到一个最终的 $N_{final}$，使得当 $n > N_{final}$ 时，恒有 $|a_n| < \varepsilon$。

* **我们已有的工具：**
    从证明的前半部分，我们已经知道：存在一个`N`和一个常数`b` (0<b<1)，使得当 $n = N+m > N$ 时，有不等式：
    $$|a_n| < b^{m-1}|a_{N+1}|$$

* **推导过程：**
    1.  我们的任务是让 $|a_n| < \varepsilon$。利用上面的不等式，我们只需要能找到一个方法，让 $b^{m-1}|a_{N+1}| < \varepsilon$ 就可以了。
    2.  我们来解这个关于`m`的不等式（这里我们假设 $|a_{N+1}| \neq 0$，如果它等于0，那么后面的所有项都是0，结论显然成立）。
        $$b^{m-1} < \frac{\varepsilon}{|a_{N+1}|}$$
    3.  为了把指数`m-1`解出来，我们两边取对数。因为 $0<b<1$，所以对数函数 $\log_b$ 是一个**减函数**，取对数时**不等号要反向**：
        $$m-1 > \log_b\left(\frac{\varepsilon}{|a_{N+1}|}\right)$$       $$m > 1 + \log_b\left(\frac{\varepsilon}{|a_{N+1}|}\right)$$
    4.  这一步非常关键！它告诉我们：只要`m`大到超过 $1 + \log_b\left(\frac{\varepsilon}{|a_{N+1}|}\right)$ 这个数，就能保证 $|a_n|<\varepsilon$。
    5.  现在我们把 `m` 换回 `n`。因为 $m = n - N$，所以我们需要的条件是：
        $$n - N > 1 + \log_b\left(\frac{\varepsilon}{|a_{N+1}|}\right)$$       $$n > N + 1 + \log_b\left(\frac{\varepsilon}{|a_{N+1}|}\right)$$
    6.  我们就找到了我们要的那个 $N_{final}$！我们令
        $$N_{final} = N + 1 + \log_b\left(\frac{\varepsilon}{|a_{N+1}|}\right)$$
        对于任意给定的`ε`，这个 $N_{final}$ 是一个确定的数（因为`N`, `b`, `a_{N+1}`都是已经确定的常数）。
    7.  这样，我们就严格地证明了：对于任意 $\varepsilon>0$，都存在这样一个 $N_{final}$，使得当 $n > N_{final}$ 时，恒有 $|a_n| < \varepsilon$。极限的定义被满足了！

---

#### **问题二：关于无穷估阶的其他“武器”**

你这个问题问得非常好，一个厉害的解题者，脑子里都有一个丰富的“武器库”。除了我们已经聊过的**比值法**、**积分估算法**和**斯特林公式**，你的武器库里还可以增加以下几件利器：

**武器一：斯托尔兹-切萨罗定理 (Stolz–Cesàro Theorem)**
* **外号：** “**数列版的洛必达法则**”，专门处理“$\frac{\infty}{\infty}$”型的数列极限。
* **内容：** 如果数列 $\{y_n\}$ 严格单调递增且趋于 $+\infty$，且极限 $\underset{n\rightarrow\infty}{\lim}\frac{x_{n+1}-x_n}{y_{n+1}-y_n}=L$ 存在，那么 $\underset{n\rightarrow\infty}{\lim}\frac{x_n}{y_n}=L$。
* **应用场景：** 对付分子或分母是“求和”形式的极限有奇效。比如求 $\underset{n\rightarrow\infty}{\lim}\frac{1^2+2^2+\dots+n^2}{n^3}$。
    * 令 $x_n = \sum k^2, y_n = n^3$。
    * 求 $\frac{x_{n+1}-x_n}{y_{n+1}-y_n} = \frac{(n+1)^2}{(n+1)^3-n^3} = \frac{n^2+2n+1}{3n^2+3n+1}$，这个极限是`1/3`。
    * 所以原极限就是`1/3`。

**武器二：利用已知的等价无穷大/小**
* **思路：** 就像在$x \to 0$时我们用 $x$ 替换 $\sin x$ 一样，在 $n \to \infty$ 时，我们也可以用更简单的形式来替换复杂的部分。
* **常用等价：**
    * **调和级数：** $1+\frac{1}{2}+\frac{1}{3}+\dots+\frac{1}{n} \sim \ln n$
    * **p-级数的部分和：** $\sum_{k=1}^n \frac{1}{k^p} \to \text{一个常数}$ (当$p>1$时)
    * **多项式：** $an^k+bn^{k-1}+\dots \sim an^k$ (抓大头)
    * **斯特林公式本身也是一种等价：** $n! \sim \sqrt{2\pi n}(n/e)^n$

**武器三：函数增长速度的层次**
* **外号：** “**增长速度鄙视链**”。这是一个定性的快速判断工具。
* **内容：** 当 $n \to \infty$ 时，不同类型函数的增长速度有严格的等级之分。
    $$(\ln n)^a \ll n^b \ll c^n \ll n! \ll n^n$$
    （其中 $a>0, b>0, c>1$）
    `<<` 意为“远远小于”。
* **应用场景：** 快速判断一个复杂表达式中谁是“老大”，谁可以被忽略。比如我们昨天那个 $\sqrt{2\pi n} \left(\frac{2}{e}\right)^n$ 的极限，就是因为指数函数 $(\frac{2}{e})^n$ 比多项式函数 $\sqrt{n}$ “厉害”得多，所以极限由指数函数决定，为0。

#### **问题一：寻找函数不可导点的通用框架是什么？**

* **解答：**
    我们总结出了一套“**三步排查法**”，用于系统地寻找一个函数`f(x)`的所有“嫌疑”不可导点。

    1.  **第一步：排查“断点”（不连续的点）**
        * **原理：** 可导必连续，故**不连续的点必然不可导**。
        * **对象：** 分段函数的分段点、分式函数分母为0的点等。

    2.  **第二步：排查“尖点”（左右导数存在但不相等）**
        * **原理：** 函数在该点连续，但图像有尖锐转折。
        * **对象：** 主要由**绝对值函数**`|g(x)|`在`g(x)=0`的点产生；或某些在分段点连续但左右导数不等的分段函数。

    3.  **第三步：排查“无穷导数点”（左右导数至少有一个不存在）**
        * **原理：** 函数在该点连续，但图像的切线是**垂直的**。
        * **对象：** 主要由**根式函数**产生，例如 $f(x)=\sqrt[3]{x}$ 在 $x=0$ 点。

---
#### **问题二：对于“尖点”和“无穷导数点”，有没有比定义法更快捷的等价判断方法？**

* **解答：**
    有。我们有两种快捷的“武器”来处理第二类和第三类嫌疑点。

    1.  **“尖点”的快捷判断法 (`h(a)=0`法则):**
        * 对于形如 $f(x) = h(x) \cdot |x-a|$ 的函数，其在`x=a`点的可导性取决于“抹平因子”`h(x)`。
        * **若 $h(a) \neq 0$**，则尖点无法抹平，函数在`a`点**不可导**。
        * **若 $h(a) = 0$**，则尖点被抹平，函数在`a`点**可导**，且导数通常为0。

    2.  **“无穷导数点”的快捷判断法（导数极限定理）:**
        * 若`f(x)`在`x₀`点**连续**，我们可以去计算导函数在`x₀`的极限 $\underset{x\rightarrow x_0}{\lim}f'(x)$。
        * **若极限为 $\infty$ 或 $-\infty$**，则函数在`x₀`点有垂直切线，**不可导**。
        * **若极限为有限数`L`**，则函数在`x₀`点**可导**，且 $f'(x_0)=L$。

---
#### **问题三：`导数存在` 与 `导函数极限存在` 是等价的吗？**

* **解答：**
    **不是等价关系，是单向推论。**

    1.  **正确方向 `⇐`**：
        若 $\underset{x\rightarrow x_0}{\lim}f'(x) = L$（L为有限数）且`f(x)`在`x₀`连续，则 $f'(x_0)$ **存在**且等于`L`。

    2.  **错误方向 `⇒`**：
        $f'(x_0)$ **存在**，并**不能**保证 $\underset{x\rightarrow x_0}{\lim}f'(x)$ 存在。
        * **经典反例：** $f(x) = x^2\sin\frac{1}{x}$ (当$x=0$时为0)。
        * 这个函数在 $x=0$ 点的导数 $f'(0)$ 存在且为0，但它的导函数 $f'(x) = 2x\sin\frac{1}{x} - \cos\frac{1}{x}$ 在 $x \to 0$ 时因振荡而极限不存在。
    * **结论：** 函数在一点可导，**不意味着**导函数在该点连续。

---
#### **问题四：如果“导函数极限法”这个快捷方法算出的极限不存在，该怎么办？**

* **解答：**
    “导函数极限法”是一个强大的**快速诊断工具**，但它有一个“失灵”的情况。

    * **当 $\underset{x\rightarrow x_0}{\lim}f'(x)$ 的极限是有限数、无穷大、或左右极限不等的有限数时**，该方法均能给出**确切**的结论。
    * **当且仅当 $\underset{x\rightarrow x_0}{\lim}f'(x)$ 因“振荡”而不存在时**（如上面的反例），此方法**失效**，我们无法对 $f'(x_0)$ 的存在性做出任何判断。
    * 在这种“疑难杂症”下，我们必须回归到最根本的“最终武器”——**导数的定义** $\underset{x\rightarrow x_0}{\lim}\frac{f(x)-f(x_0)}{x-x_0}$ 来进行最终的审判。

    * **对于函数极限 (ε-δ)：**
        * **命题：** 若 `ε₂ < ε₁`，则对`ε₂`有效的`δ`集合，是对`ε₁`有效`δ`集合的**子集**。
        * **证明：** 根据极限定义，若`δ₂`对`ε₂`有效（即在`δ₂`范围内，误差小于`ε₂`），那么由于`ε₂ < ε₁`，误差自然也小于`ε₁`。所以`δ₂`也对`ε₁`有效。因此，适用于更严苛条件的`δ`集合，必然被适用于更宽松条件的`δ`集合所包含。

    * **对于数列极限 (ε-N)：**
        * **命题：** 若 `ε₂ < ε₁`，则满足`ε₂`的最小分界点 $N_{min}(\varepsilon_2)$，一定大于或等于满足`ε₁`的最小分界点 $N_{min}(\varepsilon_1)$。
        * **证明：** 根据极限定义，若从`N₂`项之后，所有项都满足了更严格的误差`ε₂`，那么它们自然也满足了更宽松的误差`ε₁`。所以，$N_2$ 也是一个对`ε₁`有效的`N`。而`ε₁`所要求的最小的那个`N`（即 $N_{min}(\varepsilon_1)$），必然小于或等于任何一个对`ε₁`有效的`N`（包括$N_2$）。因此 $N_{min}(\varepsilon_1) \le N_2$。这个逻辑对所有满足`ε₂`的`N`都成立，包括最小的那个 $N_{min}(\varepsilon_2)$。故 $N_{min}(\varepsilon_1) \le N_{min}(\varepsilon_2)$。
