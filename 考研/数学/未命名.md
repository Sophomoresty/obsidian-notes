### **1. 两个题目之间的联系是什么？**

它们的联系就在于**核心解题思想**，我们可以称之为“**先定性，后定量**”的两步走策略：

1.  **第一步（定性分析）：** 通过**求导**，分析导函数`F'(x)`的符号，找到函数的**单调性**，并确定**极值点的位置**（比如`x=1`）。在这一步，我们完全**不用去计算那个复杂的积分本身**。

2.  **第二步（定量计算）：** 在确定了唯一的极值点（比如`x=x_ext`）之后，我们再回头去**计算或估算**在**这一个特定点**的函数值 `F(x_ext)`。

### **2. 用“两步走”策略解决第一题**

**原题：** 求 $F(x) = \int_x^{x+1}{|t(t^2-1)|}dt$ 的最小值。

#### **第一步：定性分析——求导找极值点**

你感觉“去绝对值很麻烦”，这是对的。但是，我们求导的时候，可以**先不去管绝对值内部的具体表达式**，而是利用变上限积分求导的基础公式。

令被积函数为 $h(t) = |t(t^2-1)|$。
根据公式 $\left(\int_{\varphi(x)}^{\Psi(x)} f(t)dt\right)' = f(\Psi(x))\Psi'(x) - f(\varphi(x))\varphi'(x)$，我们有：
$$F'(x) = h(x+1) \cdot (x+1)' - h(x) \cdot (x)'$$$$F'(x) = |(x+1)((x+1)^2-1)| - |x(x^2-1)|$$$$F'(x) = |(x+1)(x^2+2x)| - |x(x-1)(x+1)|$$
$$F'(x) = |x(x+1)(x+2)| - |x(x-1)(x+1)|$$

现在，我们令 $F'(x)=0$ 来找驻点：
$$|x(x+1)(x+2)| = |x(x-1)(x+1)|$$在 $x \neq 0, x \neq -1$ 的情况下，两边可以约去 $|x(x+1)|$，得到：$$|x+2| = |x-1|$$这个方程意味着`x`到`-2`的距离等于`x`到`1`的距离。在数轴上，这两个点的中点就是解：$$x = \frac{-2+1}{2} = -\frac{1}{2}$$
现在我们来分析 $F'(x)$ 的符号，它取决于 $g(x) = |x+2| - |x-1|$ 的符号。
* 当 $x > -1/2$ 时，$x$离`1`更近，所以 $|x-1| < |x+2|$，$g(x) > 0$，$F'(x) > 0$，函数单调递增。
* 当 $x < -1/2$ 时，$x$离`-2`更近，所以 $|x+2| < |x-1|$，$g(x) < 0$，$F'(x) < 0$，函数单调递减。

因此，$F(x)$ 在 $x = -1/2$ 处取得**唯一的极小值**，这个极小值也就是**最小值**。

#### **第二步：定量计算——求 $F(-1/2)$ 的值**

现在，我们已经找到了最小值点 $x = -1/2$。我们只需要计算这**一个**特定点的积分值就可以了，这就大大简化了问题！
$$F\left(-\frac{1}{2}\right) = \int_{-1/2}^{1/2} |t(t^2-1)| dt = \int_{-1/2}^{1/2} |t(t-1)(t+1)| dt$$
我们来分析被积函数 $h(t) = |t(t^2-1)|$：
* 这是一个**偶函数**，因为 $h(-t) = |-t((-t)^2-1)| = |-t(t^2-1)| = |t(t^2-1)| = h(t)$。
* 积分区间 `[-1/2, 1/2]` 关于原点对称。
* 所以，我们可以利用偶函数积分的性质：
    $$F\left(-\frac{1}{2}\right) = 2 \int_0^{1/2} |t(t^2-1)| dt$$
* 在积分区间 `[0, 1/2]` 内，$t \ge 0$, $t-1 < 0$, $t+1 > 0$，所以 $t(t^2-1) \le 0$。
* 因此，$|t(t^2-1)| = -(t^3-t) = t - t^3$。
* 积分变成了我们非常熟悉的多项式积分：
    $$F\left(-\frac{1}{2}\right) = 2 \int_0^{1/2} (t-t^3) dt = 2 \left[\frac{t^2}{2} - \frac{t^4}{4}\right]_0^{1/2}$$   $$= 2 \left( \left(\frac{(1/2)^2}{2} - \frac{(1/2)^4}{4}\right) - 0 \right) = 2 \left( \frac{1/4}{2} - \frac{1/16}{4} \right)$$   $$= 2 \left( \frac{1}{8} - \frac{1}{64} \right) = 2 \left( \frac{8-1}{64} \right) = 2 \cdot \frac{7}{64} = \frac{7}{32}$$
**最终答案就是 $\frac{7}{32}$**。
