## 题目
现有5个操作A、B、C、D和E, 操作C必须在A和B完成后执行, 操作E必须在C和D完成后执行, 请使用信号量的Wait()、signal()操作(P、V操作)描述上述操作之间的同步关系, 并说明所用信号量及其初值.
解:

每个操作1个进程
```c++
semaphore t_ac=0;
semaphore t_bc=0;
semaphore t_ce=0;
semaphore t_de=0;

P_A(){
	while(1){
		操作A;
		signal(t_ac);
	}
}
P_B(){
	while(1){
		操作B;
		signal(t_bc);
	}

}
P_C(){
	while(1){
		wait(t_ac);
		wait(t_bc);
		操作C;
		signal(t_ce)
	}
}
P_D(){
	while(1){
		操作D;
		signal(t_de);
	}
}
P_E(){
	while(1){
		wait(t_ce);
		wait(t_de);
		操作E;
	}
}
```
