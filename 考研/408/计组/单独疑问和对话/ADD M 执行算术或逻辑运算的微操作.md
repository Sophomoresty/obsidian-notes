
微操作左边的数除了立即数, 都必须加括号

| 时序  | 微操作                                             | 控制信号                         | 含义                                                                                                                                                  |
| --- | ----------------------------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Ad(IR)->Bus->MAR                                | IRout,MARin                  | IR 中的地址码通过 cpu 内部总线 写入到 MAR                                                                                                                         |
| 2   | M(MAr)->外部数据总线->MDR                             | MemR, MARout, MDREin         | CU 发出可读的控制信号给主存,<br>MAR 把地址通过地址总线发给主存,<br>主存取出内容通过外部数据总线写给 MDR                                                                                      |
| 3   | (MDR)->Bus->Y                                   | MDRout, Yin                  | MDR 把操作数写入暂存寄存器 Y, 该操作数为加数,被加数提前写入 ACC 了, 为什么要暂存.因为目前的 cpu 内部总线只有1条, 而加法需要输入两个信号, 所以需要提前保存1个数据到 Y, Y 通过内部线路把信号输入给 ALU, ACC 通过 cpu 内部总线把另一个信号输入给 ALU |
| 4   | (ACC)->Bus->ALU;<br>(Y)->专用线路->ALU;<br>(ALU)->Z | ACCout,Yout,ALUin,ALUout,Zin | ACC 和 Y 把内容给 ALU, ALU 计算后结果给暂存寄存器 Z                                                                                                                 |
| 5   | (Z)->ACC                                        | Zout,ACCin                   | 暂存寄存器把结果输入给 ACC                                                                                                                                     |


### **核心理解确认：**

你的核心理解是：**为了解决单总线结构下 ALU 需要两个输入的问题，引入了暂存寄存器 `Y`**。这个理解是**非常准确且关键的**！这正是单总线 CPU 数据通路设计中的一个典型策略。

### **微操作步骤分析与优化：**

#### **前提：** 假设这是一条 `ADD M` 这样的指令（`ACC = ACC + M(地址)`），并且 CPU 内部只有一条总线。

| 时序    | 微操作                                                                                                     | 控制信号                                                            | 含义                                                                                                                                                                            |
| :---- | :------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1** | `Ad(IR) -> Bus -> MAR`                                                                                  | `IRout (Ad)`, `MARin`                                           | **IR 中的地址码 (`Ad(IR)`)** 通过 CPU 内部总线 写入到 MAR。这个地址码是**操作数的地址**。                                                                                                                 |
| **2** | `M(MAR) -> 外部数据总线 -> MDR`                                                                               | `MemR`, `MARout`, `MDREin`                                      | CU 发出读内存 (`MemR`) 的控制信号给主存。<br>`MAR` 把地址通过**地址总线**发给主存（`MARout` 信号激活 MAR 到地址总线）。<br>主存根据地址取出内容（即操作数），通过**外部数据总线**写入到 `MDR` ( `MDRin` 信号激活 MDR 接收数据)。<br>                      |
| **3** | `(MDR) -> Bus -> Y`                                                                                     | `MDRout`, `Yin`                                                 | `MDR` 中的**操作数**（作为加数）通过 CPU 内部总线写入**暂存寄存器 `Y`**。这个操作数需要被暂存，因为目前的 CPU 内部总线只有一条，而 `ALU` 需要两个输入（另一个是 `ACC` 的内容），它们无法同时通过同一条总线输入 `ALU`。                                           |
| **4** | `(ACC) -> Bus -> ALU_Input1` (通常是 ALU 的一个输入端)<br>`(Y) -> ALU_Input2` (通常是 ALU 的另一个输入端)<br>`ALUout -> Z` | `ACCout`, `Yout`, `ALUin`, ` ALU_Op_Code `, ` ALUout `, ` Zin ` | `ACC` 的内容通过内部总线送给 `ALU` 的一个输入端。<br>`Y` 的内容通过**专用线路**（或在另一个时钟周期内，通过总线）送给 `ALU` 的另一个输入端。<br>`ALU` 执行运算（由 `ALU_Op_Code` 控制，如 ADD）。<br>`ALU` 计算后的结果从 `ALUout` 输出，送入**暂存寄存器 `Z`**。 |
| **5** | `(Z) -> Bus -> ACC`                                                                                     | `Zout`, `ACCin`                                                 | `Z` 寄存器中的**最终结果**通过内部总线写入 `ACC` (累加器)。                                                                                                                                        |

### **一点点细微的优化：**

  * **时序 4 中 `ALU` 输入**：通常 `ALU` 会有 A、B 两个输入端，所以是 `ALU_A_in`, `ALU_B_in` 这样的信号。你的 `ALUin` 也可以理解为总体的输入使能。
  * **时序 4 的多操作并行性**：`(ACC) -> Bus` 和 `(Y) -> ALU` 可以尝试在同一个时序点完成，这取决于总线设计和专用线路是否存在。如果 `Y` 也是通过总线，那么时序 3 和时序 4 可能需要更精细的拆分或使用多周期。但你的设计是为了**单总线**而进行的，所以分时发送到 ALU 输入是合理的。
