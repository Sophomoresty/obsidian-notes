### 💡 破题逻辑：为什么可以优化？

你的暴力解法里，内层循环 `j` 从 `i` 跑到 `n-1`，目的是为了找 $A[j]$ 谁跟 $A[i]$ 乘起来最大。

我们来分析一下数学性质：

1.  如果 $A[i]$ 是 **正数**：我们要想乘积最大，就要找 $i$ 后面（包括 $i$ 自己）的 **最大值**。
2.  如果 $A[i]$ 是 **负数**：我们要想乘积最大（负负得正），就要找 $i$ 后面（包括 $i$ 自己）的 **最小值**（绝对值最大的负数）。
3.  如果 $A[i]$ 是 **0**：乘谁都是 0，结果就是 0。

**核心发现：**
对于每个 $i$，我们只需要知道它身后（后缀区间 $A[i \dots n-1]$）里的 **最大值 (`max_val`)** 和 **最小值 (`min_val`)** 就可以了。

如果我们**从后往前**遍历数组，这两个值是可以一边走一边维护的，完全不需要每次都回头重新找一遍！

-----

### 📝 标准答案模板

#### (1) 算法的基本设计思想

算法采用 **从后向前（逆向）遍历** 的策略，通过一次遍历即可完成计算，将时间复杂度从 $O(n^2)$ 降低到 $O(n)$。

具体步骤如下：

1.  维护两个变量 `suffMax` 和 `suffMin`，分别记录当前位置 `i` 及其之后所有元素中的 **最大值** 和 **最小值**。
2.  初始时（最右端），令 `suffMax` 和 `suffMin` 均为 `A[n-1]`。
3.  从 `i = n-1` 开始倒序遍历至 `0`。对于每个 `A[i]`：
      * 更新当前后缀范围内的最大值 `suffMax` 和最小值 `suffMin`。
      * 计算 `A[i] * suffMax` 和 `A[i] * suffMin`，取两者中的较大值作为结果存入 `res[i]`。
      * （原理：若 `A[i]` 为正，乘最大值可能最大；若 `A[i]` 为负，乘最小值可能得最大正数）。

#### (2) 算法代码描述 (C++)

```cpp
#include <algorithm> // 为了使用 std::max 和 std::min
#include <climits>   // 如果需要 INT_MIN

void calMulMax(int A[], int res[], int n) {
    if (n <= 0) return;

    // 初始化后缀最大值和最小值
    // 刚开始在最后一位，最大最小都是它自己
    int suffMax = A[n - 1];
    int suffMin = A[n - 1];

    // 从后往前遍历
    for (int i = n - 1; i >= 0; i--) {
        // 1. 维护当前后缀区间的最大值和最小值
        if (A[i] > suffMax) {
            suffMax = A[i];
        }
        if (A[i] < suffMin) {
            suffMin = A[i];
        }

        // 2. 计算最大乘积
        // 情况A: A[i]是正数，乘以suffMax最大
        // 情况B: A[i]是负数，乘以suffMin（可能是负数）得正最大
        // 直接计算两种可能并取大者
        long long maxProd = (long long)A[i] * suffMax;
        long long minProd = (long long)A[i] * suffMin;

        if (maxProd > minProd) {
            res[i] = (int)maxProd;
        } else {
            res[i] = (int)minProd;
        }
    }
}
```

*(注：代码中为了防止乘积溢出使用了 `long long` 暂存，如果是考研手写，直接用 `int` 比较通常也不扣分，除非题目特意强调了大数)*

#### (3) 算法复杂度分析

  * **时间复杂度：** **$O(n)$**。
      * 算法只需要对数组进行一次逆向扫描，每个元素处理常数次操作。
  * **空间复杂度：** **$O(1)$**。
      * 仅使用了 `suffMax`, `suffMin` 等几个辅助变量，不随数据规模 $n$ 增长（`res` 数组为题目要求的输出空间，不计入辅助空间）。
