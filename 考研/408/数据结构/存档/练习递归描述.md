# 规范

**步骤1: 定义函数签名与规约**

- 函数签名

	- 输入:
	- 输出:
- 函数规约
	- 前置条件: 调用者必须保证为真的条件
	- 后置条件: 执行完毕后必须为真的结果

**步骤2 识别并实现基本情况** 

分析问题域，找出其最简实例。这些实例的解是平凡的 (trivial)，可以直接给出，无需进一步分解。这是递归的终止锚点。

步骤3 设计递归步骤

1. 问题分解: 将当前问题P分解为1个或多个与P结构相同, 但规模更小的子问题P'
2. 递归调用: 基于函数规约, 假设对子问题P'的递归调用f(p')能够返回正确的结果.此假设在形式化方法中被称为归纳假设

**步骤4  组合子问题解**

利用步骤3中递归调用返回的子问题的解, 通过附加的计算和逻辑操作, 构造出原问题P的最终阶, 并确保该解满足函数规约中定义的后置条件


## 反转链表

**步骤1  函数签名与规约**
- 签名:`reverseList(LisNode *head)`
- 规约:
	- 前置条件: head是一个指向合法链表头结点的指针, 该链表以nullptr结尾
	- 后置条件: 函数返回一个指向新头结点的指针, 该新头结点是原链表反转后的结果. 原链表的节点结构被就地修改

**步骤2 识别并实现基本情况(归纳验证, 即能处理n=1, 或则说基本情况的问题)**
- 分析: 最简的链表实例是空链表或只包含一个节点的链表
- 实现:
```c++
if (head==nullptr || head->next==nullptr){
return head;
}
```
