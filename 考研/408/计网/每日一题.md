0.0.0.0
二进制第1位固定为0, 第1个点分十进制位是0-127, A类地址
二进制第1-2位固定为10, 第1个点分十进制位128-191, B类地址
二进制第1-3位固定位110, 第1个点分十进制位192-223, C类地址.


BC类网络号除了固定位全0, 是可以指派的.
A类网络号全0, 表示本网络

I DISCOVER
II OFFER
III REQUEST
IV RELEASE
IV. A. B. c. D.
A 仅I, II
B 仅II, III
C 仅II, IV
D 仅I, III, IV

![[每日一题.md_Attachments/每日一题-20250907100222309.png]]
## 知识点总结
**DHCP 动态主机配置协议**

DHCP需要配置的项目
- IP地址
- 子网掩码
- 默认路由器的IP地址
- 域名服务器的IP地址, 这个是DNS吗?
默认网关是指什么?
默认网关就是默认路由器的IP地址


DHCP使用客户/服务器方式.
DHCP是TCP/TP协议体系中**应用层**的协议, 使用**运输层**的**UDP**所提供的服务
- DHCP客户使用的UDP端口是 68
- DHCP服务器使用的UDP端口是 67

| 报文名称               | 发送方      | 源IP地址        | 目的IP地址                            | 报文中的关键信息          |
| ------------------ | -------- | ------------ | --------------------------------- | ----------------- |
| DHCP DISCOVER 发现报文 | DHCP 客户  | 0.0.0.0<br>  | 255.255.255.255<br>               | 客户端MAC地址;<br>事务ID |
| DHCP OFFER 提供报文    | DHCP 服务器 | DHCP 服务器IP地址 | 255.255.255.255                   | 事物ID;<br>配置信息     |
| DHCP REQUEST 请求报文  | DHCP 客户  | 0.0.0.0      | 255.255.255.255或<br>DHCP客户租用的IP地址 |                   |
| DHCP ACK 确认报文      | DHCP 服务器 | 服务器IP地址      | 255.255.255.255或<br>DHCP客户租用的IP地址 |                   |
| DHCP NACK 否认报文     | DHCP 服务器 | DHCP 服务器IP地址 | DHCP客户租用的IP地址                     |                   |
| DHCP RELEASE 释放报文  | DHCP 客户  | 0.0.0.0      | 255.255.255.255                   |                   |

**注:**
1.DHCP DISCOVER
- 源IP地址为什么是0.0.0.0?
	- 目前主机没有IP地址, 只能0.0.0.0表示自己
- 目的IP地址为什么是广播地址?
	- 客户也不知道DHCP的IP地址, 也不知道有几个, 故用广播地址
- DHCP客户发送的DCHP广播数据报, 假设被其他用户主机接收, 层层解封, 得到封装有DHCP发现报文的UDP用户数据报, 由于该主机应用层没有监听该UDP用户数据包端口67的进程, 故会舍弃
