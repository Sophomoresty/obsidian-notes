### **机械工艺学 · 核心知识点深度解析：定位误差的分析与计算**

#### **1. 核心区别：尺寸的“大小”与“位置”**

在分析任何误差之前，我们首先要理解，图纸上的“尺寸”其实有两种完全不同的“身份”。我们可以用一个“在墙上挂画”的故事来理解：

* **“画的大小” (尺寸精度)**: 回答“这个东西本身有多大/多宽/多深?”的问题。
    * **例子**: 画框的“宽40 cm，高60 cm”；零件上孔的**直径**、槽的**宽度**。
    * **由谁保证？**: 主要由**刀具**的尺寸或**机床的运动精度**来保证。

* **“画挂在哪” (位置精度)**: 回答“这个东西在整体的哪个地方?”的问题。
    * **例子**: 画的中心点距离墙角和地面的“100 cm”和“150 cm”；孔心**距离零件边缘的距离**。
    * **由谁保证？**: 主要由加工时的**夹具定位**方案来保证。

> **一句话结论**: **定位误差分析，是专门用来分析“位置”的准确性的，而不是分析“尺寸”的准确性的。**

| 类别     | 解决的问题            | 中文术语                    | 加工中由谁保证？          | “挂画”类比             |
| :----- | :--------------- | :---------------------- | :---------------- | :----------------- |
| **尺寸** | "这个东西有多大/多宽/多深?" | 尺寸公差 (Dimensional Tol.) | **刀具** / **机床运动** | 画框的大小 (40 x 60 cm) |
| **位置** | "这个东西在零件的哪里?"    | 位置公差 (Positional Tol.)  | **夹具定位** / **基准** | 钉子在墙上的位置           |

#### **2. 定位误差分析：以图 9-29 为例**

> **题目**
> (分析图9-29所示的定位方案中，工件上不同尺寸的定位误差。)

* **💡 核心概念**
    * 定位误差由**基准不重合误差** $\varDelta_{bc}$ 和**基准位置误差** $\varDelta_{jw}$ 两部分组成。
    * **基准不重合误差 ($\varDelta_{bc}$)**: 当加工时实际依靠的**定位基准**，和图纸上标注尺寸所依据的**设计基准**不是同一个面时，由于联系这两个基准的尺寸链存在公差，所引起的附加定位误差。

* **✍️ 第一步：确定定位基准**
    * 根据图 (b) 的夹具，工件被装夹时，它的**左端面**和**底面**紧紧地靠在了夹具的两个相互垂直的定位块上。
    * **结论**: 所以，这个夹具的**定位基准**是工件的**左端面**和**底面**。

* **✍️ 第二步：逐一分析各尺寸**

    * **针对尺寸 A（槽的宽度）的分析**
        * **分析**: 尺寸 A 是“铣槽的尺寸”，也就是**槽的宽度**。这是一个**“大小”**属性，而不是“位置”属性。
        * **结论**: **定位误差不直接影响尺寸 A（槽宽）**。它的精度由刀具和机床运动保证。因此，关于尺寸 A 的定位误差为零。

    * **针对尺寸 C（槽底到地面的距离）的分析**
        * **工序基准**: 尺寸 C 的标注是从工件的**底面**开始的。
        * **定位基准**: 垂直方向的定位基准也是**底面**。
        * **误差分析**: **基准完全重合**！因此 $\varDelta_{bc} = 0$。同时，因为是平面定位，非常稳定，所以基准位置误差 $\varDelta_{jw} = 0$。
        * **结论**: 总定位误差 $\varDelta_{dw(C)} = \varDelta_{bc} + \varDelta_{jw} = 0 + 0 = 0$。这是一个**理想的**工艺方案。

    * **针对保证右端面位置的分析**
        * **问题背景**: 这是一个典型的“基准不重合”的例子，假设我们的**设计要求**是保证零件**右端面**的位置，但我们实际加工时，却用了**左端面**来定位。
        * **基准对比**:
            * **设计/工序基准**: 右端面
            * **定位基准**: 左端面
        * **误差分析**:
            * **基准不重合**！因此存在 $\varDelta_{bc}$。
            * **误差来源**: 连接“设计基准（右端面）”和“定位基准（左端面）”的尺寸是零件的**总长度 L**。
            * **计算 $\varDelta_{bc}$**: 由于总长度 L 本身有公差 `$L \pm \varDelta L$`，所以右端面相对于左端面的位置最大变动范围就是总长度的公差带宽度 $T_L$。
                $\varDelta_{bc} = (L + \varDelta L) - (L - \varDelta L) = 2\varDelta L$
            * 因为是平面定位，**基准位置误差** $\varDelta_{jw} = 0$。
        * **结论**:
            * 总定位误差 $\varDelta_{dw} = \varDelta_{bc} + \varDelta_{jw} = 2\varDelta L + 0 = 2\varDelta L$。
            * 这意味着，仅仅因为选错了定位基准，就会引入一个高达零件总长公差的定位误差。这是一个**有风险的、应尽量避免**的方案。
