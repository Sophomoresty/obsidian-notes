2.  此题要求写出**正态分布表达式**并**为代码添加注释**。
   
    最终表达式为 $N(3, 1; 5, 4; \displaystyle\frac{\sqrt{5}}{4})$。

> [!解释]
> **表达式的计算过程是**：
> 首先从均值向量 `miu = [3 1]` 中直接提取出均值 $\mu_x = 3, \mu_y = 1$；
>
> 接着从协方差矩阵 `sigma` 的对角线提取方差 $\sigma_x^2 = 5, \sigma_y^2 = 4$；
>
> 最后根据公式计算相关系数 $(\rho)$。协方差 $Cov(X,Y) = 2.5$，标准差 $\sigma_x = \sqrt{5}, \sigma_y = 2$。
>
> $$\rho = \frac{Cov(X,Y)}{\sigma_x \sigma_y} = \frac{2.5}{2\sqrt{5}} = \frac{5}{4\sqrt{5}} = \frac{\sqrt{5}}{4}$$
>
> 将这些值代入 $N(\mu_x, \mu_y; \sigma_x^2, \sigma_y^2; \rho)$，即可得到最终结果。

代码注释如下：

```matlab
clear                         % 清除工作区中的所有变量
miu = [3 1];                  % 定义二元正态分布的均值向量
sigma = [5 2.5; 2.5 4];       % 定义二元正态分布的协方差矩阵
s = rng; rng(s);              % 保存并重置随机数生成器状态, 保证结果可复现
Nr = mvnrnd(miu, sigma, 50);  % 从指定的二元正态分布中生成50个随机样本
```

### 四、简答题

**(1) 数据分析在机械问题中的应用**

以**风力发电机关键轴承的故障预测**为例，其数据分析流程主要包括几个阶段。

首先是**数据采集**，收集轴承的振动、温度等实时传感器数据及历史故障记录。接着进行**数据预处理与特征提取**，对信号去噪、归一化，并提取时域和频域的关键特征。

然后是**模型训练**，利用这些特征训练机器学习模型，建立从传感器数据到轴承健康状态的映射关系。最后进行**模型评估与部署**，将训练好的模型用于在线监测系统，实现对轴承的故障预警和剩余寿命预测。

**(2) 优化设计在机械行业的应用**

以**汽车车身结构轻量化设计**为例，其**流程**首先是建立优化模型，定义设计变量、目标函数和约束条件。接着结合有限元分析(FEA)软件对给定设计方案进行性能仿真。

最后采用优化算法自动调整设计变量并重复仿真，直至找到最优解。

这种方法的**优势**在于能够显著降低产品重量、成本和能耗，同时提升性能、缩短研发周期。但其**不足**之处在于计算量巨大，且对仿真模型的精度要求高。

**(3) 数据分析与优化设计的区别与联系**

二者的**区别**在于：**数据分析**是“向后看”，从现有数据中发现规律与模式，核心是**描述与预测**；而**优化设计**是“向前看”，在众多可能性中寻找满足特定目标的最优方案，核心是**决策与规定**。

二者的**联系**在于相辅相成。数据分析可以为优化模型提供精确的参数和边界，是优化的基础。而优化设计产生的新方案可以生成新的数据，用于进一步的分析和验证，形成持续改进的闭环。

### 五、建立优化数学模型

这是一个典型的线性规划问题。**设计变量**定义为每天生产甲、乙两种产品的件数，分别记为 $x_1$ 和 $x_2$。**目标函数**是最大化总利润 Z。**约束条件**主要来自材料、工时和电力的供应上限，同时变量本身需满足非负约束。完整的数学模型如下：

**目标函数**:

$$\max Z = 60x_1 + 120x_2$$

**约束条件**:
$$
\left\{
\begin{aligned}
   9x_1 +  4x_2 &\le 360 \\
   3x_1 + 10x_2 &\le 300 \\
   4x_1 +  5x_2 &\le 200 \\
         x_1, x_2 &\ge 0
\end{aligned}
\right.
$$

### 六、计算题

#### 1. 黄金分割法

**问题**: 求 $f(x)=x^{2}-7x+10$ 在区间 `[2, 8]` 上的最优解, 迭代一步。

**算法思想与步骤总览**:

黄金分割法是一种用于求解单变量函数在给定单峰区间内极小值的高效搜索算法。其核心思想是利用黄金分割比例（约0.618）在区间内确定两个试探点，通过比较两点的函数值，来舍去一部分不包含极小值的区间，从而逐步缩小搜索范围。本题解题步骤为：初始化区间 -> 计算试探点 -> 计算函数值 -> 比较并缩减区间 -> 得出新区间。

**解题步骤**:

1.**初始化**: 目标函数为 $f(x)=x^{2}-7x+10$，初始搜索区间为 $[a_1, b_1] = [2, 8]$，其长度 $L_1 = 6$。使用黄金分割系数 $\tau = 0.618$。

2.**计算试探点**: 在区间内按黄金比例找到两个内部点 $x_r = a_1 + \tau L_1 = 2 + 0.618 \times 6 = 5.708$ 和 $x_l = b_1 - \tau L_1 = 8 - 0.618 \times 6 = 4.292$。

3.**计算函数值**: 评估两个试探点处的函数值，$f(x_l) = f(4.292) \approx -1.624$，$f(x_r) = f(5.708) \approx 2.624$。

4.**比较与缩减区间**: 因为 $f(x_l) < f(x_r)$，说明函数值在从 $x_l$ 到 $x_r$ 的方向上是上升的，极小点一定在 $x_r$ 的左侧。因此，舍去区间 $[x_r, b_1]$，保留新区间 $[a_2, b_2] = [a_1, x_r]$。

5.**得出新区间**: 迭代一步后，新的搜索区间为 **`[2, 5.708]`**。

#### 2. 惩罚函数法

##### (1) 外点法求解等式约束问题

**算法思想与步骤总览**:

外点法的思路是将有约束问题转化为无约束问题。它通过在目标函数上增加一个对违反约束行为施加巨大惩罚的“惩罚项”，当罚因子 $M \to \infty$ 时，迭代点会被“逼迫”去满足约束条件。解题步骤为：构造增广函数 -> 对变量求偏导并令其为零 -> 求解用罚因子 M 表示的变量 -> 取极限得出最优解。

**解题步骤**:

1.**构造增广函数**: 新的无约束目标函数为 $\Phi(X, M) = \frac{1}{2}x_{1}^{2}+\frac{1}{4}x_{2}^{2} + M(x_1+x_2-1)^2$。

2.**求偏导**: 对 $x_1$ 和 $x_2$ 求偏导并令其为零，得到方程组：$x_1 + 2M(x_1+x_2-1) = 0$ 和 $\frac{1}{2}x_2 + 2M(x_1+x_2-1) = 0$。

3.**求解方程组**: 联立方程解得 $x_1 = \displaystyle\frac{2M}{1 + 6M}$ 和 $x_2 = \displaystyle\frac{4M}{1 + 6M}$。

4.**取极限**: 当罚因子 $M \to \infty$ 时，求得 $x_1^* = \displaystyle\frac{1}{3}$ 和 $x_2^* = \displaystyle\frac{2}{3}$。最终最优解为 $X^* = \left(\displaystyle\frac{1}{3}, \frac{2}{3}\right)$。

##### (2) 对数内点法求解不等式约束问题

**算法思想与步骤总览**:

内点法同样是将约束问题转化为无约束问题，但它的迭代点始终保持在可行域内部。它通过增加一个当迭代点靠近边界时会趋于无穷大的“障碍项”（通常是对数函数）来实现。当障碍因子 $r \to 0^+$ 时，迭代点会逼近最优解。解题步骤为：构造增广函数 -> 求偏导 -> 求解用障碍因子 r 表示的变量 -> 取极限得出最优解。

**解题步骤**:

1.**构造增广函数**: 对应约束 $x_1 \ge 0, x_2 \ge 0$ 的增广函数为
$$\Phi(X, r) = x_{1}^{2}+6x_{1}+x_{2}^{2}+4 - r \ln(x_1) - r \ln(x_2)$$
   
2.**求偏导**: 对 $x_1$ 和 $x_2$ 求偏导并令其为零，得到方程组：$2x_1 + 6 - \displaystyle\frac{r}{x_1} = 0$ 和 $2x_2 - \displaystyle\frac{r}{x_2} = 0$。

3.**求解方程组**: 解得 $x_2 = \displaystyle\sqrt{\frac{r}{2}}$ 和 $x_1 = \displaystyle\frac{-6 + \sqrt{36+8r}}{4}$ (取正根以保证在可行域内)。

4.**取极限**: 当障碍因子 $r \to 0^+$ 时，求得 $x_1^* = 0$ 和 $x_2^* = 0$。最终最优解为 $X^* = (0, 0)$。
