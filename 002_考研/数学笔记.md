# 强化第一章

## 函数单调性与导数关系

### 一、区间上的单调性

在讨论函数在区间上的单调性时，我们通常假定函数在该区间上**可导**。

#### 1.1 导数符号 $\Rightarrow$ 函数单调性（充分条件）

这是我们利用导数判断函数单调性的主要方法。

* **严格单调增加/减少：**
    如果函数 $f(x)$ 在区间 $I$ 上**可导**，并且对 $I$ 内的**所有** $x$，都有 $f'(x) > 0$，那么 $f(x)$ 在区间 $I$ 上**严格单调增加**。
    （同理，若 $f'(x) < 0$，则 $f(x)$ 在区间 $I$ 上**严格单调减少**。）

* **单调不减/不增：**
    如果函数 $f(x)$ 在区间 $I$ 上**可导**，并且对 $I$ 内的**所有** $x$，都有 $f'(x) \ge 0$，那么 $f(x)$ 在区间 $I$ 上**单调不减**。
    （同理，若 $f'(x) \le 0$，则 $f(x)$ 在区间 $I$ 上**单调不增**。）
    * **核心辨析：** **非常重要, 这里一定要注意**: 这里的 $f'(x) \ge 0$ 确实能推出 $f(x)$ 是**单调不减**。但它并不能**保证** $f(x)$ **一定不是严格单调增加**；函数仍有可能是严格单调增加的，例如 $f(x)=x^3$ 在 $\mathbb{R}$ 上，其导数 $f'(x)=3x^2 \ge 0$，而函数本身是严格单调增加的。因此，**若要精确证明一个函数是严格单调增加，由导数 $f'(x) > 0$ 去推导是准确的；但在导数存在零点时，最好从单调性**定义**出发去证明。**

#### 1.2 函数单调性 $\Rightarrow$ 导数符号（必要条件）

这是反过来，由函数单调性推导出导数的符号。

* **严格单调增加/减少：**
    如果函数 $f(x)$ 在区间 $I$ 上**可导**，且在区间 $I$ 上**严格单调增加**，那么对 $I$ 内的**所有** $x$，都有 $f'(x) \ge 0$。
    （同理，若严格单调减少，则 $f'(x) \le 0$。）
    * **重要说明：** 即使函数严格单调，其导数在个别点上**可能为零**。一个典型反例是 $f(x)=x^3$ 在 $x=0$ 处，函数严格单调增加，但 $f'(0)=0$。

* **单调不减/不增：**
    如果函数 $f(x)$ 在区间 $I$ 上**可导**，且在区间 $I$ 上**单调不减**，那么对 $I$ 内的**所有** $x$，都有 $f'(x) \ge 0$。
    （同理，若单调不增，则 $f'(x) \le 0$。）
    * **理解：** 这个结论与“严格单调增加的必要条件”是相同的，因为“严格单调增加”是“单调不减”的一种特殊情况。

### 二、点上的单调性（局部考量）

在讨论函数在某一点 $x_0$ 处的局部单调性时，通常假定函数在 $x_0$ 处**可导**。

#### 2.1 点的单调性 $\Rightarrow$ 导数符号（必要条件）

* **命题：** 如果函数 $f(x)$ 在 $x_0$ 处可导，并且在 $x_0$ 点的某个邻域内**严格单调增加**，那么 $f'(x_0) \ge 0$。
    （同理，若在邻域内严格单调减少，则 $f'(x_0) \le 0$。）

#### 2.2 导数符号 $\Rightarrow$ 点的单调性（需要注意陷阱）

这个方向的推论需要格外注意，因为 $f'(x_0)$ 的值并不能完全决定函数在该点邻域的“严格单调性”。

* **结论：** 如果 $f'(x_0) > 0$，则 $f(x)$ 在 $x_0$ 处具有**局部上升的趋势**。
    * **具体表现：** 存在一个 $\delta > 0$，使得当 $x \in (x_0-\delta, x_0)$ 时，$f(x) < f(x_0)$；当 $x \in (x_0, x_0+\delta)$ 时，$f(x) > f(x_0)$。
    * **重要辨析：** 这种“局部上升趋势”与“在 $x_0$ 邻域内严格单调增加”**不是等价的**。
        * **反例：** 函数 $f(x) = \begin{cases} x+2x^2\sin \frac{1}{x}, & x\ne 0\\ 0, & x=0\\ \end{cases}$。
        * 该函数在 $x=0$ 处的导数 $f'(0) = 1 > 0$。
        * 但由于其导函数 $f'(x) = 1 + 4x\sin\frac{1}{x} - 2\cos\frac{1}{x}$ 在 $x=0$ 的任何邻域内都会取到负值，导致 $f(x)$ 在 $x=0$ 的任何邻域内**都不是严格单调增加的**（尽管 $f(0)$ 确实介于其左右邻域值之间）。

## 函数奇偶性与导数关系

这里主要讨论原函数 $f(x)$ 和其导数 $f'(x)$ 的奇偶性关系，以及导数和其原函数（即不定积分）的奇偶性关系。

### 1 原函数 $f(x) \Rightarrow$ 导数 $f'(x)$

这个方向的推导比较直接。

* **结论：** **原函数的奇偶性与导数的奇偶性通常相反。**
    * 如果 $f(x)$ 是**奇函数**且 $f'(x)$ 存在，则 $f'(x)$ 是**偶函数**。
    * 如果 $f(x)$ 是**偶函数**且 $f'(x)$ 存在，则 $f'(x)$ 是**奇函数**。

* **简要证明思路：**
    利用复合函数求导法则。
    1.  **若 $f(x)$ 为奇函数：** $f(-x) = -f(x)$。两边求导得 $f'(-x) \cdot (-1) = -f'(x) \implies f'(-x) = f'(x)$，即 $f'(x)$ 是偶函数。
    2.  **若 $f(x)$ 为偶函数：** $f(-x) = f(x)$。两边求导得 $f'(-x) \cdot (-1) = f'(x) \implies f'(-x) = -f'(x)$，即 $f'(x)$ 是奇函数。


### 2 导数 $f'(x) \Rightarrow$ 原函数 $F(x)$ （不定积分）

这个方向的讨论需要利用**变上限积分函数**作为桥梁。

设 $F(x)$ 是 $f'(x)$ 的一个原函数，即 $F(x) = \int f'(x) dx$。我们知道 $F(x)$ 可以表示为 $G(x) + C$，其中 $G(x)$ 是一个特定的变上限积分（例如 $\int_{a}^{x} f'(t) dt$），$C$ 是任意常数。

#### 2.1 导数 $f'(x)$ 是**奇函数**时

* **结论：** 如果 $f'(x)$ 是**奇函数**，那么它的**任何**原函数 $F(x)$ 都是**偶函数**。

* **简要证明：**
    1.  考虑变上限积分 $G(x) = \int_{a}^{x} f'(t) dt$。
    2.  可将 $G(x)$ 拆分为 $G(x) = \int_{a}^{0} f'(t) dt + \int_{0}^{x} f'(t) dt$。
    3.  其中，$\int_{a}^{0} f'(t) dt$ 是一个**定值常数** $C_0$（常数只会影响奇函数性, 不会影响偶函数性）。
    4.  关键在于 $\int_{0}^{x} f'(t) dt$。对其考察 $G_0(-x) = \int_{0}^{-x} f'(t) dt$。
    5.  利用换元法（令 $u = -t \implies dt = -du$），并利用 $f'(t)$ 是奇函数（$f'(-u) = -f'(u)$）：
        $G_0(-x) = \int_{0}^{x} f'(-u)(-du) = \int_{0}^{x} (-f'(u))(-du) = \int_{0}^{x} f'(u) du = G_0(x)$。
    6.  所以，$\int_{0}^{x} f'(t) dt$ 是一个**偶函数**。
    7.  因此，原函数 $F(x) = G_0(x) + C_0 + C$（仍然是偶函数加常数），最终 $F(x)$ 是**偶函数**。

#### 2.2 导数 $f'(x)$ 是**偶函数**时

* **结论：** 如果 $f'(x)$ 是**偶函数**，那么它的原函数 $F(x)$：
    * 只有当常数 $C=0$ 时（即**积分下限为 $0$ 的变上限积分函数** $\int_{0}^{x} f'(t) dt$），原函数才是**奇函数**。
    * **一般情况下**（即 $C \ne 0$ 时，或积分下限 $a \ne 0$），原函数**既不是奇函数也不是偶函数**。

* **简要证明：**
    1.  同样考虑变上限积分 $G(x) = \int_{0}^{x} f'(t) dt$。
    2.  对其考察 $G_0(-x) = \int_{0}^{-x} f'(t) dt$。
    3.  利用换元法（令 $u = -t \implies dt = -du$），并利用 $f'(t)$ 是偶函数（$f'(-u) = f'(u)$）：
        $G_0(-x) = \int_{0}^{x} f'(-u)(-du) = \int_{0}^{x} f'(u)(-du) = -\int_{0}^{x} f'(u) du = -G_0(x)$。
    4.  所以，$\int_{0}^{x} f'(t) dt$ 是一个**奇函数**。
    5.  因此，原函数 $F(x) = G_0(x) + C$。
        * 当 $C=0$ 时，$F(x) = G_0(x)$，此时 $F(x)$ 是**奇函数**。
        * 当 $C \ne 0$ 时，$F(-x) = -G_0(x) + C$。这通常既不等于 $F(x)$ 也不等于 $-F(x)$，所以 $F(x)$ **一般既不是奇函数也不是偶函数**。

## 函数周期性与导数的关系

### 1 原函数 $f(x) \Rightarrow$ 导数 $f'(x)$

这个方向的结论通常比较直接和普遍。

* **结论：** 如果函数 $f(x)$ 是周期函数，且其导数 $f'(x)$ 存在，那么 $f'(x)$ 也是周期函数。
* **证明：**
    设 $f(x)$ 是周期为 $T$ 的函数，即 $f(x+T) = f(x)$。

    对等式两边关于 $x$ 求导：

    $\frac{d}{dx}f(x+T) = \frac{d}{dx}f(x)$

    根据复合函数求导法则，左边为 $f'(x+T) \cdot \frac{d}{dx}(x+T) = f'(x+T) \cdot 1 = f'(x+T)$。

    所以，$f'(x+T) = f'(x)$。

    这证明了 $f'(x)$ 也是周期函数，且周期为 $T$（不一定是最小正周期）。

### 2 导数 $f'(x) \Rightarrow$ 原函数 $F(x)$

这个方向需要更严谨地讨论，因为导数具有周期性，其原函数不一定具有周期性。

* **结论：** 如果 $f'(x)$ 是周期函数，且其在一个周期内的积分等于 $0$，那么它的原函数 $F(x)$ 具有周期性。

* **严谨证明：**
    设 $f'(x)$ 是一个周期为 $T$ 的函数。
    考虑 $f'(x)$ 的一个原函数，比如变上限积分函数 $F(x) = \int_{a}^{x} f'(t) dt$（其中 $a$ 是某个常数）。

    我们来考察 $F(x+T)$：
    $F(x+T) = \int_{a}^{x+T} f'(t) dt$

    将积分拆分为：
    $F(x+T) = \int_{a}^{x} f'(t) dt + \int_{x}^{x+T} f'(t) dt$

    根据变上限积分的定义，$\int_{a}^{x} f'(t) dt$ 就是 $F(x)$。所以：
    $F(x+T) = F(x) + \int_{x}^{x+T} f'(t) dt$

    现在，关键在于处理 $\int_{x}^{x+T} f'(t) dt$ 这部分。我们需要证明**周期函数在一个周期内的积分值是相等的，无论从哪里开始积。**

    **【补充证明：周期函数在一个周期内的积分相等】**

    设 $g(x)$ 是一个周期为 $T$ 的函数，在 $[x, x+T]$ 上可积。我们要证明 $\int_{x}^{x+T} g(t) dt = \int_{0}^{T} g(t) dt$。

    证明步骤：
    1.  我们可以将 $\int_{x}^{x+T} g(t) dt$ 拆分成三部分：
        $\int_{x}^{x+T} g(t) dt = \int_{x}^{0} g(t) dt + \int_{0}^{T} g(t) dt + \int_{T}^{x+T} g(t) dt$

    2.  现在，我们专注于最右边的积分 $\int_{T}^{x+T} g(t) dt$。
        令变量替换 $u = t - T$。那么 $t = u + T$，且 $dt = du$。
        
        当 $t=T$ 时，$u=0$。
        
        当 $t=x+T$ 时，$u=x$。

    3.  代入积分中：
        $\int_{T}^{x+T} g(t) dt = \int_{0}^{x} g(u+T) du$
        
        由于 $g(x)$ 是周期为 $T$ 的函数，所以 $g(u+T) = g(u)$。
        
        因此，$\int_{0}^{x} g(u+T) du = \int_{0}^{x} g(u) du$。

    4.  将这个结果代回第 1 步的拆分式中：
        $\int_{x}^{x+T} g(t) dt = \int_{x}^{0} g(t) dt + \int_{0}^{T} g(t) dt + \int_{0}^{x} g(t) dt$

    5.  注意到 $\int_{x}^{0} g(t) dt = -\int_{0}^{x} g(t) dt$。所以：
        $\int_{x}^{x+T} g(t) dt = -\int_{0}^{x} g(t) dt + \int_{0}^{T} g(t) dt + \int_{0}^{x} g(t) dt$

    6.  前面的两项正好抵消，最终得到：
        $\int_{x}^{x+T} g(t) dt = \int_{0}^{T} g(t) dt$。
    至此，【补充证明】完毕。

    **回到原证明：**

    利用上述【补充证明】的结论，我们可以将 $\int_{x}^{x+T} f'(t) dt$ 替换为 $\int_{0}^{T} f'(t) dt$：
    $F(x+T) = F(x) + \int_{0}^{T} f'(t) dt$

    * **结论：**
        如果**导数 $f'(x)$ 在一个周期 $T$ 内的积分 $\int_{0}^{T} f'(t) dt$ 等于 $0$**，那么：
        $F(x+T) = F(x) + 0 = F(x)$。
        这证明了此时 $F(x)$ 具有周期性，且周期为 $T$。

* **总结：** 只有当导数 $f'(x)$ 的周期积分为 $0$ 时，其原函数 $F(x)$ 才具有周期性。如果这个周期积分不为 $0$，原函数 $F(x)$ 将会呈线性增长或下降趋势（例如 $F(x+T) = F(x) + C_1$，其中 $C_1 \neq 0$），因此不具有周期性。

## 极限的保号性定理

极限的保号性是微积分中一个非常基础且重要的定理，它描述了函数极限与其在邻域内函数值符号之间的关系。

#### 1 由极限推出函数值符号

* **定理：** 如果 $\lim_{x \to x_0} f(x) = A$，且 $A > 0$（或 $A < 0$），那么**存在** $x_0$ 的一个去心邻域 $U(x_0, \delta)$，使得当 $x \in U(x_0, \delta)$ 时，有 $f(x) > 0$（或 $f(x) < 0$）。
    * **理解：** 如果极限不为零，那么在极限点附近，函数值会和极限保持相同的符号。

* **证明：**
    设 $\lim_{x \to x_0} f(x) = A$ 且 $A > 0$。
    
    根据极限的定义，对于任意给定的 $\varepsilon > 0$，存在一个 $\delta > 0$，使得当 $0 < |x - x_0| < \delta$ 时，有 $|f(x) - A| < \varepsilon$。
    
    这等价于 $A - \varepsilon < f(x) < A + \varepsilon$。
    
    我们选择一个特殊的 $\varepsilon$，例如 $\varepsilon = A/2$（因为 $A>0$，所以 $A/2>0$）。
    
    将 $\varepsilon = A/2$ 代入不等式：
    
    $A - A/2 < f(x) < A + A/2$
    
    $A/2 < f(x) < 3A/2$
    
    由于 $A/2 > 0$，所以 $f(x) > 0$。
    
    因此，在 $x_0$ 的去心邻域 $U(x_0, \delta)$ 内，$f(x)$ 保持正号。
    
    （当 $A < 0$ 时，证明类似，选择 $\varepsilon = -A/2$ 即可证明 $f(x) < 0$。）

---
#### 2 逆定理：由函数值符号推出极限的符号）

* **定理：** 如果 $\lim_{x \to x_0} f(x) = A$，且在 $x_0$ 的某个去心邻域 $U(x_0, \delta_0)$ 内有 $f(x) \ge 0$（或 $f(x) \le 0$），那么 $A \ge 0$（或 $A \le 0$）。
    * **理解：** 如果函数在某处附近值都是非负的（或非正的），那么它的极限也只能是非负的（或非正的）。极限不会突然变成负数（或正数）。

* **证明：**
    设 $\lim_{x \to x_0} f(x) = A$，并且存在 $x_0$ 的一个去心邻域 $U(x_0, \delta_0)$ 使得 $f(x) \ge 0$。
    
    我们使用**反证法**。
    
    假设 $A < 0$。
    
    根据极限的定义，对于 $\varepsilon = -A/2 > 0$（因为我们假设 $A < 0$），存在一个 $\delta > 0$（我们可以选择 $\delta \le \delta_0$），使得当 $0 < |x - x_0| < \delta$ 时，有 $|f(x) - A| < \varepsilon$。
    
    这等价于 $A - \varepsilon < f(x) < A + \varepsilon$。
    
    代入 $\varepsilon = -A/2$：
    
    $A - (-A/2) < f(x) < A + (-A/2)$
    
    $3A/2 < f(x) < A/2$
    
    由于我们假设 $A < 0$，所以 $A/2 < 0$。这意味着 $f(x) < A/2 < 0$。
    
    因此，在 $x_0$ 的去心邻域 $U(x_0, \delta)$ 内，$f(x) < 0$。
    
    这与我们已知的条件“在 $U(x_0, \delta_0)$ 内 $f(x) \ge 0$”相矛盾。
    
    所以，我们的假设 $A < 0$ 是不成立的。
    
    因此，必然有 $A \ge 0$。
    
    （当 $f(x) \le 0$ 时，证明类似，假设 $A > 0$ 即可推导出矛盾。）
