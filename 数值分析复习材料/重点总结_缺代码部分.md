## **一、数据分析基础**

### 数据的分类
> [!summary] 记忆数据的4个分类

统计数据可以从不同维度进行划分。

1.按计量尺度可分为**分类数据**（如性别）、**顺序数据**（如等级）和**数值型数据**（如身高）。

2.按收集方法可分为**观测数据**（通过观察或调查获得）和**实验数据**（通过控制实验获得）。

3.按与时间的关系可分为**横截面数据**（同一时间点上不同对象的数据）和**时间序列数据**（同一对象在不同时间点的数据）。

此外，还可以分为**一手数据**和**二手数据**。

### 核心统计量

#### 分位数与三均值
> [!summary] 需要掌握 分位数 和 三均值 的公式和代码

**分位数 (Quantile)** 是指将一个概率分布或样本数据按大小排序后，切割成等份的分割点。p 分位数就是一个数值，它使得小于该数值的数据占比为 p。


在 MATLAB 中，可以使用 `prctile(X, P)` 命令来求，其中 `X` 是数据向量，`P` 是百分位的数值（例如，求0.25分位数时，P 为25）。

**三均值 (Trimean)** 是一种稳健的中心位置度量，它综合了中位数和四分位数的优点。其公式为：
$$T = \displaystyle\frac{Q_1 + 2Q_2 + Q_3}{4}$$
这里，$Q_1, Q_2, Q_3$ 分别是下四分位数、中位数和上四分位数。

MATLAB 代码
```matlab
% 假设数据向量为X
Q = prctile(X, [25 50 75]);
Trimean = (Q(1) + 2*Q(2) + Q(3)) / 4;
```
#### 上下截断点与 IQR
> [!summary] 需要掌握 上下截断点 和 四分位极差(IQR) 的代码表示, 公式辅助记忆

在统计学中，常用一种基于**四分位极差 (Interquartile Range, IQR)** 的准则来识别潜在的异常值。

IQR 本身是一个稳健的离散程度度量，其定义为上四分位数 ($Q_3$) 与下四分位数 ($Q_1$) 之差，即 $IQR = Q_3 - Q_1$，它代表了数据中间50%的散布范围。在 MATLAB 中，可以通过 `iqr(A)` 命令计算得到。

基于 IQR，我们可以定义出判断异常值的“围栏”，即**上下截断点**。任何超出这个范围的数据点，都被视为潜在的异常值。

##### 公式及代码
**四分位极差**的公式: $IQR=Q_3-Q_1$
代码表示:
```matlab
% 求数据A的四分位极差
R = iqr(A)
```
**上截断点**的公式为 $Q_3 + 1.5 \times IQR$
代码表示:
```matlab
% 求数据A的上截断点
SJ = prctile(A, 75) + 1.5 * iqr(A)
```
**下截断点**的公式为 $Q_1 - 1.5 \times IQR$
代码表示:
```matlab
% 求数据A的下截断点
XJ = prctile(A, 25) - 1.5 * iqr(A)
```

### PDF、CDF 与 ECDF
> [!summary] 了解即可

**概率密度函数 (PDF, Probability Density Function)** 描述的是连续型随机变量在**某一个点附近**的概率密度或可能性大小。对于 PDF 曲线而言，其任意一段的曲线下面积代表了变量落入该区间的概率，曲线下总面积恒为1。

**累积分布函数 (CDF, Cumulative Distribution Function)**  是一个理论概念，它定义为 $F(x) = P(X \le x)$，即变量取值小于等于 x 的**累积概率**。它的值域在0到1之间。

**经验分布函数 (ECDF, Empirical Cumulative Distribution Function)** 是根据**样本数据**对总体真实 CDF 的一个近似。ECDF 是一个阶梯函数，每遇到一个数据点，函数值就跳跃 $1/n$（n 为样本量）。

两者的核心区别在于：CDF 是描述**总体**的**理论**分布函数，而 ECDF 是基于**样本**对 CDF 的一个**估计**。

## **二、数据分布与检验**

### 偏度与峰度
> [!summary] 了解即可


**偏度**是衡量分布的非对称程度或偏斜成都的特征, 总体分布是正态分布时, 偏度近似为0。若偏度大于0，称为右偏态（正偏），分布有向右延伸的长尾巴；若小于0，称为左偏态（负偏）。

**峰度**是衡量数据尾部分散性的指标, 总体分布是正太分布时, 峰度近似为0。若峰度大于0，称为尖峰厚尾，意味着分布有比正态分布更多的极端值；若小于0，称为低峰细尾。

### 总体分布的正态性检验
> [!summary] 重点记忆高亮部分

检验方法主要分为图形法和统计检验法。

#### 图形检验法

主要是**Q-Q 图**检验方法，它将样本数据的分位数与理论分布的分位数做散点图。

如果散点近似在一条直线上，则可认为样本数据服从该理论分布。

==Q-Q 图 可用于一维和多维数据的正态性检验, 多维数据书上也只能用 Q-Q 图进行正态性检验。==

#### 统计检验法

主要有 **JB 检验**, **KS 检验**, **Lilliefors 检验**。

**JB 检验**是==利用正太分布的偏度 sk 和峰度 ku 进行检验==。

**KS 检验**和 **Lilliefors 检验**都是通过样本经验分布函数与给定的分布函数进行比较进行检验。

KS 检验用于正态性检验时只能做**标准正态检验**（即均值、方差已知）, 

而 Lilliefors 检验是其改进，可以做**一般的正态性检验**（即均值、方差未知，由样本估计）。

## **三、回归分析**

### 一元线性回归
> [!summary] 代码要会默写, 公式可以辅助记忆

一元线性回归模型是 $\hat{y}_{i}=a+bx_{i}$。其核心是使用**最小二乘法**来估计系数 $a$ 和 $b$。


$$L_{xx} = \sum(x_i-\bar{x})^2$$

$$L_{xy} = \sum(x_i-\bar{x})(y_i-\bar{y})$$

$$b = \displaystyle\frac{L_{xy}}{L_{xx}}$$

$$a = \bar{y} - b\bar{x}$$

Matlab 代码
```matlab
Lxx = sum((x-mean(x)).^2);
Lxy = sum((x-mean(x)).*(y-mean(y)));
b = Lxy / Lxx;
a = mean(y) - b*mean(x);
```
### 平方和关系与显著性检验
> [!summary] 掌握平方和关系和回归方程的显著性检验方法

**平方和分解**关系为：

==总平方和 (TSS) = 回归平方和 (ESS) + 残差平方和 (RSS)，即 $TSS=ESS+RSS$。==

**总平方和 TSS** ($TSS = \sum(y_i - \bar{y})^2$) 度量了因变量 Y 的总变异。

**回归平方和 ESS** ($ESS = \sum(\hat{y}_i - \bar{y})^2$) 度量了 Y 的总变异中，可以被回归模型解释的部分。

**残差平方和 RSS** ($RSS = \sum(y_i - \hat{y}_i)^2$) 度量了 Y 的总变异中，无法被模型解释的部分。

==**常用的回归方程的显著性检验方法**有三种：**F 检验**, **T 检验**, **可决系数 $R^2$ 检验**。==

==可决系数的范围在0到1之间, 越接近1, 方程越显著, 越接近0, 方程越不显著。==

### 回归诊断
> [!summary] 回归诊断包括哪些? 异常点和强影响点的统计量是什么?

回归诊断包括**异常点与强影响点诊断**, **残差分析**, **多重共线性诊断**三个主要内容。

**异常点 (Outlier)**，它特指在 Y 方向上严重偏离模型预测值的点，其残差很大。
> 统计量为: 残差, 皮尔森残差, 学生化残差

**强影响点 (Influential Point)**，指那些一旦移除就会对回归模型产生巨大改变的点，它通常需要同时具备高杠杆和高残差两个特征。
> 统计量为: 杠杆值, Cook 距离, CovRatio 统计量, Dffits 统计量, Dfbeta 统计量

## **四、优化设计**
> [!summary] 全背
### 优化设计基础

**优化设计三要素**：**设计变量**、**目标函数**和**约束条件**。

**优化设计流程**：

建立优化数学模型 -> 选择合适的优化算法 -> 进行迭代寻优计算 -> 分析与验证最优解。

**数据分析与优化设计的区别与联系**：

数据分析是“向后看”，从数据中发现规律与模式，核心是**描述与预测**；优化设计是“向前看”，在众多可能性中寻找满足特定目标的最优方案，核心是**决策与规定**。二者相辅相成，数据分析是优化的基础。

### 优化算法详解与计算实例
> [!summary] 一维必须掌握==外推==, ==黄金分割==. 二维必须掌握==梯度法==和==惩罚函数法==, 有时间的话可以看==二次插值法==和==牛顿法==

#### 一维优化方法

##### 外推法

**算法介绍**

外推法是一种用于确定**初始单峰区间**的算法。它的思想是从一个初始点出发，沿着函数值下降的方向以固定步长前进，直到找到函数值呈现“高-低-高”趋势的三个点，这三点构成的区间即为单峰区间，为后续的精确搜索（如黄金分割法）做准备。

**整体的计算过程**

1.给定初始点 $x_1$ 和初始步长 $h$。计算 $f_1 = f(x_1)$。

2.计算试探点 $x_2 = x_1+h$，并计算 $f_2 = f(x_2)$。

3.比较 $f_1$ 和 $f_2$。若 $f_1 < f_2$，说明前进方向错误，应反向搜索，令 $h = -h$ 后回到第2步。

4.若 $f_1 > f_2$，说明前进方向正确，则开始外推。循环计算下一点 $x_3 = x_2+h$ 和 $f_3=f(x_3)$，并判断是否 $f_2 > f_3$。

5.如果 $f_2$ 依然大于 $f_3$，说明仍未越过极小点，则更新各点 ($x_1 \leftarrow x_2, x_2 \leftarrow x_3$) 并继续外推。

6.如果 $f_2 \le f_3$，说明 $x_2$ 点是“高-低-高”趋势中的“低”点，已找到单峰区间。根据 $h$ 的正负，确定区间的左右端点。

**计算示例**

**问题**: 用外推法为函数 $f(x)=(x-5)^2$ 寻找一个包含极小值的单峰区间。设初始点 $x_1=1$，初始步长 $h=1$。

**解题步骤**:

1.初始化 $x_1=1, h=1$。计算 $f(x_1) = (1-5)^2 = 16$。

2.计算新点 $x_2 = x_1+h = 2$，及其函数值 $f(x_2) = (2-5)^2 = 9$。

3.判断方向，因为 $f(x_1) > f(x_2)$，说明前进方向正确，开始外推。

4.令 $x_1 \leftarrow 2, x_2 \leftarrow 3$，计算 $f(x_2)=f(3)=4$。因为 $f(x_1)=9 > f(x_2)=4$，继续外推。

5.令 $x_1 \leftarrow 3, x_2 \leftarrow 4$，计算 $f(x_2)=f(4)=1$。因为 $f(x_1)=4 > f(x_2)=1$，继续外推。

6.令 $x_1 \leftarrow 4, x_2 \leftarrow 5$，计算 $f(x_2)=f(5)=0$。因为 $f(x_1)=1 > f(x_2)=0$，继续外推。

7.令 $x_1 \leftarrow 5, x_2 \leftarrow 6$，计算 $f(x_2)=f(6)=1$。此时 $f(x_1)=0 < f(x_2)=1$。

8.找到单峰区间，三个点分别为 (4, 5, 6)，函数值为 (1, 0, 1)，呈现“高-低-高”趋势。最终确定的单峰区间为 **`[4, 6]`**。

##### 黄金分割法

**算法介绍**

黄金分割法是在已知的单峰区间内，通过0.618的黄金比例不断缩小区间来精确搜索极小点的一种高效算法。它通过计算和比较两个内分点的函数值，以确定取舍哪部分区间，直至区间长度满足精度要求。

**整体的计算过程**

1.给定单峰区间 $[a, b]$ 和精度要求 $\epsilon$。

2.计算两个内点 $x_l = b - 0.618(b-a)$ 和 $x_r = a + 0.618(b-a)$。

3.比较 $f(x_l)$ 和 $f(x_r)$ 的大小。若 $f(x_l) < f(x_r)$，则新区间为 $[a, x_r]$；否则新区间为 $[x_l, b]$。

4.检查新区间的长度是否小于 $\epsilon$，若否则回到第2步。

**计算示例**

**问题**: 求 $f(x)=x^{2}-7x+10$ 在区间 `[2, 8]` 上的最优解, 迭代一步。

**解题步骤**:

1. 初始化目标函数 $f(x)=x^{2}-7x+10$，初始区间 $[a_1, b_1] = [2, 8]$，长度 $L_1 = 6$，黄金分割系数 $\tau = 0.618$。
2. 计算试探点 $x_r = a_1 + \tau L_1 = 5.708$ 和 $x_l = b_1 - \tau L_1 = 4.292$。
3. 计算函数值 $f(x_l) \approx -1.624$，$f(x_r) \approx 2.624$。
4. 比较函数值，因为 $f(x_l) < f(x_r)$，说明极小点在 $x_r$ 的左侧，舍去区间 $[x_r, b_1]$。
5. 得出新区间，迭代一步后，新的搜索区间为 **`[2, 5.708]`**。

##### 二次插值法
**算法介绍**

二次插值法的基本思想是在搜索区间内取三个点，用这三点构造一个二次多项式（抛物线）来近似代替原函数，然后将该抛物线的极小点作为原函数最优解的新的近似点。通过不断用新的近似点替换旧的三个点之一，来逐步逼近最优解。

**整体的计算过程**

1.选取初始三个点 $x_1, x_2, x_3$ 及其函数值 $f_1, f_2, f_3$。

2.用这三点求解二次函数 $f(x) \approx ax^2+bx+c$ 的系数 $a, b, c$。

3.计算该二次函数的极小点 $x^* = -b/(2a)$。

> [!summary] 实际2,3步可以合为一步, 需要记忆公式, 否则现计算 a, b 非常麻烦
> $$x^*=\frac{1}{2}\frac{f_1\cdot (x_{2}^{2}-x_{3}^{2})+f_2\cdot (x_{3}^{2}-x_{1}^{2})+f_3\cdot (x_{1}^{2}-x_{2}^{2})}{f_1\cdot (x_2-x_3)+f_2\cdot (x_3-x_1)+f_3\cdot (x_1-x_2)}$$

4.判断收敛。若未收敛，则用 $x^*$ 替换掉原来三点中最不好的一个点（通常是函数值最大的点），组成新的三点，返回第2步。

**计算示例**

**问题**: 用二次插值法为 $f(x)=x^2-4x+3$ 求最优解，初始点为 $x_1=0, x_2=1, x_3=4$。

**解题步骤**:

1.初始化三个点及函数值：
$$x_1=0, f_1=3$$
$$x_2=1, f_2=0$$
$$x_3=4, f_3=3$$

2.根据三点坐标 $(0,3), (1,0), (4,3)$ 构造插值多项式。可以解方程组或使用拉格朗日插值公式得到抛物线方程。这里直接给出极小点计算公式：
$$x^* = \frac{1}{2} \frac{f_1(x_2^2-x_3^2)+f_2(x_3^2-x_1^2)+f_3(x_1^2-x_2^2)}{f_1(x_2-x_3)+f_2(x_3-x_1)+f_3(x_1-x_2)}$$ 
3.代入数值计算：$$x^* = \displaystyle\frac{1}{2} \frac{3(1^2-4^2)+0(4^2-0^2)+3(0^2-1^2)}{3(1-4)+0(4-0)+3(0-1)} = \displaystyle\frac{1}{2} \frac{3(-15)+3(-1)}{3(-3)+3(-1)} = \displaystyle\frac{1}{2} \frac{-48}{-12} = 2$$
4.得出近似最优解，经过一次迭代，得到的最优解近似值为 **`2`**。

#### 多维优化方法

##### 梯度法

**算法介绍**

梯度法，又称最速下降法，是一种经典的一阶迭代优化算法，用于求解无约束优化问题。其核心思想是：函数在某一点的**负梯度方向**是该点附近函数值下降最快的方向。算法从一个初始点出发，反复沿负梯度方向进行一维搜索，直至收敛。

**整体的计算过程**

1.  选定初始点 $X^{(0)}$ 和收敛精度 $\epsilon$。
2.  计算当前点 $X^{(k)}$ 的梯度 $\nabla f(X^{(k)})$。
3.  若梯度的模（范数）$||\nabla f(X^{(k)})|| < \epsilon$，则停止。
4.  确定搜索方向 $d^{(k)} = -\nabla f(X^{(k)})$。
5.  进行一维搜索，寻找最优步长 $\alpha_k > 0$，使得 $f(X^{(k)} + \alpha_k d^{(k)})$ 最小。
6.  更新迭代点 $X^{(k+1)} = X^{(k)} + \alpha_k d^{(k)}$，并返回第2步。

**计算示例**

**问题**: $\min f(X)=3x_{1}^{2}+2x_{2}^{2}$, 初始点 $X^{(0)}=[1, 1]^{T}$，迭代一步。

**解题步骤**:
1.  **计算初始点梯度**：目标函数 $f(X)=3x_{1}^{2}+2x_{2}^{2}$ 的梯度为 $\nabla f(X) = \begin{pmatrix} 6x_1 \\ 4x_2 \end{pmatrix}$。在初始点 $X^{(0)} = [1, 1]^T$ 处的梯度为 $\nabla f(X^{(0)}) = \begin{pmatrix} 6 \\ 4 \end{pmatrix}$。
2.  **确定搜索方向**：取负梯度方向为搜索方向 $d^{(0)} = -\nabla f(X^{(0)}) = \begin{pmatrix} -6 \\ -4 \end{pmatrix}$。
3.  **求解最优步长 $\alpha_0$**：构造关于 $\alpha$ 的一元函数 $\phi(\alpha) = 3(1-6\alpha)^2 + 2(1-4\alpha)^2$。令其导数 $\phi'(\alpha)=0$ 求解，得到最优步长 $\alpha_0 = \displaystyle\frac{13}{70}$。
4. **更新迭代点**：得到新点 $X^{(1)} = X^{(0)} + \alpha_0 d^{(0)} = \begin{pmatrix} \dfrac{-4}{35} \\ \dfrac{9}{35} \end{pmatrix}$。

##### 牛顿法

**算法介绍**

牛顿法是一种利用二阶导数（Hessian 矩阵）信息的无约束优化算法。

它通过构造一个二阶泰勒展开式来逼近目标函数，然后直接跳到这个二次函数的极小点。其收敛速度快（二次收敛），但要求计算 Hessian 矩阵及其逆矩阵，计算量大且要求 Hessian 矩阵正定。

> [!info] Hessian矩阵
> **定义**
> Hessian矩阵（或称海森矩阵）是一个方阵，它由一个多变量函数的**所有二阶偏导数**构成。它描述了函数的局部曲率，这正是牛顿法比梯度法收敛更快的原因，因为它不仅考虑了梯度（下降最快的方向），还考虑了函数在该方向上的弯曲程度。
> 
> 对于一个有两个变量的函数 $f(x_1, x_2)$，其Hessian矩阵 $H(X)$ 定义如下：
> 
> $$H(X) = \left[\begin{matrix} \displaystyle\frac{\partial^2 f}{\partial x_1^2} & \displaystyle\frac{\partial^2 f}{\partial x_1 \partial x_2} \\ \\ \displaystyle\frac{\partial^2 f}{\partial x_2 \partial x_1} & \displaystyle\frac{\partial^2 f}{\partial x_2^2} \end{matrix}\right]$$
> 
> 对于大多数在优化问题中遇到的函数（只要二阶偏导连续），混合偏导数是相等的，即 $\displaystyle\frac{\partial^2 f}{\partial x_1 \partial x_2} = \frac{\partial^2 f}{\partial x_2 \partial x_1}$。这使得Hessian矩阵是一个**对称矩阵**。


**整体的计算过程**

1.选定初始点 $X^{(0)}$ 和收敛精度 $\epsilon$;
2.计算当前点 $X^{(k)}$ 的梯度 $\nabla f(X^{(k)})$ 和 Hessian 矩阵 $H(X^{(k)})$;
3.若梯度的模（范数）$||\nabla f(X^{(k)})|| < \epsilon$，则停止;
4.更新迭代点 $X^{(k+1)}=X^{(k)}-\left[ H\left ( X^{(k)} \right) \right] ^{-1}\nabla f\left ( X^{(k)} \right)$ (步长常取1)。返回第2步。

**计算示例**

**问题**: 用牛顿法求 $f(X)=x_1^2 + 2x_2^2$ 的极小点，设初始点 $X^{(0)}=[1,1]^{T}$，迭代一次。

**解题步骤**:
1.  **计算梯度和 Hessian 矩阵**：梯度为 $\nabla f(X) = \begin{pmatrix} 2x_1 \\ 4x_2 \end{pmatrix}$，Hessian 矩阵为 $H(X) = \begin{bmatrix} 2 & 0 \\ 0 & 4 \end{bmatrix}$。
2.  **计算初始点的梯度和 Hessian 逆矩阵**：在 $X^{(0)} = [1, 1]^T$ 处，梯度为 $\nabla f(X^{(0)}) = \begin{pmatrix} 2 \\ 4 \end{pmatrix}$。Hessian 矩阵是常数矩阵，其逆矩阵为 $H^{-1} = \begin{bmatrix} 1/2 & 0 \\ 0 & 1/4 \end{bmatrix}$。
3.  **更新迭代点**：$X^{(1)} = X^{(0)} - H^{-1} \nabla f(X^{(0)}) = \begin{pmatrix} 1 \\ 1 \end{pmatrix} - \begin{bmatrix} 1/2 & 0 \\ 0 & 1/4 \end{bmatrix} \begin{pmatrix} 2 \\ 4 \end{pmatrix} = \begin{pmatrix} 1 \\ 1 \end{pmatrix} - \begin{pmatrix} 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \end{pmatrix}$。
4.  **得出结论**：由于该函数是简单的二次函数，牛顿法仅用一步就直接到达了最优解 **$(0, 0)$**。

##### 可行方向法
> [!summary] 了解即可, 大概率不会出计算题

**可行方向法**是处理约束优化问题的一种直接方法，它在当前点寻找一个既能使目标函数下降、又指向可行域内部的方向进行搜索。
##### 共轭方向法和鲍威尔法
> [!summary] 了解即可, 大概率不会出计算题

**共轭方向法和鲍威尔法**是对梯度法的改进，通过构造一系列“共轭”的搜索方向来替代简单的负梯度方向，能够极大提高在狭长山谷型函数中的收敛效率，避免梯度法的“锯齿形”路径。

##### 惩罚函数法
**算法介绍**

惩罚函数法是处理**约束优化问题**的核心方法之一。其基本思想是通过在原目标函数上增加一个“惩罚项”，将复杂的约束问题转化为一系列的**无约束优化问题**来求解。根据惩罚项作用方式的不同，主要分为**外点法**和**内点法**。

###### (1) 外点法

**算法介绍**

外点法的迭代点可以从可行域外部开始，通过一个巨大的“惩罚”来迫使迭代结果逐渐逼近并最终满足约束条件。对于违反约束的行为，惩罚项会给予一个很大的函数值，从而在求解无约束问题时，算法会自动避开这些点。

**整体的计算过程**

1.构造增广目标函数 $\Phi(X, M) = f(X) + M \cdot P(X)$。其中 $f(X)$ 是原目标函数，$M$ 是一个很大的正数（罚因子），$P(X)$ 是惩罚项。对于等式约束 $h(X)=0$，惩罚项为 $[h(X)]^2$；对于不等式约束 $g(X) \le 0$，惩罚项为 $[\max(0, g(X))]^2$。

2.设定一个递增的罚因子序列 $M_k$（例如 $M_{k+1}=10M_k$），使其趋于无穷大。

3.对于每一个 $M_k$，求解当前的无约束问题 $\min \Phi(X, M_k)$，得到解 $X^*(M_k)$。

4.当 $M_k$ 足够大时，$X^*(M_k)$ 就是原约束优化问题的近似最优解。

**计算示例**

**问题**: 求解 $\min f(X)=\displaystyle\frac{1}{2}x_{1}^{2}+\displaystyle\frac{1}{4}x_{2}^{2}$，约束条件为 $h(X)=x_{1}+x_{2}-1=0$。

**解题步骤**:

1.构造增广函数。这是一个等式约束，因此增广函数为：
$$\Phi(X, M) = \displaystyle\frac{1}{2}x_{1}^{2}+\displaystyle\frac{1}{4}x_{2}^{2} + M(x_1+x_2-1)^2$$ 
2.对变量求偏导并令其为零，以求解无约束极值：$$\displaystyle\frac{\partial \Phi}{\partial x_1} = x_1 + 2M(x_1+x_2-1) = 0$$
$$\displaystyle\frac{\partial \Phi}{\partial x_2} = \displaystyle\frac{1}{2}x_2 + 2M(x_1+x_2-1) = 0$$ 
3.求解上述方程组，得到用 $M$ 表示的解：$$x_1 = \displaystyle\frac{2M}{1 + 6M} \quad , \quad x_2 = \displaystyle\frac{4M}{1 + 6M}$$ 
4.令罚因子 $M \to \infty$ 取极限，得到原问题的最优解：$$x_1^* = \lim_{M \to \infty} \displaystyle\frac{2M}{1 + 6M} = \displaystyle\frac{2}{6} = \displaystyle\frac{1}{3}$$
$$x_2^* = \lim_{M \to \infty} \displaystyle\frac{4M}{1 + 6M} = \displaystyle\frac{4}{6} = \displaystyle\frac{2}{3}$$
最终最优解为 $X^* = \left(\displaystyle\frac{1}{3}, \displaystyle\frac{2}{3}\right)$。

###### (2) 内点法

**算法介绍**

内点法，又称障碍函数法，其迭代点始终保持在**可行域内部**。它通过增加一个“障碍项”来实现，当迭代点靠近可行域的边界时，障碍项会趋于无穷大，就像一堵无形的墙一样，阻止迭代点穿越边界。该方法仅适用于不等式约束。

**整体的计算过程**

1.构造增广目标函数 $\Phi(X, r) = f(X) + r \cdot B(X)$。其中 $f(X)$ 是原目标函数，$r$ 是一个很小的正数（障碍因子），$B(X)$ 是障碍项。

对于不等式约束 $g(X) \ge 0$，常用的障碍项是, 选哪种都可以
- 分数形式 $B(X)=-\sum{\dfrac{1}{g_i\left( X \right)}}$
- 对数形式 $B(X) = -\sum \ln(g_i(X))$。

2.设定一个递减的障碍因子序列 $r_k$（例如 $r_{k+1}=0.1r_k$），使其趋于0。

3.对于每一个 $r_k$，求解当前的无约束问题 $\min \Phi(X, r_k)$，得到解 $X^*(r_k)$。

4.当 $r_k$ 足够接近0时，$X^*(r_k)$ 就是原约束优化问题的近似最优解。

**计算示例**

**问题**: 求解 $\min f(X)=x_{1}^{2}+6x_{1}+x_{2}^{2}+4$，约束条件为 $x_{1}\ge0, x_{2}\ge0$。

**解题步骤**:
1.构造增广函数。这是一个不等式约束，使用对数障碍函数：
$$\Phi(X, r) = x_{1}^{2}+6x_{1}+x_{2}^{2}+4 - r \ln(x_1) - r \ln(x_2)$$ 
2.对变量求偏导并令其为零：$$\displaystyle\frac{\partial \Phi}{\partial x_1} = 2x_1 + 6 - \displaystyle\frac{r}{x_1} = 0 \implies 2x_1^2 + 6x_1 - r = 0$$
$$\displaystyle\frac{\partial \Phi}{\partial x_2} = 2x_2 - \displaystyle\frac{r}{x_2} = 0 \implies 2x_2^2 - r = 0$$ 
3.求解上述方程组，得到用 $r$ 表示的解（取正根以保证在可行域内）：$$x_2 = \sqrt{\displaystyle\frac{r}{2}}$$
$$x_1 = \displaystyle\frac{-6 + \sqrt{36+8r}}{4}$$
4.令障碍因子 $r \to 0^+$ 取极限，得到原问题的最优解：$$x_1^* = \lim_{r \to 0^+} \displaystyle\frac{-6 + \sqrt{36+8r}}{4} = \displaystyle\frac{-6+6}{4} = 0$$
$$x_2^* = \lim_{r \to 0^+} \sqrt{\displaystyle\frac{r}{2}} = 0$$
最终最优解为 $X^* = (0, 0)$。
