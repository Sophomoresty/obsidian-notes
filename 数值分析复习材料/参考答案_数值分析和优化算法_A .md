> [!解释]
> 这里填 Box-Cox 变换和对数变换都可以, 对数变换是 Box-Cox 变换的一个特例。
> 
> **Box-Cox变换** 是一个变换“家族”，它旨在寻找一个最佳的参数 $\lambda$ (lambda)，对数据进行幂变换，使其更接近正态分布、方差更稳定。它的通用公式是：
> 
> $$
> y(\lambda) = 
> \begin{cases} 
> \frac{x^\lambda - 1}{\lambda} & \text{如果 } \lambda \neq 0 \\
> \log(x) & \text{如果 } \lambda = 0 
> \end{cases}
> $$
> 从公式中可以看到:
> * 当Box-Cox变换中的参数 **$\lambda$ (lambda) 恰好等于0时，这个变换就是对数变换**。
> * 所以，对数变换是 Box-Cox 变换家族中的一个特殊成员。

2. (12分)

- **正态分布表达式**: $N(3, 1; 5, 4; \frac{\sqrt{5}}{4})$
> [!解释]
> **正态分布表达式 $N(3, 1; 5, 4; \frac{\sqrt{5}}{4})$ 是如何计算的？**
> 
> $N(\mu_x, \mu_y; \sigma_x^2, \sigma_y^2; \rho)$ 代表了均值、方差和相关系数。我们需要从已知的 `miu` 和 `sigma` 中把这些值算出来。
> 
> **第一步：提取均值 $(\mu_x, \mu_y)$**
> 
> 这最简单，直接从 `miu = [3 1]`  中读取：
> 
> * $\mu_x = 3$
> * $\mu_y = 1$
> 
> **第二步：提取方差 $(\sigma_x^2, \sigma_y^2)$**
> 
> 协方差矩阵 `sigma`  的对角线上的元素就是方差。
> $$\Sigma = \begin{pmatrix} \sigma_x^2 & Cov(X,Y) \\ Cov(X,Y) & \sigma_y^2 \end{pmatrix} = \begin{pmatrix} 5 & 2.5 \\ 2.5 & 4 \end{pmatrix}$$
> 
> * $\sigma_x^2 = 5$ （X 的方差）
> * $\sigma_y^2 = 4$ （Y 的方差）
> 
> **第三步：计算相关系数 $(\rho)$**
> 
> 相关系数的计算公式为：
> $$\rho = \frac{Cov(X,Y)}{\sigma_x \sigma_y}$$
> 
> * 从协方差矩阵中可知，协方差 $Cov(X,Y) = 2.5$。
> * 标准差是方差的平方根：$\sigma_x = \sqrt{5}$，$\sigma_y = \sqrt{4} = 2$。
> * 代入公式计算：
>     $$\rho = \frac{2.5}{\sqrt{5} \times 2} = \frac{2.5}{2\sqrt{5}} = \frac{5/2}{2\sqrt{5}} = \frac{5}{4\sqrt{5}}$$
> * 为了化简，分子分母同乘 $\sqrt{5}$：
>     $$\rho = \frac{5\sqrt{5}}{4\sqrt{5}\sqrt{5}} = \frac{5\sqrt{5}}{4 \times 5} = \frac{\sqrt{5}}{4}$$
> 
> **第四步：组合成最终表达式**
> 
> 将上面计算出的所有值代入格式 $N(\mu_x, \mu_y; \sigma_x^2, \sigma_y^2; \rho)$，就得到了最终结果：
> 
> $$N(3, 1; 5, 4; \frac{\sqrt{5}}{4})$$

- **代码注释**:
```matlab

sigma = [5 2.5; 2.5 4];       % 定义二元正态分布的协方差矩阵
s = rng; rng(s);              % 保存并重置随机数生成器状态, 保证结果可复现
Nr = mvnrnd(miu, sigma, 50);  % 从指定的二元正态分布中生成50个随机样本
subplot(1,2,1), normplot(Nr(:,1)) % 在左子图中绘制第一维数据的正态概率图
subplot(1,2,2), normplot(Nr(:,2)) % 在右子图中绘制第二维数据的正态概率图
figure(2)                     % 创建一个新图形窗口
subplot(1,2,1), qqplot(Nr(:,1)), grid on % 在新窗口左子图中绘制第一维数据的Q-Q图
subplot(1,2,2), qqplot(Nr(:,2)), grid on % 在新窗口右子图中绘制第二维数据的Q-Q图
```

2. **惩罚函数法 (20分)**

(1) 外点法求解等式约束问题

**算法核心思想**

外点法的思路是，将有约束的优化问题，通过在目标函数上增加一个“惩罚项”，转化为无约束优化问题。  这个惩罚项的特点是：当迭代点在**可行域之外**（即不满足约束条件）时，惩罚项为一个很大的正数，从而“惩罚”这种违规行为；当迭代点在可行域内时，惩罚项为0。

对于等式约束 $h(X)=0$，惩罚项通常是 $M \cdot [h(X)]^2$，其中 $M$ 是一个非常大的正数，称为罚因子。通过让 $M \to \infty$，迭代点就会被“逼”着去满足 $h(X)=0$ 这个条件。


**解题步骤**

1. **构造增广目标函数 $\Phi(X, M)$**
    将原函数与惩罚项相加，构造一个新的、无约束的目标函数：
    $$\Phi(X, M) = f(X) + M \cdot [h(X)]^2 = \frac{1}{2}x_{1}^{2}+\frac{1}{4}x_{2}^{2} + M(x_1+x_2-1)^2$$

2. **求解无约束极值**
    现在问题变成了求 $\Phi(X, M)$ 的最小值。我们对 $x_1$ 和 $x_2$ 分别求偏导，并令其等于0：
    $$\frac{\partial \Phi}{\partial x_1} = x_1 + 2M(x_1+x_2-1) = 0 \quad \cdots (a)$$
    $$\frac{\partial \Phi}{\partial x_2} = \frac{1}{2}x_2 + 2M(x_1+x_2-1) = 0 \quad \cdots (b)$$

3. **求解方程组**
    由式 (a) 和 (b) 可以得到 $x_1 = \frac{1}{2}x_2$。将其代入式 (a) 中整理可得：
    $$x_2(0.5 + 3M) = 2M \implies x_2 = \frac{4M}{1 + 6M}$$
    因此，
    $$x_1 = \frac{1}{2}x_2 = \frac{2M}{1 + 6M}$$

4. **取极限得出最优解**
    当罚因子 $M \to \infty$ 时，我们就能得到原约束问题的最优解：
    $$x_1^* = \lim_{M \to \infty} \frac{2M}{1 + 6M} = \frac{2M}{6M} = \frac{1}{3}$$
    $$x_2^* = \lim_{M \to \infty} \frac{4M}{1 + 6M} = \frac{4M}{6M} = \frac{2}{3}$$
    所以，该问题的最优解为 $X^* = (\frac{1}{3}, \frac{2}{3})$。

(2) 对数内点法求解不等式约束问题

**算法核心思想**


内点法（或称障碍函数法）同样是将约束问题转化为无约束问题，但它的迭代点始终保持在**可行域内部**。  它通过增加一个“障碍项”来实现，当迭代点靠近可行域的边界时，障碍项会趋于无穷大，就像一堵墙一样，阻止迭代点穿越边界。

对于不等式约束 $g(X) \ge 0$，最常用的障碍项就是对数项 $-r \cdot \ln(g(X))$，其中 $r$ 是一个很小的正数，并逐渐趋于0。

**解题步骤**

1. **构造增广目标函数 $\Phi(X, r)$**
    原问题的约束是 $x_1 \ge 0$ 和 $x_2 \ge 0$。对应的对数障碍项就是 $-r\ln(x_1)$ 和 $-r\ln(x_2)$。构造新的目标函数：
    $$\Phi(X, r) = f(X) - r\ln(x_1) - r\ln(x_2) = x_{1}^{2}+6x_{1}+x_{2}^{2}+4 - r \ln(x_1) - r \ln(x_2)$$

2. **求解无约束极值**
    对 $x_1$ 和 $x_2$ 分别求偏导，并令其等于0：
    $$\frac{\partial \Phi}{\partial x_1} = 2x_1 + 6 - \frac{r}{x_1} = 0 \quad \implies \quad 2x_1^2 + 6x_1 - r = 0$$
    $$\frac{\partial \Phi}{\partial x_2} = 2x_2 - \frac{r}{x_2} = 0 \quad \implies \quad 2x_2^2 - r = 0$$

3. **求解方程组**
    从第二个方程可以轻松解得 $x_2 = \sqrt{\frac{r}{2}}$ （因为必须在可行域内，所以取正根）。
    第一个方程是一个关于 $x_1$ 的一元二次方程，使用求根公式可得：
    $$x_1 = \frac{-6 + \sqrt{36 - 4(2)(-r)}}{4} = \frac{-6 + \sqrt{36+8r}}{4}$$
    （同样，因为 $x_1>0$ 才能使 $\ln(x_1)$ 有意义，所以取正根）。

4. **取极限得出最优解**
    当障碍因子 $r \to 0^+$ 时，我们得到原问题的最优解：
    $$x_1^* = \lim_{r \to 0^+} \frac{-6 + \sqrt{36+8r}}{4} = \frac{-6+6}{4} = 0$$
    $$x_2^* = \lim_{r \to 0^+} \sqrt{\frac{r}{2}} = 0$$
    所以，该问题的最优解为 $X^* = (0, 0)$。
