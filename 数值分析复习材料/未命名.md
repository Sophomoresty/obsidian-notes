### **优化算法详解与计算实例**

#### 惩罚函数法
**算法介绍**
惩罚函数法是处理**约束优化问题**的核心方法之一。其基本思想是通过在原目标函数上增加一个“惩罚项”，将复杂的约束问题转化为一系列的**无约束优化问题**来求解。根据惩罚项作用方式的不同，主要分为**外点法**和**内点法**。

---
#### (1) 外点法

**算法介绍**
外点法的迭代点可以从可行域外部开始，通过一个巨大的“惩罚”来迫使迭代结果逐渐逼近并最终满足约束条件。对于违反约束的行为，惩罚项会给予一个很大的函数值，从而在求解无约束问题时，算法会自动避开这些点。

**整体的计算过程**
1. 构造增广目标函数 $\Phi(X, M) = f(X) + M \cdot P(X)$。其中 $f(X)$ 是原目标函数，$M$ 是一个很大的正数（罚因子），$P(X)$ 是惩罚项。对于等式约束 $h(X)=0$，惩罚项为 $[h(X)]^2$；对于不等式约束 $g(X) \le 0$，惩罚项为 $[\max(0, g(X))]^2$。
2. 设定一个递增的罚因子序列 $M_k$（例如 $M_{k+1}=10M_k$），使其趋于无穷大。
3. 对于每一个 $M_k$，求解当前的无约束问题 $\min \Phi(X, M_k)$，得到解 $X^*(M_k)$。
4. 当 $M_k$ 足够大时，$X^*(M_k)$ 就是原约束优化问题的近似最优解。

**计算示例**
**问题**: 求解 $\min f(X)=\displaystyle\frac{1}{2}x_{1}^{2}+\displaystyle\frac{1}{4}x_{2}^{2}$，约束条件为 $h(X)=x_{1}+x_{2}-1=0$。
**解题步骤**:
1. 构造增广函数。这是一个等式约束，因此增广函数为：
$$\Phi(X, M) = \displaystyle\frac{1}{2}x_{1}^{2}+\displaystyle\frac{1}{4}x_{2}^{2} + M(x_1+x_2-1)^2$$ 2. 对变量求偏导并令其为零，以求解无约束极值：$$\displaystyle\frac{\partial \Phi}{\partial x_1} = x_1 + 2M(x_1+x_2-1) = 0$$
$$\displaystyle\frac{\partial \Phi}{\partial x_2} = \displaystyle\frac{1}{2}x_2 + 2M(x_1+x_2-1) = 0$$ 3. 求解上述方程组，得到用 $M$ 表示的解：$$x_1 = \displaystyle\frac{2M}{1 + 6M} \quad , \quad x_2 = \displaystyle\frac{4M}{1 + 6M}$$ 4. 令罚因子 $M \to \infty$ 取极限，得到原问题的最优解：$$x_1^* = \lim_{M \to \infty} \displaystyle\frac{2M}{1 + 6M} = \displaystyle\frac{2}{6} = \displaystyle\frac{1}{3}$$
$$x_2^* = \lim_{M \to \infty} \displaystyle\frac{4M}{1 + 6M} = \displaystyle\frac{4}{6} = \displaystyle\frac{2}{3}$$
最终最优解为 $X^* = \left(\displaystyle\frac{1}{3}, \displaystyle\frac{2}{3}\right)$。

#### (2) 内点法

**算法介绍**
内点法，又称障碍函数法，其迭代点始终保持在**可行域内部**。它通过增加一个“障碍项”来实现，当迭代点靠近可行域的边界时，障碍项会趋于无穷大，就像一堵无形的墙一样，阻止迭代点穿越边界。该方法仅适用于不等式约束。

**整体的计算过程**
1. 构造增广目标函数 $\Phi(X, r) = f(X) + r \cdot B(X)$。其中 $f(X)$ 是原目标函数，$r$ 是一个很小的正数（障碍因子），$B(X)$ 是障碍项。对于不等式约束 $g(X) \ge 0$，常用的障碍项是对数形式 $B(X) = -\sum \ln(g_i(X))$。
2. 设定一个递减的障碍因子序列 $r_k$（例如 $r_{k+1}=0.1r_k$），使其趋于0。
3. 对于每一个 $r_k$，求解当前的无约束问题 $\min \Phi(X, r_k)$，得到解 $X^*(r_k)$。
4. 当 $r_k$ 足够接近0时，$X^*(r_k)$ 就是原约束优化问题的近似最优解。

**计算示例**
**问题**: 求解 $\min f(X)=x_{1}^{2}+6x_{1}+x_{2}^{2}+4$，约束条件为 $x_{1}\ge0, x_{2}\ge0$。
**解题步骤**:
1. 构造增广函数。这是一个不等式约束，使用对数障碍函数：
$$\Phi(X, r) = x_{1}^{2}+6x_{1}+x_{2}^{2}+4 - r \ln(x_1) - r \ln(x_2)$$ 2. 对变量求偏导并令其为零：$$\displaystyle\frac{\partial \Phi}{\partial x_1} = 2x_1 + 6 - \displaystyle\frac{r}{x_1} = 0 \implies 2x_1^2 + 6x_1 - r = 0$$
$$\displaystyle\frac{\partial \Phi}{\partial x_2} = 2x_2 - \displaystyle\frac{r}{x_2} = 0 \implies 2x_2^2 - r = 0$$ 3. 求解上述方程组，得到用 $r$ 表示的解（取正根以保证在可行域内）：$$x_2 = \sqrt{\displaystyle\frac{r}{2}}$$
$$x_1 = \displaystyle\frac{-6 + \sqrt{36+8r}}{4}$$ 4. 令障碍因子 $r \to 0^+$ 取极限，得到原问题的最优解：$$x_1^* = \lim_{r \to 0^+} \displaystyle\frac{-6 + \sqrt{36+8r}}{4} = \displaystyle\frac{-6+6}{4} = 0$$
$$x_2^* = \lim_{r \to 0^+} \sqrt{\displaystyle\frac{r}{2}} = 0$$
最终最优解为 $X^* = (0, 0)$。
