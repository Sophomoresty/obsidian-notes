### 六、计算题

#### 1. 黄金分割法

**算法介绍**:

黄金分割法是一种用于求解单变量函数在给定**单峰区间**内极小值的高效搜索算法。  其核心思想是利用黄金分割比例（约0.618）在区间内确定两个试探点，通过比较两点的函数值，来舍去一部分不包含极小值的区间，从而逐步缩小搜索范围，逼近最优解。

**总体步骤**:

1. **初始化**: 确定包含极小值的初始区间 $[a, b]$ 和收敛精度 $\epsilon$。
2. **插入试探点**: 根据黄金分割比例在区间 $[a, b]$ 内计算两个内点 $x_l$ 和 $x_r$。
3. **比较函数值**: 计算 $f(x_l)$ 和 $f(x_r)$ 的大小。
4. **缩减区间**: 根据比较结果，舍弃不含极小值的一部分区间，得到新的、更小的区间。
5. **判断终止**: 检查新区间的长度是否小于 $\epsilon$。若是，则停止迭代，区间中点即为近似最优解；否则，返回第2步。

**本题计算过程**:

1. **步骤一：初始化**
    * **含义**: 明确要求解的函数、初始搜索范围和迭代次数。
    * **计算**:
        * 目标函数: $f(x)=x^{2}-4x+3$
        * 初始区间: $[a_1, b_1] = [-2, 1]$
        * 区间长度: $L_1 = b_1 - a_1 = 1 - (-2) = 3$
        * 黄金分割系数: $\tau = 0.618$

2. **步骤二：计算试探点**
    * **含义**: 在当前区间内按黄金比例找到两个对称的内部点，用于后续的函数值比较。
    * **计算**:
        * $x_r = a_1 + \tau L_1 = -2 + 0.618 \times 3 = -0.146$
        * $x_l = b_1 - \tau L_1 = 1 - 0.618 \times 3 = -0.854$

3. **步骤三：计算函数值**
    * **含义**: 评估两个试探点处的函数值，以判断极小点更靠近哪一侧。
    * **计算**:
        * $f(x_l) = f(-0.854) = (-0.854)^2 - 4(-0.854) + 3 \approx 7.145$
        * $f(x_r) = f(-0.146) = (-0.146)^2 - 4(-0.146) + 3 \approx 3.605$

4. **步骤四：比较与缩减区间**
    * **含义**: 根据“大→小”或“小→大”的趋势，判断并舍弃肯定不包含极小值的区间部分。
    * **判断**: 因为 $f(x_r) < f(x_l)$，说明函数值在从 $x_l$ 到 $x_r$ 的方向上是下降的，极小点一定在 $x_l$ 的右侧。因此，舍去区间 $[a_1, x_l]$。
    * **新区间**: 新的搜索区间为 $[a_2, b_2] = [x_l, b_1]$。

5. **步骤五：得出新区间**
    * **含义**: 给出单次迭代后的最终结果。
    * **结果**: 下一个搜索区间为 **`[-0.854, 1]`**。

#### 2. 梯度法

**算法介绍**:

梯度法，又称最速下降法，是一种经典的一阶迭代优化算法，用于求解无约束优化问题。  其核心思想是：函数在某一点的**负梯度方向**是该点附近函数值下降最快的方向。  因此，算法从一个初始点出发，沿着当前点的负梯度方向进行一维搜索，找到该方向上的极小点作为下一次迭代的起点，如此反复，直至收敛到函数的局部极小点。

**总体步骤**:

1. **初始化**: 选定初始点 $X^{(0)}$ 和收敛精度 $\epsilon$。
2. **计算梯度**: 计算当前点 $X^{(k)}$ 的梯度 $\nabla f(X^{(k)})$。
3. **判断终止**: 检查梯度的模（范数）$||\nabla f(X^{(k)})||$ 是否小于 $\epsilon$。若是，则停止迭代；否则继续。
4. **确定搜索方向**: 取当前点的负梯度方向为搜索方向 $d^{(k)} = -\nabla f(X^{(k)})$。
5. **一维搜索**: 寻找最优步长 $\alpha_k > 0$，使得 $f(X^{(k)} + \alpha_k d^{(k)})$ 最小。
6. **更新迭代点**: 计算新点 $X^{(k+1)} = X^{(k)} + \alpha_k d^{(k)}$，并返回第2步。

**本题计算过程**:

1. **步骤一：计算初始点梯度**
    * **含义**: 确定在初始点 $X^{(0)}$ 处，函数值增长最快的方向。
    * **计算**:
        * 目标函数: $f(X)=3x_{1}^{2}+2x_{2}^{2}$
        * 梯度向量: $\nabla f(X) = \begin{pmatrix} \partial f / \partial x_1 \\ \partial f / \partial x_2 \end{pmatrix} = \begin{pmatrix} 6x_1 \\ 4x_2 \end{pmatrix}$
        * 初始点 $X^{(0)} = [1, 1]^T$ 处的梯度: $\nabla f(X^{(0)}) = \begin{pmatrix} 6(1) \\ 4(1) \end{pmatrix} = \begin{pmatrix} 6 \\ 4 \end{pmatrix}$。

2. **步骤二：确定搜索方向**
    * **含义**: 取负梯度方向作为本次迭代函数值下降最快的方向。
    * **计算**: $d^{(0)} = -\nabla f(X^{(0)}) = \begin{pmatrix} -6 \\ -4 \end{pmatrix}$。

3. **步骤三：求解最优步长 $\alpha_0$ (线搜索)**
    * **含义**: 确定沿着搜索方向 $d^{(0)}$ 走多远（步长 $\alpha$）能使函数值最小。
    * **计算**:
        * 构造关于 $\alpha$ 的一元函数: $\phi(\alpha) = f(X^{(0)} + \alpha d^{(0)}) = f(1-6\alpha, 1-4\alpha) = 3(1-6\alpha)^2 + 2(1-4\alpha)^2$。
        * 求导并令其为0: $\phi'(\alpha) = 3 \cdot 2(1-6\alpha)(-6) + 2 \cdot 2(1-4\alpha)(-4) = -36(1-6\alpha) - 16(1-4\alpha) = 0$。
        * 解得: $216\alpha - 36 + 64\alpha - 16 = 280\alpha - 52 = 0 \implies \alpha_0 = \frac{52}{280} = \frac{13}{70}$。

4. **步骤四：更新迭代点 $X^{(1)}$**
    * **含义**: 从初始点出发，沿着下降最快的方向，移动最优步长的距离，得到新的、函数值更小的点。
    * **计算**: $X^{(1)} = X^{(0)} + \alpha_0 d^{(0)} = \begin{pmatrix} 1 \\ 1 \end{pmatrix} + \frac{13}{70} \begin{pmatrix} -6 \\ -4 \end{pmatrix} = \begin{pmatrix} 1 - 78/70 \\ 1 - 52/70 \end{pmatrix} = \begin{pmatrix} -8/70 \\ 18/70 \end{pmatrix} = \begin{pmatrix} -4/35 \\ 9/35 \end{pmatrix}$。

5. **步骤五：验证方向垂直**
    * **含义**: 梯度法的一个重要特性是，对于二次函数，连续两次迭代的搜索方向是正交（垂直）的。  我们通过计算两次梯度的点积来验证这一点。
    * **计算**:
        * 计算新点 $X^{(1)}$ 处的梯度: $\nabla f(X^{(1)}) = \begin{pmatrix} 6(-4/35) \\ 4(9/35) \end{pmatrix} = \begin{pmatrix} -24/35 \\ 36/35 \end{pmatrix}$。
        * 计算前后两次梯度的点积: $(\nabla f(X^{(0)}))^T (\nabla f(X^{(1)})) = (6)(-\frac{24}{35}) + (4)(\frac{36}{35}) = \frac{-144 + 144}{35} = 0$。
    * **结论**: 因为点积为0，所以前后两个搜索方向（梯度方向）**相互垂直**。
